# 摩擦滑移与碰撞反弹

## 一个接触实验台，两组问题

同一斜面上的两个滑块为什么一个滑、一个停？给球设置了恢复系数，为什么仍可能不明显反弹？本课用沿坡位移和首次反弹峰，把模型文件中的 surface 参数、接触双方配对和真实运动对应起来。

左侧 friction_ramp 为20°斜面，slider_low、slider_high 是同尺寸、同质量滑块；右侧 ball_dead、ball_bouncy 从相同高度落向各自的 pad。质量、惯性和几何保持受控，主要改变接触属性。全部测量使用 Classic 原生 pose/stats，不需要 ROS 或接触传感器。

## 参数写在 collision 中

本课采用 Gazebo Classic 11、ODE 的摩擦金字塔模型。surface 位于 `model → link → collision` 内；visual 的颜色与材质用于显示，不决定这里的摩擦或恢复系数。

```text
个人练习目录/
  world.sdf          几何、质量和各collision的surface
  parameters.json    滑移步数、峰值采样窗口
  lab.py             predict / experiment入口
  contacts.py        参数校验、接触配对与理论预测
  instrument.py      实际采样、沿坡投影与括峰拟合
  transport.py       Classic消息读取与有界查询
  verify.py          验收入口
```

点击“编辑练习文件”打开个人 world.sdf。按 model name 找到相应模型，再修改它的 collision/surface。不要在安装目录中修改原始课包；“查看参考答案”只读展示计算和操作，不覆盖个人文件。

| 字段 | 单位与作用 |
| --- | --- |
| friction/ode/mu | 无量纲，第一切向方向的库仑摩擦系数，允许非负且可大于1 |
| friction/ode/mu2 | 无量纲，第二个正交切向方向的摩擦系数 |
| friction/ode/fdir1 | collision 局部坐标系中的第一切向单位向量 |
| bounce/restitution_coefficient | 无量纲、0至1，法向碰撞恢复系数 e |
| bounce/threshold | m/s，激活反弹恢复项所需的最小接近速度 |

mu 与 mu2 对应两个空间方向，**不能把它们解释为静摩擦和动摩擦**。静止时摩擦力在允许范围内取维持平衡所需的值，并非总等于 μN。进入沿某一主方向的滑动后，可用该方向的库仑摩擦上限作近似分析。[官方摩擦说明](https://classic.gazebosim.org/tutorials?cat=physics&tut=friction)解释了这两个方向与非负系数。

## 接触双方怎样配对

在本课 Classic/ODE 路径中，对两个接触表面 A、B：

```text
mu_pair        = min(mu_A, mu_B)
mu2_pair       = min(mu2_A, mu2_B)
e_pair         = min(e_A, e_B)
threshold_pair = min(threshold_A, threshold_B)
```

这些是本版本后端的配对规则，不可推广成所有物理引擎的统一规律。例如球 e=0.8，垫 e=0，配对后仍为0；只提高球的值不能越过垫的限制。阈值也取 min：一侧阈值10、另一侧0.1，接触阈值仍为0.1 m/s。[Classic ODE 接触实现](https://github.com/gazebosim/gazebo-classic/blob/gazebo11/gazebo/physics/ode/ODEPhysics.cc)可用于核对配对过程。

fdir1 随 collision 的姿态转到 world；第二方向与它及接触法线正交。斜面与两滑块初始方向一致，三者都设 `(1,0,0)`，因此沿坡运动使用 mu。不能把局部 X 无条件当成世界 X。本课要求双方使用同一切向主轴，允许一起切换到局部 ±Y，不处理任意方向或冲突方向的选择。

## 先预测，再测量

点击“开始实验”，执行命令区“预测当前接触参数与采样窗口”，等价于：

```bash
python3 lab.py predict
```

先记录滑块的配对系数、预计状态和球的预测反弹高度。predict 读取个人文件，不证明服务器已经加载修改。窗口出现时，物体可能已运动；正式仪器会重新建立初始条件。

然后运行命令区的实验，或在“打开实验终端”中保存一次实际报告：

```bash
python3 lab.py experiment --report measurements-baseline.json
```

仪器先完整校验配置，再读取原暂停状态、暂停并推进一步排空历史力/扭矩，等待实际步数确认后 reset ALL，采集 stats 基线并核对真实模型和 surface。正式采样按仿真步数的时间顺序安排，读取滑块位移及球峰前后的高度。不要同时拖动、单步、重置或施力。

核对时区分文件声明值、按引擎规则预期的运行值和实际读取值。例如本课静态斜面、垫面的文件 `contact/ode/max_vel=0.1`，Classic/ODE 加载静态 collision 后会将运行值强制设为0；这是明确的引擎转换。它与恢复系数、bounce/threshold 分别核对，不能从静态表面的这个0推断球不会反弹。[对应的 ODECollision 加载代码](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/physics/ode/ODECollision.cc#L65)给出转换条件。

试验会重置本课全部模型、速度和仿真时间，最后只恢复原暂停/继续状态，保留试验结果；不会还原原来的完整 state。恢复运行后物体还会继续运动，JSON 保留的是采样时刻的结果。

## 第一组：滑动和静止需要哪一个系数

斜面的 mu/mu2 为1/1；低摩擦滑块为0.1/0.8，高摩擦滑块为0.8/0.8。两滑块均为1 kg、0.4×0.4×0.2 m。沿坡使用第一方向，所以配对系数分别为0.1、0.8。

坡角 θ=20°，`tanθ≈0.364`。高摩擦块可用支撑摩擦平衡坡向重力，应保持近似静止；低摩擦块预计向坡下滑动。对于从静止开始、贴合斜面且无滚转的主轴滑移，近似加速度为：

```text
a = g(sinθ − mu_pair cosθ)
s ≈ a t²/2
```

基准 g=9.81、800步×0.001 s=0.8 s，低摩擦块预计沿坡移动约0.779 m。不要把世界 x 的变化直接当作沿坡距离；仪器会做坡向投影。接触建立、积分和约束近似会带来偏差，这个连续模型预测不作为逐位相等的实测数值。

对静止高摩擦块，摩擦力只需抵消坡向重力。把0.8硬代入滑动公式得到负加速度，不代表它会自行向坡上加速。

## 第二组：首跳高度与反弹阈值

两个球半径0.12 m、质量0.5 kg，初始球心 z=1.8 m，垫顶 z=0.2 m；球心接触高度是0.32 m，自由落差 `H=1.8−0.2−0.12=1.48 m`。两个垫的 e 都为1，球的 e 分别为0和0.8，因此配对恢复系数为0和0.8。双方 threshold 均为0.1 m/s，低于预计约5.389 m/s的法向接近速度。

恢复系数是碰撞后分离速度与碰撞前接近速度的法向比值。理想竖直落球、无空气阻力且垫静止时，首次反弹上升高度为 `h≈e_pair² H`。因此 ball_bouncy 预测上升0.9472 m，球心峰高约1.2672 m；ball_dead 不应出现显著恢复性反弹。接触纠正仍可能造成微小运动，不把任何小抖动都解释成非零恢复系数。

仪器对反弹球采集峰区上升与下降两侧的实际高度，再拟合峰位置，并检查括峰和曲率；它不会只在预测时刻读取一个点就声称找到最高点。报告中的预测峰和实际采样峰应分别阅读。理想 h=e²H 关系描述法向高度，不能把 e 直接当成保留的能量比例。

2026-10-30，ikaros 基准实测：低/高摩擦块沿坡位移0.779768/0.000400164 m；反弹球峰区采样最大球心z为1.22539 m，三点拟合峰为1.2258801 m，对应rise为0.9058801 m，dead对照rise为0。实际rise比理想0.9472 m低约4.4%；实际接触包含软约束和离散求解，应在报告中保留这种偏差，不能把理想值代替测量或把拟合顶点称为直接采到的一帧。

同日将三处 fdir1 一致转为Y后，两滑块实测位移均约0.000400164 m，表现为初始微小间隙沉降后的近静止；与X方向低块的0.779768 m形成对照，不将这个微小位移写成绝对零。

本课固定全局 `physics/ode/constraints/contact_max_correcting_vel=10 m/s`，两球都使用 `contact/ode/max_vel=10 m/s、min_depth=0.001 m`，且 kp/kd 也相同；两球接触对比仍只改变恢复系数。在 Classic 11.15.1 的 QuickStep 路径中，加入恢复项后的接触约束目标仍会受速度上限夹紧，过低的 max_vel 会把应有反弹截成微小运动，不能概括为“只影响纠穿”。这里提高上限用于避免额外截断，不改变 e 的速度比定义；predict 的 contact_velocity_limits 会检查全局与两球上限至少达到 `max(e_pair×预计撞速)+0.5 m/s`，基准需要约4.811 m/s。

SDF 的默认 bounce threshold 很大；修改模型时应显式核对。阈值以 m/s 表示，取双方较小值；若预计接近速度低于配对阈值，恢复项关闭。本课使用 `bounce/threshold`，不要用未定义的 surface/min_vel 替代；`contact/ode/max_vel` 是另一项接触速度上限，本版本对最终反弹幅度的影响如上所述。[SDF 1.7 的 collision/surface 定义](https://sdformat.org/spec/1.7/collision/)给出字段位置。

## 单变量修改与独立挑战

每次先保留正确配置、写预测，再修改个人文件并保存，运行 predict，点击“重载项目”，最后重新实验并另存报告。只重开 Gazebo 窗口或重置模型状态不会重新解析 surface。

1. **摩擦大小**：只把 slider_low 的 mu 从0.1改为0.2，mu2仍留0.8，其他量不变。预计沿坡仍滑动，但0.8 s位移减至约0.484 m。用实际坡向位移比较；这同时检查你有没有把 mu2 当作动摩擦系数。
2. **摩擦方向**：从基准出发，仅把 friction_ramp、slider_low、slider_high 三处 fdir1 同步由 `(1,0,0)` 改为 `(0,1,0)`，保持接触双方方向一致。沿坡改用第二方向系数，两块应都近似静止。不要只改单个表面，或同时改 mu 来混淆比较。
3. **恢复系数**：恢复基准方向，只把 ball_bouncy 的 `bounce/restitution_coefficient` 从0.8改为0.6。预测首次上升0.5328 m、球心峰高0.8528 m；峰高相对接触高度的增量应为原来的0.5625。重新测量，区分恢复系数与高度比。
4. **阈值配对**：先只把 ball_bouncy 的 threshold 改为10，pad_bouncy仍为0.1，预测接触阈值仍为0.1，反弹仍激活。再把 pad_bouncy 也改为10，预计恢复项关闭。后一个配置超出本课“清晰首跳峰”定量仪器的适用范围，predict 会拒绝测量；它仍是可手动观察的场景。保存、重载后用“暂停 → 重置模型状态 → 继续”观察首落，随后将双方阈值恢复0.1、重载，再做正式验收。

定量仪器需要可观察的位移和反弹峰。本课要求滑动时预计位移≥0.15 m、离静止/滑移边界 `|tanθ−mu_eff|≥0.04`，初始位置及所有采样结束前均留有跑道余量。反弹球配对 e 限0.4至0.9，理想rise≥0.12 m，预计撞速须比配对阈值大0.3 m/s以上；峰半窗至少0.04 s，预计邻点高度差至少0.004 m。predict 给出当前事件步数及适用性检查，完整边界见参考页；阈值关闭或过小反弹时，应区分“物理配置合法”与“当前测量方法适用”。

## 验收、排错与边界

点击“验收实验”会重新建立初始条件，核对当前文件与实际服务器的 surface、几何等属性，再检验本课滑移和反弹观测；同样只恢复暂停状态。请保留预测、修改前后实际 JSON 和你的解释。自动验收不替你证明理解了静止摩擦、坐标方向或配对规则。

信息流是：**个人 world/参数 → 配对与测量窗口预测 → 暂停、排空历史输入、重置 → 真实模型/surface 与时钟基线 → 按步数排序采样 → 沿坡投影、上升/下降括峰及拟合 → 对照预测并保留结果 → 恢复原暂停状态。**

| 现象 | 优先检查 |
| --- | --- |
| 改颜色却没有改变滑动 | 接触属性在 collision/surface，visual 材质不参与本课参数配对 |
| mu已调高但仍很滑 | 另一接触面的较小值、当前沿坡使用mu还是mu2、是否已重载 |
| 旋转后方向解释不一致 | fdir1是collision局部方向；本课双方需采用相同切向主轴 |
| 球e非零仍不反弹 | 垫的e是否为0；配对阈值是否过高；当前QuickStep的全局与球速度上限是否截断恢复目标 |
| 静态表面max_vel文件为0.1、运行值为0 | 按Classic/ODE静态collision转换规则核对；不要把它误作恢复系数或反弹阈值 |
| 只把球阈值调大却仍反弹 | pad的较小阈值仍会成为配对阈值 |
| 读到的峰低于预测 | 是否用了球心高度与真实接触高度、首次反弹、实际括峰数据；是否超出采样量程 |
| predict正确、运行还是旧结果 | 文件预测不等于当前服务器配置；保存并重载后再测量 |

本课固定接触和求解设置，先解释参数与现象；求解稳定性、接触传感器会在后续课程专门讨论。进一步理解摩擦金字塔与切向方向，可看[Classic 物理参数说明](https://classic.gazebosim.org/tutorials?cat=physics&tut=physics_params)和[ODE 接触模型手册](https://www.ode.org/ode-latest-userguide.html)。
