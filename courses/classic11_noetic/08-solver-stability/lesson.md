# 求解稳定性：承载接触与可复现比较

## 球沉入支撑面，一定是求解失败吗

本课让两个相同的刚体球分别压在不同接触刚度的支撑面上。你将测量尾段高度、几何重叠及重复差异，再分别改变步长、迭代次数和求解器。目标是分清物理模型允许的柔顺性、数值近似和当前仪器能观察到的波动，而不是制造一次“参数太粗就必然爆炸”的演示。

probe_soft、probe_firm 都是半径0.15 m、质量2 kg的均匀球；support_soft、support_firm 为静态水平支撑，顶面z=0.2 m。初始球心z=0.353 m，距表面有0.003 m间隙。两组接触的摩擦、恢复系数、阻尼等条件相同，主要差别是接触刚度。

球与支撑仍是刚体几何；soft contact（软接触）用允许的几何重叠近似柔顺性，不会把球网格压扁，也不等同有限元材料变形。

```text
  stability.py       配对承载预测、量程与采样计划
  instrument.py      真实物理查询、重复采样与统计

```

点击“编辑练习文件”打开个人 world.sdf。课程模板留在安装目录，修改个人副本；“查看参考答案”只读展示解法。

应用在开始时自动准备已提供的只读查询工具，需要已安装g++、pkg-config及Gazebo开发包；初次初始化可能稍久，你无需编写或先学习C++。工具只读取physics_info，不向服务器安装插件或修改求解配置。

| 参数层 | 本课关注的量 | 改变什么 |
| --- | --- | --- |
| physics | max_step_size、ode/solver/type、iters | 时间离散与约束求解方法 |
| collision/surface/contact/ode | kp、kd、min_depth、max_vel | 接触柔顺性、允许深度及速度限制 |
| parameters.json | 预热、采样间隔和重复次数 | 观察计划，不直接改变材料或求解器 |

kp单位为N/m，kd为N·s/m，深度为m，速度上限为m/s，步长为s。质量与中心惯量沿用均匀球公式；本课球的三个主惯量均为0.018 kg·m²。

## 接触刚度怎样进入ERP与CFM

**ERP（error reduction parameter）**指定每步尝试消除多少约束误差；**CFM（constraint force mixing）**允许约束在载荷下有一定柔顺性。它们不是“一项调精度、一项调速度”的两个旋钮。

本课 Classic 11/ODE 对显式接触参数先合并两侧：

```text
k_pair = 1/(1/k_A + 1/k_B)
d_pair = d_A + d_B
ERP_contact = h k_pair / (h k_pair+d_pair)
CFM_contact = 1/(h k_pair+d_pair)
```

soft两侧kp均为2000，配对刚度为1000 N/m；firm两侧均为200000，配对为100000 N/m。双方kd均为30，配对阻尼为60 N·s/m。基准h=0.001 s时，soft接触ERP约0.016393、CFM约0.016393；firm分别为0.625、0.00625。数字相同不表示ERP和CFM具有相同物理意义。

这条局部接触路径使用由kp/kd计算的soft ERP/CFM，不能只改变全局erp/cfm就声称已经改变上述接触柔顺性。改变h、保持物理kp/kd不变时，派生的ERP/CFM也会变化。[Classic的实际接触转换](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/physics/ode/ODEPhysics.cc)和[ODE的ERP/CFM说明](https://www.ode.org/ode-latest-userguide.html)可用于核对。

单接触、近似静态承载时，球重mg与接触反力平衡，几何重叠可估为 `δ≈min_depth+mg/k_pair`。基准min_depth=0.0001 m，soft预测约0.01972 m、firm约0.0002962 m。这些是模型预测，真实尾段统计仍需测量。soft球更深不自动表示它的求解结果更差。

## 步长、迭代和实际速度

基准采用ODE的quick、80次迭代、h=0.001 s。quick使用迭代约束求解；world使用另一条直接求解路径。iters控制QuickStep的迭代预算，不能按同样意义解释world的这个字段。world仍有有限步长、接触模型和浮点误差，不能称作真实世界的精确答案。

减小h，会增加相同仿真时长所需的步数，也可能改善时间分辨率；增加iters会增加每步工作量，可能降低迭代误差。结果还取决于问题条件、接触集合与误差来源，不能保证某个高度指标随这些参数单调变好。本课只有两个简单单接触系统，20次与80次迭代可能已经十分接近。

**仿真时间**按实际步数推进：`Δt_sim=N×h`。实时因子RTF比较同一运行区间的仿真时间与现实时间；GUI帧率和终端命令耗时都不能替代h。real_time_update_rate为0表示不按该频率节流，设备仍受计算能力限制。physics_info返回的real_time_factor是**配置目标**，无节流时也可能仍显示1，不是当前实测的sim/wall时间比。本课仪器报告的墙钟耗时包括CLI、等待和采样，是端到端时间，不是纯求解器CPU时间，也不当作自由运行RTF。[官方物理参数说明](https://classic.gazebosim.org/tutorials?cat=physics&tut=physics_params)介绍了这些区别。

## 引导实验：先认识可观察的量

1. 开始实验，执行“预测当前求解与接触配置”，或在实验终端运行 `python3 lab.py predict`。先记录当前h、solver、iters、配对ERP/CFM和两球预计重叠。再用“读取实际已加载physics配置”或 `python3 lab.py physics` 对照服务器的真实配置，区分文件预测与运行状态。
2. 运行实验并保存报告：`python3 lab.py experiment --report measurements-baseline.json`。仪器重新建立初始条件，读取真实物理配置和模型，按仿真时间推进；期间不要拖动、施力或同时操作暂停/单步。
3. 基准进行2次重复试验，每次先推进一步排空历史输入、reset ALL并取新stats基线，首次重置后核对实际模型。预热1 s时取得第一个尾段点，再按0.1 s间隔采另外4点，即本次基线后的1.0、1.1、1.2、1.3、1.4 s。比较每组的平均重叠、高度标准差与极差、与预测的差值，以及两次重复的均值差；实际时刻以报告stats为准。
4. 球心z低于 `支撑顶面+r` 表示几何重叠，高于则存在间隙。这来自pose与已知形状，不是接触传感器、接触力或求解器内部残差。课包关闭自动休眠与额外速度衰减，并在每个尾段点核对球仍enabled，避免用sleep冻结伪装稳定。几个尾段点很平稳仍不能证明所有物理步上都没有高频运动；本课不据此做频谱分析。
5. 检查仪器的状态边界：试验会重置本课模型、速度和时钟，最终只恢复原暂停/继续状态，保留结果，不还原试验前完整state。恢复运行后球仍可继续演化，JSON保存的是当次采样。

## 独立挑战：每次只比较一个变量

每次从基准出发，保存修改、运行predict、点击“重载项目”，再执行experiment并使用新报告文件名。修改文件不会自动改变旧服务器配置。

- 只将quick的iters从80改为20，其他参数保持。比较尾段均值和波动；如果差异很小，说明这次简单问题与采样没有显示出明显差异，不补写一场没有发生的失稳。
- 恢复基准，只将max_step_size从0.001改为0.002 s。保持预热与采样的**仿真时长**及物理kp/kd不变，让工具重新换算步数和接触ERP/CFM。不要同时缩短观察窗口。
- 恢复基准，只将ode/solver/type从quick改为world。记录当前实际solver，比较相同指标；不要用world下的iters数值推断它执行了80次QuickStep迭代，也不由一次端到端墙钟耗时作性能排名。
- 接触柔顺性扩展：恢复基准，只把soft球与其支撑的kp同时从2000改为4000，保持双方配对设计一致。配对刚度变为2000 N/m，承载预测重叠约0.00991 m；这次改变的是物理接触模型，不以“沉得更少”称作求解精度提高。

各项对照都应把预测、实际配置和真实统计分别保存。合法参数对照可以全部保持稳定；本课不要求某个配置必须倾倒、抖动或发散。

### 2026-10-30 ikaros实测示例

在Classic 11.15.1上，基准两球的尾段平均几何重叠分别为19.529608 mm与0.294383 mm，对应理论19.72 mm与0.2962 mm。quick改为20次迭代后，结果与80次只差约10⁻¹³ m量级；这次简单接触没有显示出有意义的迭代差异。world对照为19.720002 mm与0.2962 mm，更接近本例的承载预测，但不能据此推出它在所有场景都更准确或更快。步长与刚度变式的完整对照见参考页。

本轮各尾段点均核对enabled=true，两次重复均值差为0；基准soft的5点标准差约3×10⁻⁹ m、极差约7.7×10⁻⁹ m，firm标准差为0。这些是模拟器数值尾样，既不表示纳米级物理精度，也不证明没有未采到的高频运动或跨设备逐位一致；firm的零标准差也不是休眠证据。

## 为什么尺度、接触层和种子也重要

大质量比、错误惯量、过小几何尺度和大量冗余接触会改变约束系统的数值条件。先核对SI、COM与惯量，不能靠任意改质量来掩盖问题。几何长度缩放时，惯量也随质量和长度平方变化；这些一致性检查承接第06课。

contact_surface_layer与min_depth描述允许的接触深度，max_vel限制接触修正目标；本版本QuickStep中它还可能影响加入恢复项后的目标，前一课已有示例。本课保持它们固定。显式局部min_depth会进入动态体的接触参数，不能假定只改全局层厚就必然改变本例的死区；需追踪实际采用路径。

本课服务器使用固定种子42，完整reset ALL会重新设定当前Gazebo/ODE随机种子，有助于重复比较。相同种子不能消除线程、浮点、消息时序、版本与平台差异；重复试验用真实差异和容差描述，不承诺跨设备逐位一致。[World::Reset的种子与重置路径](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/physics/World.cc)提供了版本依据。

## 验收与排错

“验收实验”核对当前文件与实际服务器配置，再按相同仪器流程取得重复观测。请解释每个指标测到了什么；一个PASS不表示所有工况都准确，较小的几何重叠也不自动等于更好的物理模型。

信息流是：**个人物理/接触参数 → 单位和采样计划校验、理论预测 → 暂停并核对实际physics配置 → 每次排空历史输入、重置与采stats基线（首次核对实际模型）→ 预热和定步尾段采样、检查enabled → 几何重叠统计与重复差 → 保留结果并恢复原暂停状态。**

| 现象 | 检查方向 |
| --- | --- |
| soft球明显沉入支撑 | 先比较软接触预测，不把允许的柔顺重叠一概当成未收敛 |
| 改全局CFM后结果接近 | 查本例局部contact kp/kd派生的ERP/CFM是否覆盖对应项 |
| 减h后步数仍没变 | 核对以秒规定的观察时长、实际stats与换算后的步数 |
| 两次墙钟耗时不同 | 查询、调度、图形和系统负载也在变化；本报告不是纯求解CPU基准 |
| 迭代变多但某个指标未改善 | 检查主要误差来自迭代、时间离散还是模型柔顺性，避免只盯一个数 |
| 文件已改、实际参数仍旧 | 保存后重载；使用本课只读物理查询，勿把修改命令当查询 |

需要补充矩阵与数值条件的背景，可看[MIT线性代数课程](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)。本课不引入关节结构或PID控制，后续会在独立课程中处理。
