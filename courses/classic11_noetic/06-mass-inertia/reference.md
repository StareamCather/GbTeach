# 参考推导：三站实验的参数与预期

本页只读，不改写个人练习。下列数字分为几何/参数推导与本课固定步进预测；真实采样以实验输出为准，不把预测值冒充测量值。

## 质量与自由落体

均匀长方体的中心主惯量为：

```text
Ixx = m(b²+c²)/12
Iyy = m(a²+c²)/12
Izz = m(a²+b²)/12
```

边长0.2 m的立方体三项均为 `m×0.04/6`。0.5 kg时每项0.0033333333 kg·m²，5 kg时0.0333333333，挑战改为10 kg时应填0.0666666667。尺寸不变、质量同比变化，惯量同比变化；这与自由落体加速度保持 g 并不矛盾。

基准 g=9.81 m/s²、dt=0.001 s、N=200，连续下落距离0.1962 m。本课步进预测使用 `g dt² N(N+1)/2`，得到0.197181 m，中心高度2−0.197181=1.802819 m；此时仍未触地。它依赖本课的积分与步进条件，不作为所有物理引擎的通用离散公式。

改变初始高度会改变可用测量窗口，但不会改变只有重力时的加速度。正式比较应对齐真实 stats 的仿真时钟和步数，排除接触后阶段。

## 低塔与高塔：先算质心

以脚底作为计算高度零点：1 kg柱中心在0.6 m，4 kg配重在0.12或1.08 m。

```text
h_low  = (1×0.6 + 4×0.12)/5 = 0.216 m
h_high = (1×0.6 + 4×1.08)/5 = 0.984 m
```

SDF link 原点位于几何中心，高于脚底0.6 m，所以 inertial.pose.z 应为−0.384、+0.384；配重 visual 中心相对 link 为−0.48、+0.48。塔整体倾斜时，应再用模型 pose 把这些局部坐标变换到 world，不能只把它们加到世界 z。

坡角20°时，重力线在支撑面上的坡向偏移绝对值为：

```text
0.216 tan20° ≈ 0.07862 m < 0.15 m
0.984 tan20° ≈ 0.35815 m > 0.15 m
```

低塔具有静态平衡的支撑条件，高塔的初始姿态无法保持静态平衡。这里假定摩擦足够，接触支撑面与几何一致；判据不直接计算动态倾覆角度，也不能用来判断任意外力下的运动。

## 两塔的中心惯性

柱尺寸0.3×0.3×1.2 m、质量1 kg，配重尺寸0.24×0.24×0.16 m、质量4 kg。先计算各自关于自身 COM 的惯性，再用平行轴定理移到总 COM 并求和。

```text
柱：Ixx=Iyy=0.1275；Izz=0.015
配重：Ixx=Iyy=0.0277333333；Izz=0.0384
低塔：柱距总COM 0.384，配重距总COM −0.096 m
高塔：上述两个偏移的符号相反

总Ixx=总Iyy
 = 0.1275+0.0277333333 + 1×0.384² + 4×0.096²
 = 0.3395533333 kg·m²
总Izz = 0.015+0.0384 = 0.0534 kg·m²
```

两种分布关于几何中心上下镜像，所以中心主惯量相同，COM 相对支撑边的位置不同。关于倾覆边的惯量还需加入新的平行轴项；不能由中心惯量相同推断两塔会以相同速度倾倒。

低塔的关键 SDF 数据可写成：

```xml
<inertial>
  <pose>0 0 -0.384 0 0 0</pose>
  <mass>5</mass>
  <inertia>
    <ixx>0.339553333333</ixx>
    <iyy>0.339553333333</iyy>
    <izz>0.0534</izz>
    <ixy>0</ixy><ixz>0</ixz><iyz>0</iyz>
  </inertia>
</inertial>
```

计算挑战中配重移到离脚底0.3 m：总 COM 高度0.36 m，inertial.pose.z=−0.24 m，配重 visual.z=−0.3 m；投影约0.13103 m，仍小于0.15 m。中心横向惯量重新计算为 `0.1275+0.0277333333+1×0.24²+4×0.06²=0.2272333333`，Izz仍为0.0534 kg·m²。只改 COM 坐标却保留旧惯性，不能描述这次配重移动的同一质量分布。

## 飞轮：主惯量与单步角冲量

外半径 R=0.35 m、厚度 H=0.08 m、质量 M=2 kg。均匀实心圆柱相当于内半径 r=0；均匀厚圆环 r=0.32 m。沿中心轴及横向的惯量为：

```text
Izz = M(R²+r²)/2
Ixx = Iyy = M[3(R²+r²)+H²]/12
```

| 模型 | Ixx=Iyy / kg·m² | Izz / kg·m² |
| --- | --- | --- |
| 实心飞轮 | 0.0623166667 | 0.1225 |
| 环形飞轮 | 0.1135166667 | 0.2249 |

它们质量相同，环把更多质量分配到远离 z 轴的位置，Izz更大。碰撞采用共同的外圆柱包络；环形网格用于表达外观，本试验没有接触，不把这个简化包络当作孔洞碰撞模型。

50 N·m施加0.001 s，角冲量0.05 N·m·s。初始静止、沿主轴纯转、没有其他力矩时：

```text
ω_solid = 0.05/0.1225 ≈ 0.4081633 rad/s
ω_ring  = 0.05/0.2249 ≈ 0.2223210 rad/s
500步自由转动 = 0.5 s
预计姿态增量约0.2040816、0.1111605 rad
转速之比 = 0.2249/0.1225 ≈ 1.835918
```

后续0.5 s没有继续施加50 N·m。姿态差的测量起止应遵循仪器报告，不把脉冲前、脉冲后与重置前的时间混在一起。一般随体方程为 `τ=Iα+ω×(Iω)`；本例由于沿主轴纯转，交叉项为零，才可直接用 Izz 做标量比较。[官方原生施力说明](https://classic.gazebosim.org/tutorials?cat=tools_utilities&tut=apply_force_torque)明确单次 GUI 操作只施加一个物理步。

两次姿态经 atan2 得到的是±π范围内的最短角差，多圈转动会发生混叠。本仪器同时检查分辨率：每个飞轮须有 `0.02≤|预测coast角|<2.8 rad`，且 `|预测ω|≥0.012 rad/s`，后者是当前0.002 rad/s绝对容差的6倍。默认和本课挑战均满足；这些界限属于当前两姿态采样方法，不限制 Gazebo 的物理旋转圈数。

环形挑战改为内半径0.2 m时，保持2 kg、R=0.35、H=0.08，Izz=0.1625，Ixx=Iyy=0.0823166667 kg·m²。同样角冲量下，角速度约0.3076923 rad/s、0.5 s姿态增量约0.1538462 rad。修改 parameters.json、world 中的三项主惯量后运行 `python3 lab.py rebuild-ring`，使外观与内半径一致；该命令只备份并重建网格，惯量由你按公式填写。随后 predict、重载、experiment，旧服务器不会自动采用新的惯性配置。

## 张量、坐标与有效性

`inertial.pose` 的平移定位 COM，旋转定位惯性坐标系 C；inertia 是关于 COM、在 C 中的矩阵。对于一般坐标变换，先用 `R I Rᵀ` 旋转表示；换到平行且偏置的原点，再用 `m[(d·d)E−ddᵀ]`。把关于脚底的惯量当成中心惯量，会重复或遗漏平行轴贡献。

三个对角数为正不足以保证一般矩阵正定；还需考虑非对角项及特征值。本课先按主轴对齐，主惯量均为正，同时满足各项不超过另外两项之和。diag(1,1,3) 的三个特征值为1、1、3，仍因1+1<3而无有效质量分布。正规三维物体满足严格的物理关系；理想薄片等退化极限可能出现三角等号，本课不使用零主惯量的理想点/线体。

所有数据先统一 SI：100 mm=0.1 m，1 kg·mm²=10⁻⁶ kg·m²，1 g·mm²=10⁻⁹ kg·m²。尺寸同比缩放 λ、质量保持不变时，惯量乘 λ²；若密度保持不变，则质量随 λ³、惯量随 λ⁵变化。质心、质量、惯量应来自同一物理模型。

[SDF 惯性坐标和符号定义](https://sdformat.org/spec/1.6/link/)、[Gazebo Math 有效惯性检查](https://gazebosim.org/api/math/6/classignition_1_1math_1_1MassMatrix3.html)和[OpenStax 平行轴与组合物体推导](https://openstax.org/books/university-physics-volume-1/pages/10-5-calculating-moments-of-inertia)可用于继续核对。

## 怎样复现实验与判断证据

predict 读取当前文件并检查配置。experiment 和应用“验收实验”先完成文件校验，再读取原暂停状态并暂停，推进一步、等待真实 stats 确认，以消耗历史 Wrench 队列；随后才 reset ALL，采集新的 stats 基线并核对实际模型及初始位姿，再开始正式定步测量。reset ALL 本身不会清除原生 Link 已排队的力/扭矩消息；排空步在报告中单记为 historical_input_drain，不计为正式脉冲。无效配置在任何 Transport 操作之前就被拒绝。

有效采样窗还要求预测落差≥0.02 m，以及塔的总观察时间 `(freefall_steps+tower_steps)×dt` 达到下界 `2√(1/a₀)+0.2 s`；a₀由高塔初始支点重力矩除以支点惯量估计。这是保守的仪器窗口，不是完整瞬态解，也不表示支撑投影可以预测完成倾倒时间。基准最低约1.686 s，g=6变式最低约2.100 s，当前2.7 s均足够；predict 的 instrument_limits 给出当前窗口、最低窗口和所需步数，量程不足在启动测量前拒绝。

整次试验只在开始重置一次，后续阶段不会把已落地箱子和已倾覆高塔重新归零。结束仅恢复原暂停状态，不恢复原来的 twist 或完整 state。

用 `python3 lab.py experiment --report measurements-baseline.json` 可保存一份实际报告；其中保留采样时刻的 pose、stats、实际步数与预测。若恢复为运行，飞轮仍会继续旋转，不能拿稍后的屏幕姿态代替报告中的采样姿态。

修改质量/惯量后保存个人文件，先 predict，再“重载项目”，最后运行仪器和验收。自动结果证明本课规定条件下的运动与参数相符；单位解释、COM坐标换算、投影判断和张量推导仍需要你独立说明。

2026-10-30 ikaros 真机报告中的基准实测为：两箱0.2 s均下落0.19718 m；低塔/高塔相对坡面法线倾角约3.7×10⁻⁷/1.5707968 rad；0.5 s观测得到两飞轮角速度0.408164/0.222322 rad/s，对应 Iω 为0.05000009/0.05000022 N·m·s，与输入角冲量0.05接近。另一次变式把 g 改为6 m/s²、两箱质量改为0.25/8 kg，两者均下落0.12060 m。实测来自实际 pose/stats，理论值由配置独立计算，不用固定基准数字替代新配置的验收。
