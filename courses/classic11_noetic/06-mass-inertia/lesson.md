# 质量、质心与惯性实验台

## 三个问题，三组受控比较

本课用一张实验台回答：重物是否下落更快？同样高、同样重的塔为什么稳定性不同？相同扭矩为什么不能让两个同质量飞轮获得相同转速？

三站分别只突出一个因素：同尺寸箱子的质量、同外形塔的质心位置、同外尺寸飞轮的质量分布。课程使用 Gazebo Classic 原生物理和 Transport，不需要 ROS、控制器或自己编译插件。实验工具负责定步施加输入、读取实际位姿和时钟；理论预测与服务器观测会分别输出。

## 先把物理量和坐标写对

| 量 | 本课单位 | 含义 |
| --- | --- | --- |
| mass | kg | 质量，决定平动的惯性大小 |
| 位置、质心坐标 | m | 必须说明相对哪个坐标系 |
| 力、力矩 | N、N·m | 力改变动量；关于质心的合力矩改变角动量 |
| 转动惯量 | kg·m² | 质量相对所选轴的分布 |
| 角速度、角加速度 | rad/s、rad/s² | 姿态变化率及其变化率 |
| 时间、物理步长 | s | 使用仿真时钟，不用终端命令的耗时替代 |

一个 link 的 `<inertial>` 包含 mass、pose 和 inertia。这里的 **COM（center of mass，质心）**是质量加权的位置：`c=Σ(mᵢcᵢ)/Σmᵢ`。均匀规则体的质心可与几何中心重合；内部配重会改变这个位置。

本课 `inertial.pose` 的前三数是质心相对 **link 原点**的位置，后三数定义质心坐标系 C 相对 link 坐标系 L 的方向。它不相对 visual 或 collision 的原点，也不直接等于世界坐标。改这段 pose 会改变质量属性，不会把外观或碰撞形状一起平移。[SDF 1.6 的 link/inertial 定义](https://sdformat.org/spec/1.6/link/)可用于逐字段核对。

惯性是对称张量，在 C 中写为：

```text
I_C = [ ixx  ixy  ixz ]
      [ ixy  iyy  iyz ]
      [ ixz  iyz  izz ]
```

选取**主轴**作为 C 的三条轴时，非对角项为零，对角项就是三个主惯量。一般坐标下非对角项可以非零；SDF 使用惯性矩阵本身的符号约定，例如 `ixy=−∫xy dm`，不能直接抄采用相反积惯量约定的软件输出。本课先把 C 与 link 主轴对齐，保持惯性 pose 的旋转为零。

## 先预测，再运行仪器

开始实验，在本课命令区执行“预测当前个人配置的三站结果”，等价于在实验终端运行：

```bash
python3 lab.py predict
```

它读取个人 world.sdf 与 parameters.json，检查配置并计算预测值，不证明当前服务器已加载这些文件。窗口出现时，箱子可能已经落地、高塔可能已经倒下；下一条仪器命令会重新建立初始条件。

运行“重置本课仪器并运行定量实验”；也可在终端执行下面的命令，同时把实际报告保存到个人练习：

```bash
python3 lab.py experiment --report measurements-baseline.json
```

仪器先校验全部文件，再读取原暂停状态并暂停，推进一步消耗已排队的历史力/扭矩消息，确认该步完成后才重置本课全部模型和仿真时间、采集真实 stats 基线。这个排空步不计入正式试验；单独 reset ALL 不会清除原生 Link 的 Wrench 消息队列。核对已加载模型后，三个正式阶段之间不再次重置。

predict 的 `instrument_limits` 会显示有效采样窗：自由落体预测落差至少0.02 m；塔的总观察时间按高塔初始支点力矩与惯量估算下界，默认最低约1.686 s，基准前两阶段共2.7 s满足要求。采样窗不足时在操作 Gazebo 前就拒绝试验。这个窗口用于保证测量分辨率和观察时间；支撑投影判据不预测完成倾倒的时刻。

运行期间不要同时拖动模型、点击继续/单步/重置，或另发施力命令。仪器保留试验结果，最后仅恢复进入仪器前的暂停/继续状态，**不恢复原来的位姿、速度或完整物理状态**。若恢复为继续运行，物体还会继续运动，JSON 留存的是采样时刻的结果。需要重新开始时重跑仪器或重载项目。

## 第一站：不同质量的自由落体

fall_light、fall_heavy 都是边长0.2 m的均匀箱子，中心初始高度2 m，质量分别0.5、5 kg。没有空气阻力，在接触地面之前，`ma=mg` 给出相同的下落加速度 g。较大的重力与较大的平动惯性同步增加。

基准步长0.001 s，第一阶段200步，即0.2 s。连续模型预测下落 `g t²/2=0.1962 m`；本课固定步进的离散预测为0.197181 m，中心约1.802819 m。这个小差别来自积分步进；比较质量时应看两箱在同一实际仿真时间的位移，而不是要求连续公式的每位小数与数值求解完全相等。

先写下两箱位移应相同的预测，再看仪器实际 pose、步数和时钟。测量窗口止于空中，不能拿落地后的弹跳或穿透修正去解释自由落体规律。

## 第二站：质心投影与倾覆

tower_low、tower_high 外包均为0.3×0.3×1.2 m，总质量5 kg；模型用1 kg均匀柱与4 kg内部配重表示质量分布。配重从靠近底部移到靠近顶部，外包碰撞保持相同。

**本课塔的 link 原点在几何中心，距脚底0.6 m。**配重 visual 中心在 link.z=−0.48、+0.48 m，对应离脚底0.12、1.08 m。质量加权得到 COM 离脚底0.216、0.984 m，因此写入 `inertial.pose.z` 的是 **−0.384、+0.384 m**。不要把离脚底的高度直接填进 link 相对坐标。

塔随20°斜面倾斜。在足够摩擦抑制滑动、缓慢平衡的条件下，检查**重力作用线与支撑面的交点**：支撑半宽 b=0.15 m，交点相对底面中心的坡向偏移量为 `h tan20°`。低塔约0.0786 m，仍在支撑区；高塔约0.3581 m，越过支撑边，无法维持该初始静止平衡。

看仪器后续阶段的姿态：低塔应保持接近初始斜面方向，高塔应明显倾覆。投影判据判断静态平衡的可能性，不直接给出倾覆速度，也不保证任意撞击、摩擦或坡角下都稳定。塔的本地高度与世界 z 也要通过其倾斜 pose 区分。

可用 Gazebo 的 View → Center of Mass / Inertia 调试显示核对质心位置和惯性方向；这些调试图形不代表碰撞形状。[官方惯性参数教程](https://classic.gazebosim.org/tutorials?tut=inertia)介绍了这种可视检查。

## 第三站：相同角冲量，不同转速

flywheel_solid 与 flywheel_ring 都为2 kg，外半径0.35 m、轴向长度0.08 m；环的内半径为0.32 m。实心盘与环形质量分布的中心主惯量不同：`Izz=0.1225` 与 `0.2249 kg·m²`。它们使用相同圆柱碰撞包络，环的外观由本地网格表示；此站关闭重力且不安排接触，重点比较转动响应，不检验孔洞碰撞。

前两阶段结束后，飞轮仍保持静止。仪器给两者沿 link.z 各施加 **50 N·m、仅一个0.001 s物理步**的纯力矩。角冲量为 `Jτ=τΔt=0.05 N·m·s`，随后500步、0.5 s不再施力。预测角速度约0.40816、0.22232 rad/s；仪器用脉冲后自由转动的实际姿态增量除以实际仿真时间，估计这段平均角速度。0.5 s是后续观测时间，不是扭矩持续时间。

本仪器用两次姿态的最短角差测量，要求每个飞轮的预测观测角增量满足 `0.02≤|Δθ|<2.8 rad`、预测角速度绝对值至少0.012 rad/s，以兼顾分辨率和跨±π混叠余量。参数超出量程时先拒绝试验；这是采样方法的适用范围，Gazebo 本身仍支持连续多圈转动。根据 instrument_limits 提示调整步数、扭矩或质量时，也要同步核对物理配置。

这里初始静止、沿主轴纯转、没有其他力矩，所以可以用 `τz=Izz αz`、`Δωz=Jτ/Izz`。在随体坐标中，一般刚体方程还包括陀螺项：

```text
τ_C = I_C α_C + ω_C × (I_C ω_C)
```

任意三维旋转不能直接把三个轴都独立套成标量公式。Classic 原生 Apply Force/Torque 的 GUI 每次点击也仅作用一个物理步，暂停时多次提交还会累积；正式比较统一使用本课仪器。[官方施力界面说明](https://classic.gazebosim.org/tutorials?cat=tools_utilities&tut=apply_force_torque)提供了进一步操作入口。

2026-10-30，ikaros 的 Gazebo Classic 11 基准实测：两箱200步、0.2 s均下落0.19718 m，对照离散预测0.197181 m；低塔、高塔相对坡面法线的倾角约3.7×10⁻⁷、1.5707968 rad；飞轮自由转动0.5 s估计角速度0.408164、0.222322 rad/s。这些是当次实际采样，与前面的理论预测分开记录；改变参数后应重新预测和测量。

## 参数的物理一致性

对于本课有体积的刚体，质量应大于零，惯性矩阵应对称正定，即任意非零方向 v 都满足 `vᵀIv>0`。三个主惯量还应满足 `I₁+I₂≥I₃` 及循环形式。例如 diag(1,1,3) 虽然正定，却违反物理三角不等式，不能作为真实质量分布的惯性。通过这些检查也不自动证明数据与给定外形、COM 相符。[Gazebo Math 的惯性有效性定义](https://gazebosim.org/api/math/6/classignition_1_1math_1_1MassMatrix3.html)同时检查主惯量与三角不等式。

把惯性移到平行轴时使用 `I_O=I_C+m[(d·d)E−ddᵀ]`，d 是两原点间向量、E 是单位矩阵。若还改变坐标轴方向，需要旋转变换 `I_L=R_LC I_C R_LCᵀ`。SDF 的 inertia 仍填写关于质心、在 C 中表达的中心惯性；不要把关于脚底或 link 原点的矩阵直接填入。

不了解矩阵、特征值或主轴？可从[MIT 线性代数课程](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)补充背景；平行轴与组合物体的基础见[OpenStax 转动惯量计算](https://openstax.org/books/university-physics-volume-1/pages/10-5-calculating-moments-of-inertia)。

## 独立挑战与验收

1. 在个人 world.sdf 中把 fall_heavy 质量从5改为10 kg，尺寸不变；均匀箱的三个主惯量同步乘2。先 predict，再“重载项目”，再运行实验。预测自由落体加速度不变。修改文件不会自动改变旧服务器里的物理属性。
2. 保持飞轮外径、厚度和总质量，修改个人 parameters.json 的 `ring_inner_radius_m`：0.32→0.2。按圆环公式重新计算并修改 world 中 flywheel_ring 的三项主惯量；在当前实验终端运行 `python3 lab.py rebuild-ring` 同步重建环形外观。此命令会备份旧网格，**不会自动修改 world 的惯量**。然后 predict、重载项目、运行实验，预测环的转速会向实心盘靠近。可在“编辑练习文件”的同一编辑器中打开旁边的 parameters.json。
3. 计算题：若把低塔配重离脚底高度改为0.3 m，COM、支撑投影和中心惯量应怎样重新计算？先做纸面预测，参考答案提供推导；本题不要求建立任意塔参数化工具。
4. 记录飞轮原来的正确惯量，临时将一组对角项改成1、1、3，只运行 predict，观察三角不等式错误；恢复正确配置后再重载。可再验证一个负主惯量会被正定检查拒绝。

“验收实验”先校验当前个人文件，暂停后推进一步排空历史输入，再重置本课、核对实际服务器属性与初始位姿，随后运行定量试验；同样仅恢复暂停状态，试验后的物理结果会保留。验收过程中不要操作场景。请对照输出区分理论预测、实际采样与容差，而不是只看 PASS；可通过“查看实验记录”和只读参考页复盘。

信息流是：**个人 SDF/参数 → 单位与惯性一致性检查及预测 → 读取原暂停状态并暂停 → 推进一步排空历史输入并确认完成 → 重置本课与采集 stats 基线 → 核对实际已加载模型的质量/COM/惯量/几何/初始位姿 → 已知物理步与力矩输入 → 真实 pose/stats 采样 → 对比并保留结果 → 恢复原暂停状态。**

| 现象 | 检查方向 |
| --- | --- |
| 质量改了，predict 报均匀箱惯量不符 | 同尺寸、同均匀分布时，惯量应与质量同比变化 |
| 高低塔质心落在错误位置 | 核对 link 原点；本课±0.384是局部坐标，0.216/0.984是离脚底高度 |
| 两箱下落不同 | 是否处于同一采样时刻、仍未接触、没有额外输入；是否实际重载了修改 |
| 飞轮转速与预期差很多 | 检查 kg·m²、物理步长、脉冲次数、轴方向，以及是否混入GUI施力 |
| 重跑后其他物体状态变了 | 仪器会重置本课全部模型和仿真时间，这是试验初始化流程 |
| predict 通过但实际验收失败 | 文件预测不等于服务器已加载；保存后重载，核对实际模型数据 |

## 实时模型位姿的读取流程

验收中的模型位姿优先从持久Classic SDK辅助进程读取：同一Python进程、master与世界复用一个连接；一组请求发布器和响应订阅器保留到辅助进程退出。工具发送只读`entity_info`，检查响应ID、类型、模型名及实际`Model.pose`，返回真实位置和单位四元数。RPY由当前SDK的四元数Euler转换产生，沿用Classic的奇点约定；位置没有用保存SDF或理论预测补齐。

请求前后还分别等待新的WorldStatistics，保留接收顺序与源时间，二者不构成原子物理快照。反向响应通道初次发现较慢时，在同一总截止时间内最多再发一次只读查询，并使用新ID拒绝迟到旧响应。SDK缺失或不在精确支持范围内时，会在标准错误流说明原因并保留原有CLI读取，基础课仍可只安装运行时；已支持SDK上的编译、协议或查询失败会直接报告，不静默换路重试。原有模型移动和世界控制的单次发布规则、接触实验及物理求解保持原流程。
