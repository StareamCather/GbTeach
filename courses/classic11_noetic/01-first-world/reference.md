# 首课参考答案：0.8 m 方块

此页只供阅读，不会覆盖你的练习文件。先独立预测，再对照答案；应用中编辑的仍是自己的工作副本。

## 预测与计算
保持地面位于 z=0，方块中心、碰撞几何中心和质量中心重合，方块无初始转角。边长 a=0.8 m，则底面在 `z_center - a/2`。稳定接触后底面约为0，所以：

`z_center = a/2 = 0.4 m`

初始中心高度4 m决定下落行程，最终高度由接触几何决定。忽略空气阻力、接触发生前，理想自由落体满足 `z(t)=z0-g*t²/2`；质量不会使理想自由落体的重力加速度变大。Gazebo 的离散时间积分和接触约束会带来数值误差，因此实测值要与容差比较。

## 质量和惯性
均匀长方体在质心、沿几何主轴的惯性矩阵为对角形式。质量 m、长宽高 sx/sy/sz 的单位分别为 kg、m，惯性单位为 kg·m²：

`Ixx = m*(sy²+sz²)/12`

`Iyy = m*(sx²+sz²)/12`

`Izz = m*(sx²+sy²)/12`

均匀立方体可简化为 `Ixx=Iyy=Izz=m*a²/6`，交叉项为0。本例 m=1 kg、a=0.8 m，所以三项都约为0.1066666667 kg·m²。基准0.5 m方块的三项约为0.0416666667 kg·m²。改变尺寸后同步更新惯性，才能保持“均匀实体”这一物理假设。

正文中边长1 m的单变量例题同样保持质量1 kg：两处 box size 均为 `1 1 1`，三个对角惯性均为 `1/6≈0.1666666667 kg·m²`，最终中心高度预测为0.5 m，初始中心高度仍为3 m。它用于和基准方块比较尺寸的影响；下面的0.8 m、4 m配置是独立挑战。

验收按这些公式核对三个对角项，允许约0.01%的相对舍入误差，并要求交叉项接近0。均匀方块只改尺寸、未更新惯性时会被拒绝。落地高度正确，不能证明描述文件中的每个参数都正确。

## 对照修改以下位置
1. `falling_block` 的模型 pose 改为 `0 0 4 0 0 0`。
2. collision 内 box 的 size 改为 `0.8 0.8 0.8`。
3. visual 内 box 的 size 同样改为 `0.8 0.8 0.8`。
4. 质量保持1.0，三个对角惯性按上式更新。其余地面、重力、物理步长不变。

下面是该模型的完整参考片段，应放在原 world 内。不要将它粘贴成第二个同名模型：

```xml
<model name="falling_block">
  <static>false</static>
  <pose>0 0 4 0 0 0</pose>
  <link name="body">
    <inertial>
      <mass>1.0</mass>
      <inertia>
        <ixx>0.10666666666666667</ixx>
        <iyy>0.10666666666666667</iyy>
        <izz>0.10666666666666667</izz>
      </inertia>
    </inertial>
    <collision name="collision">
      <geometry>
        <box><size>0.8 0.8 0.8</size></box>
      </geometry>
    </collision>
    <visual name="visual">
      <geometry>
        <box><size>0.8 0.8 0.8</size></box>
      </geometry>
      <material>
        <ambient>0.12 0.55 0.95 1</ambient>
        <diffuse>0.12 0.55 0.95 1</diffuse>
      </material>
    </visual>
  </link>
</model>
```

## 重新运行与解释结果
通过“编辑练习文件”修改并保存工作副本，点击“重载项目”，然后先暂停并重置模型状态。应能查询到中心初始高度4 m；继续运行后，稳定中心高度应约为0.4 m。每次重载后都重复这一观察准备。运行自动验收时，它会按当前 box 高度计算预测值，而不是硬编码基准0.25 m。验收抬升高度只是为重复测量创建统一起点，不能用它代替检查你配置的4 m初始高度。

如果只改文件却没有重启，服务器仍使用原来的0.5 m碰撞体，测得约0.25 m，验收就会报告配置预测与实时测量不符。这个反例用于区分“编辑了描述文件”和“运行世界已经重新加载”。

不了解惯性参数？[查看 Gazebo 官方惯性教程](https://classic.gazebosim.org/tutorials?tut=inertia)。
