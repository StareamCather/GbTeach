# 附加专项48 · MLP强化学习与真实滑块

第47课给每个观察配上专家力标签。本课只给滑块运动结果打分，让一个小型MLP通过真实Gazebo交互更新策略。先修09课滑动关节、10课PID和47课的网络前向与反向传播。

一个**策略**规定观察到状态后怎样选动作。一次**转移**包含动作前状态、动作、真实动作后状态及奖励。一段**回合**从一次重置开始，包含固定数量的转移。REINFORCE根据当前策略采集回合，用累计奖励与动作对数概率的梯度更新参数。与第47课相比，训练数据和参数更新方向都由本轮交互决定。[Williams的REINFORCE原论文](https://link.springer.com/article/10.1007/BF00992696)

## 从网络输出到真实力

质量1kg的滑块沿X轴运动，关节粘性阻尼0.4N·s/m，行程±1.2m，施力界限±8N。位置目标为0。2→12→1的tanh MLP接收[−x,v]，即位置误差的米数与速度的米每秒数。线性输出给出潜在力均值μ，μ、raw与σ都采用牛顿尺度。

```text
epsilon ~ Normal(0, 1)
raw = mu + sigma * epsilon
sigma = 1.4
F = 8 * tanh(raw / 8)    # N
```

固定标准差描述的是变换前的采样分布。相同观察可以产生不同动作，让策略收集多种后果。tanh平滑压缩大幅值，实际力落在执行器边界内。每次采样保留raw、μ和实际力F。高斯概率与score使用raw，奖励中的动作代价使用F。将F直接填回原高斯公式会计算另一个数值。力接近边界时，进一步改变raw对F的影响会变小。

## 奖励如何分给动作

物理引擎先施力并推进20个1ms步，然后读取位置x_next与速度v_next。本课对这次转移赋予奖励。

```text
r_t = -(x_next² + 0.03 * v_next² + 0.001 * F²)
```

三项分别衡量位置偏差、剩余速度和施力代价。系数把不同物理量组合成任务评分。因为这里的奖励非正，−4比−10高。预测x_next=0.4m、v_next=0.5m/s、F=2N时三项分别贡献多少代价，然后算出r_t=−0.1715。想一想向目标加速时，当前速度惩罚增加与随后位置误差减小如何同时发生。

训练目标J是固定40步回合中从起点计时的期望折扣回报，γ=0.98。定义从第t步开始计时的回报G_t。

```text
J(theta) = E[sum_t gamma**t * r_t]
G_T = 0
G_t = r_t + gamma * G_(t+1)
```

倒序计算G_t可一次走完回合。以r=[1,2,3]、γ=0.5为例，G=[2.75,3.5,3]。当前动作能改变当前及未来结果，因此计算它的梯度权重时只保留从t开始的奖励。对当时状态和历史取条件期望，score的均值为零，已经发生的奖励乘score后在期望中抵消。G_t从当前时刻重新计时，所以还要乘γ^t，把第t步及未来奖励换回从回合起点计时的折扣。例如t=1时，γG_1=0.5×3.5=1.75，正好等于0.5×2+0.5²×3。两处折扣各自对应一个时间原点。[策略梯度与因果性推导](https://spinningup.openai.com/en/latest/spinningup/rl_intro3.html)

## 从分数到参数更新

固定σ时，单步高斯对数概率为−(raw−μ)²/(2σ²)加常数。把已经采到的raw固定，求对μ的导数，得到score=(raw−μ)/σ²。若一次向正方向偏离均值的动作取得较高相对回报，正score和正相对回报相乘，就给出提高均值的贡献。对均值的导数再经MLP反向传播到参数。Gazebo提供实际转移和奖励。

每轮采4个40步回合，整个批次用同一份参数，收完才更新。这是on-policy采样。第一轮的baseline为0，以后使用**上一批**同时间下标的G_t均值。给定以往训练记录，baseline在本轮采样前已经固定。在每个时刻score对当前动作的条件期望为零，因此减去它保持期望梯度，可减少部分波动。上一批策略变化较大时，降方差效果可能有限。实现把当前批次的均值留给下一轮。

```text
advantage_estimate = G_t - baseline_t
weight_t = gamma**t * advantage_estimate * (raw_t - mu_t) / sigma**2
```

把weight_t作为网络输出的梯度信号。代码按固定批次中的转移数取平均，相当于把每回合梯度总和的平均再除以回合长度40，保留同一方向并改变步幅。参数以0.035的学习率沿梯度上升更新。全局梯度范数超过5时，所有分量按同一比例缩小。这项裁剪控制参数更新幅度，动作边界由前面的tanh负责。两层网络、固定探索尺度和短回合让每个环节都可以单独复算。[策略梯度baseline推导](https://spinningup.openai.com/en/latest/spinningup/rl_intro3.html#baselines-in-policy-gradients)

## 文件与运行

| 文件 | 作用 |
|---|---|
| `world.sdf` | 轨道、滑块、关节和1ms物理步长 |
| `plant.cc`、`plant.py` | 会话私有socket、真实施力、步进和读回 |
| `network.py` | MLP前向、显式反传、梯度裁剪和参数更新 |
| `lab.py` | 策略采样、奖励、回合收集、训练与配对评价 |
| `learner.py` | 回报递推与高斯score填空 |
| `reference.py` | 参考实现，供演示与自动验收使用 |
| `results/run-<uuid>/` | 本次运行的轨迹、权重和报告 |

开始实验时，平台准备个人副本并编译原生插件。原生后台线程在暂停的世界请求步进，物理回调施力。每次正常动作核对原生迭代数增加20及对应仿真时间，另一次状态请求读回物理更新完成时保存的快照。重置由物理线程设置起点并推进一个辅助物理步，下一动作以真实读回为输入。每次训练更新发生在物理步之间。结束时确认恢复进入命令前的暂停状态。如果请求超时且结果未知，连接关闭，本次流程结束。不要在训练中用GUI继续或单步，也不要重发结果不明的命令。[Gazebo Classic World::Step源码](https://github.com/gazebosim/gazebo/blob/gazebo11/gazebo/physics/World.cc#L807)

```bash
python3 lab.py ready
python3 lab.py demo
```

默认运行6轮更新，每轮160次真实训练转移，可用`--updates`指定1至30轮。初始MLP种子为19，训练随机流种子为29。训练回合从两侧交替开始，起点绝对值在0.3至0.7m之间抽取，每回合另取一个噪声种子。更新前和更新后分别从−0.55m、+0.55m运行120步。对同一个起点，两次评价使用相同种子的独立评价随机流，重放同一串ε。两个起点分别使用2047和2048。训练采样使用自己的随机流。这样两次面对同一组探索噪声，便于配对比较。策略改变会使μ、施力和后续状态改变。配对固定的是起点和随机输入。

先看每个起点的前后差、动作范围及x/v变化，再看平均回报。120步评价分别报告折扣与未折扣回报，和40步训练目标分开读。横向比较应保持时域与评分公式一致。负回报变得更接近零意味着这次评价代价下降。固定两条起点和有限种子下，平均回报可能上升或下降。参数改变、梯度有限、真实轨迹和配对评价是实现证据。若要研究稳定性或普遍改进，需要更长时域、更多起点和独立种子。

默认共1440次20步动作和28次1步重置，预期推进28828个物理步。把实际步数、回合数和`pause_restoration`与本次报告核对。

每次运行保存一个独立目录。`on-policy-trajectories.jsonl`每行对应一个回合，`phase`区分更新前评价、训练和更新后评价。`rows`保存ε、μ、raw、F、奖励、动作前后原生状态及另一次状态请求的读回。`policy-000.npz`保存初始策略，后续编号对应每次更新。最终评价前从最后一份权重文件重新加载策略。

`report.json`保存本次配置和结果。`history`里的`baseline_used`和`baseline_for_next_batch`可以用来追踪基线来源。`evaluation.paired`按起点保存前后回报及差值，顶层`evaluation_improved`依据两对的平均折扣回报。最近一次报告还写到`results/reinforce-report.json`和`build/verification.json`。

## 两处填空

在个人`learner.py`填写两处关键表达式。第一处从末步向前计算G_t，先在纸上核对三项例子。第二处写固定σ的高斯均值score。提示是先展开log概率的平方项，对μ求导，然后用NumPy对数组逐项计算。这里σ是标准差，所以分母是方差。

```bash
python3 lab.py student-check
python3 lab.py student
```

第一条仅验证局部代数。第二条用个人实现重新采集与更新，并完成物理评价。参考演示与代数检查保持`assignment_pass=false`。个人运行按报告里的实际完成状态记录。

## 单变量实验与挑战

先预测再运行。比较`python3 lab.py demo`与`python3 lab.py demo --updates 12`，保留各自独立结果。对同一起点和评价噪声查看初始策略一致性、配对回报差和末段运动。训练更久会产生更多交互，也可能增大后续更新的波动。用几个额外的独立种子重复比较，记录每对结果的差及其散布。

可单独修改施力代价系数，再在统一的评价指标下比较轨迹。若同时修改评价公式，新旧奖励数值代表不同评分规则，应另用一份固定公式重算轨迹。也可只改变训练用的探索强度，再看实际力分布、轨迹覆盖和梯度范数。保持评价设置一致，记录你改变了哪处参数。

若滑块冲到轨道一端，先核对误差、raw与实际力的符号，再检查梯度上升方向和尺度。若梯度很小，检查σ²、G_t、baseline与γ^t是否按步对齐。若读回步数异常或socket超时，查看本课日志并重新启动实验。绘制x、v、F对仿真时间的曲线，可以分辨低回报来自大幅偏移、残余速度还是频繁大力控制。

独立挑战可实现只用既往数据拟合的状态baseline，或研究怎样适配47课策略的输入尺度与输出变换，再和随机初始化做相同交互预算的对照。报告初始化、每个种子、训练步数以及保留的固定评价条件。
