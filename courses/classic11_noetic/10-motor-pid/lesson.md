# 关节电机与PID：转矩、转速和位置

## 给一个目标，为什么还要观察误差

给转子恒定转矩，不等于命令它保持某个转速；给关节一个位置目标，也不等于把它直接放到那个角度。本课用一个绕Z轴旋转的均匀转子，对照恒转矩、转速P/PI、位置P/PD和输出饱和，认识目标、反馈、动力学与执行器能力之间的关系。

第09课选做用耦合状态反馈稳定小车倒立摆；本课用Gazebo Classic 11原生JointController的PID跟踪单关节目标。两种方法的输入状态、控制目标和增益含义不同，不能把LQR的向量增益直接填进PID的P/I/D。课程会自动准备控制与记录工具，不要求先写插件、C++或ROS节点。

## 转矩怎样变成转速

标称转子质量M=1 kg、半径R=0.25 m，绕中心Z轴惯量J=MR²/2=0.03125 kg·m²。关节黏性阻尼b=0.1 N·m·s/rad；设正向控制转矩u、反向负载转矩幅值τ_L≥0，则简化模型为：

```text
J dω/dt = u − bω − τ_L
dq/dt = ω
```

q用rad，ω用rad/s，u与τ_L用N·m。转轴竖直且过质心，重力不产生绕Z轴的转矩；指针、底座与刻度仅作visual参照，不增加转子惯量或接触。本课“电机”是理想关节转矩执行器与机械转子的抽象，不显式模拟电压、电流、反电动势、齿轮传动或热学。愿了解电气模型，可看[UMich直流电机建模](https://ctms.engin.umich.edu/CTMS/?example=MotorSpeed&section=SystemModeling)，不是完成本课的先修要求。

从静止施加0.4 N·m、无额外负载时，连续模型预测最终ω=0.4/0.1=4 rad/s，机械时间常数J/b=0.3125 s；转速逐渐接近4，而非瞬间跳到4。这是理论预测，真实关节状态与仿真时钟仍需实际读取。

## P、I、D分别使用哪种信息

**反馈误差**比较当前值与目标。Classic 11此处采用 `e=实际值−目标值`，控制输出使用整体负号；很多教材用目标减实际、公式前为正，两者不可只抄一半。原生离散PID可按下列顺序理解：

```text
e = y − r
积分累计 += e × h
P项 = Kp × e
I项 = Ki × 积分累计，并限制在Imin与Imax之间
D项 = Kd × (e−上次e)/h
u_raw = −P项 −I项 −D项
u = 限制u_raw到命令转矩范围
```

P根据当前偏差加力；I累计持续偏差，使恒定负载所需的转矩可以在误差接近0时仍存在；D根据误差变化提供额外作用。它们并非“越大越好”：观察对象、采样步长、饱和和输入变化都会影响结果。不了解PID，可先看[UMich PID基础教程](https://ctms.engin.umich.edu/CTMS/?example=Introduction&section=ControlPID)。

例如实际转速0、目标4 rad/s时，原生误差e=−4 rad/s；Kp=0.4的P输出是+1.6 N·m，正好向正方向加速。负误差不等于反馈接反，先核对误差定义与公式符号。

| 控制对象 | Kp单位 | Ki单位 | Kd单位 |
| --- | --- | --- | --- |
| 位置q，误差rad | N·m/rad | N·m/(rad·s) | N·m·s/rad |
| 转速ω，误差rad/s | N·m·s/rad | N·m/rad | N·m·s²/rad |

同样的增益数字不能脱离受控量和单位比较。Imax/Imin限制的是**积分项对输出的贡献**，本转动关节中单位为N·m，不是误差积分本身的单位。

## 六个对照分别回答什么

| 对照 | 主要问题 | 标称理论判断 |
| --- | --- | --- |
| 恒转矩0.4 N·m，1 s | 不闭环时转速怎样建立 | 无负载最终4 rad/s，但1 s相位只到预测约3.837 rad/s |
| 转速P，6 s，目标4 rad/s | 只用当前速度误差够不够 | 有黏性阻尼就需要持续转矩，通常留下误差 |
| 转速PI，6 s，同一目标与负载 | 积分怎样提供稳态转矩 | 输出能力足够时可抵消恒定负载的速度偏差 |
| 位置P，3 s，目标0.8 rad | 只有位置误差会怎样振荡 | 惯量与阻尼决定暂态，不能只看最后到达目标 |
| 位置PD，3 s，同一目标且无负载 | D怎样影响暂态 | 固定目标期间等效增加阻尼，但目标阶跃会产生微分突跳 |
| 低转矩上限速度PI，6 s | 控制器能否克服执行器限制 | 上限0.35 N·m、反载0.2 N·m时无法维持4 rad/s |

速度P采用Kp=0.4，PI采用独立Kp=0.4、Ki=0.8，积分项限值±0.8 N·m；正常命令上限±2 N·m。三个速度相位都在各自t=2 s起施加反向负载0.2 N·m；维持4 rad/s需 `bω+τ_L=0.6 N·m`。P的连续稳态预测约2.8 rad/s，而PI可用积分输出补足转矩；低上限0.35 N·m时，理想饱和稳态只能约1.5 rad/s，继续增大Ki不能创造缺少的执行能力。

位置P的Kp=2，PD再加Kd=0.35。无恒定负载时，到达静止位置所需的阻尼转矩为0，因此位置P可以有零稳态误差；不能由速度P的偏差推断“所有P控制都必有相同偏差”。比较位置曲线时要同时看超调、振荡和收敛过程。

## 两个容易被曲线掩盖的实现细节

**微分突跳。** 此版原生D对误差差分，参考值突然变化也会进入D项。若清零后首个有效步h=0.001 s，位置目标从0跳到0.8 rad，Kd=0.35，则D对输出的代数贡献可达+280 N·m，再被命令上限截断。这是带明确初态和步长条件的预测，不把“D总能平滑动作”当作保证；真实首步以记录为准。

**积分项限幅与输出饱和不同。** I项可被夹到±0.8 N·m，最终命令又可被夹到±0.35 N·m；后者饱和时，原生实现不会因此自动停止积分。有限I项保护不等于完整的、感知执行器饱和的抗积分饱和设计。观察低上限相位，先判断可用转矩是否足够，再讨论参数。

各对照必须清除旧目标和PID内部历史，不能让上一次积分积累污染下次比较。Classic的JointCmd.reset只移除目标/前馈记录，完整JointController::Reset还会重置PID误差历史；本课工具负责按对照初始化。精确行为可核对[11.15.1原生PID](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/common/PID.cc)与[JointController](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/physics/JointController.cc)。

## 文件与真实运行流程

```text
个人练习目录/
  parameters.json  本课唯一调参入口
  world.sdf        固定转子、关节与测量工具，验收保持原样
  config.py        参数与固定模型约束检查
  lab.py           读取、运行单相位与整套实验
  instrument.py    实验请求、真实记录与比较
  motor_lab.cc     已提供的原生控制/测量工具
  prepare.py       自动准备工具，无需学生编写插件
  verify.py        六相位验收
```

“编辑练习文件”默认打开world.sdf。本课应使用课程命令的参数编辑入口，或在实验终端运行 `gedit --new-window parameters.json`。先保留固定模型，只调当前实验参数；`python3 lab.py check-config`可在个人练习目录离线校验参数，不启动仿真，但不代表控制性能已经通过。保存后必须重载项目，才能由服务器使用新参数。不要修改课程安装目录中的模板。

运行信息流为：**个人参数与固定模型检查 → 在相位边界建立真实初始位姿、零速和累计角零位，清理旧模式/PID历史 → 设置原生力矩或PID目标 → 每个0.001仿真秒由原生控制器更新并施加力矩/独立负载 → 保存实际PID状态与同一步前后关节状态 → 依据实际时间与预测比较 → 清除目标并确认原pause。** 工具不重复调用一次原生更新，也不靠持续修改速度或角度制造跟踪结果。

默认开始后自动运行一次25仿真秒的六相位演示，随后清除控制目标，转子按阻尼自然减速；它不是无限循环，也不是零速主动制动。若窗口出现时已错过首段，可用run命令单独重播。每相位开始才初始化角度/角速度和PID，期间只通过真实转矩驱动。

## 引导实验：先看一个相位

1. 开始课程，等待工具准备。运行 `python3 lab.py inspect` 核对当前实际参数、模型、配置指纹及相位状态；演示完成不等于新配置已经验收。
2. 运行 `python3 lab.py run torque`，观察从静止到1 s的真实角速度，与连续模型约3.837 rad/s的预测比较。角度和角速度必须分开读；本课原生关节角可包含累计圈数，而指针朝向只确定模2π的角，不能看到指针归零就认定关节累计角为0。
3. 分别运行 `python3 lab.py run speed-p` 与 `python3 lab.py run speed-pi`，比较t=2 s加负载前后的转速、误差、控制输出与积分贡献。相位时间相对本次开始计，不要求世界时钟归零。
4. 分别运行 `python3 lab.py run position-p` 与 `python3 lab.py run position-pd`，比较超调、振荡与收敛，同时查看首个有效PID更新及输出饱和，不把D突跳漏掉后再称动作处处更平滑。
5. 运行 `python3 lab.py run saturation`。先计算维持目标所需的0.6 N·m，再解释为什么低上限不能达到4 rad/s；“偏差存在”在这里恰是应当观察的物理结果。
6. `python3 lab.py demo`显式重跑六相位。点击“验收实验”也会取得全部六相位的真实结果，不因默认演示刚结束就跳过当前配置检查；期间勿拖动模型、并行发送控制命令或编辑文件。

原始记录将每一步前的q/ω、PID误差/GetCmd、独立负载与推进后的q/ω配对，连同步长和实际世界时钟保存。比较同一步PID时使用对应的步前量，不能把推进后刚变化的速度回代到先前误差后误判控制器多算了一拍。SDK输入力矩也不是支座反作用力测量。标准speed-pi相位不仅要求末窗平均速度接近目标，还要求误差RMS≤0.02 rad/s，避免正负振荡在平均时抵消；低上限相位另按不可达的平衡速度判定。末态统计、首次D突跳和低上限都必须由原始记录支撑，不能把理论曲线填入实测字段。

## 单变量挑战：只改速度P的比例增益

记录基准后，只把parameters.json中的speed_p_kp从0.4改为0.8；PI及饱和相位使用的独立增益保持原值。先预测，再保存、check-config、重载、inspect并重跑speed-p，最后进行六相位验收。

有0.2 N·m反载时，连续稳态预测由2.8变为约3.333333 rad/s，误差从1.2减至约0.666667 rad/s；没有变成精确4。初始静止时未限幅P请求也会由1.6变为3.2 N·m，触及2 N·m命令上限，因此不能把整段暂态都当成未饱和一阶响应。比较当前误差、真实暂态与饱和，不由一个相位的结果推断“所有PID参数增大都更好”。完整推导和重置语义见独立只读参考，不覆盖个人参数。

## 一次正式观测：2026-10-30，ikaros

Gazebo Classic 11.15.1中，基准六相位取得25,000行真实1 ms记录。恒转矩t=0.2 s时，实际ω=1.892994 rad/s、q=0.210332 rad，连续解分别为1.890830 rad/s、0.209116 rad；小差异来自当前离散仿真与连续模型的区别。负载后速度P末窗均值为2.800000 rad/s，只把speed_p_kp改为0.8后为3.333333 rad/s；PI的目标误差RMS为0.001234 rad/s。位置P/PD目标方向峰值分别为1.221075、0.801074 rad，PD首步原始请求281.6 N·m被截为2 N·m；低上限PI末窗速度为1.500040 rad/s，控制输出0.35 N·m、原生I项−0.8 N·m，符合“积分已积累、执行能力仍不足”的判断。

同次正式检查还从正在转动的多圈状态切到恒转矩相位，确认新相位真实q、ω均为0后才推进；这只是相位边界初始化，运动中仍按力矩求解。这些数值是固定模型、参数和步长下的仿真观测，不能作为真实电机精度保证；更完整的预测/观测对照在只读参考页。

## 验收与排错

| 现象 | 优先检查 |
| --- | --- |
| 恒转矩1 s还没到4 rad/s | 4是稳态极限；本相位有限时长，比较实际时间的瞬态预测 |
| 速度P稳定但有偏差 | 先核对阻尼/负载所需转矩与P稳态公式，不立即归咎求解器 |
| PI仍达不到目标 | 输出及I项范围是否足够，低上限相位本来就不可达 |
| PD第一有效步触及上限 | 原生D对误差差分，目标阶跃可产生微分突跳 |
| 只发reset消息后结果依赖上次实验 | 消息删除目标不等于清除PID内部积分历史，使用本课初始化工具 |
| 参数已保存、服务器仍旧 | 重载并核对实际参数/指纹，不能以磁盘文件代替运行配置 |
| 停止演示后还在转 | 清除控制后会自然滑行减速，不是主动制动或继续跟踪 |

这些有限相位检验当前标称模型与原生实现，不保证任意模型、增益、采样周期或真实电机都有相同效果。
