# 参考：规定风场与真实刚体反馈

初始标准车阻力1.078N、加速度2.156m/s²。恒定风情况下，`k=.13475`，一秒的连续理论速度约1.401m/s、位移约0.8005m；Gazebo和独立Python积分器的离散结果会略有差异，验收允许位移与速度各0.025的绝对误差。

关键顺序：先从真实`WorldLinearVel()`取得当前物体速度，计算`u=w-v`；再施加`u*abs(u)`形式的有向二次阻力。质量来自实际link惯性，迎风面积来自当前插件配置。真正的运动由Gazebo计算。

插件每4秒为本课四个已记录ID的模型设置初始位姿与零速度；世界时间保持前进。每轮1秒处保存真实样本，供不同配置重复比较。其余时段继续运动。验收确认会话token、实际模型ID互异、遥测序号前进、无风基准不动和标准车确实运动。

Python预测器不读取“预期位移”遥测，只读取质量、面积、y和测量时间，以0.001s步长独立积分声明的风场与力方程。只有均匀、恒定、非零顺风时额外比较面积与质量排序；有空间剪切或阵风时停用粗略排序，仍逐车验证方程。整体无风则检查四车都静止。

这是四个无重力、无接触摩擦的理想纵向试验体。导轨是visual，黄色板不是完整气动力网格采样。风切变、阵风均由外部函数规定；不宣称求解流场。

挑战参考：三维应先定义风和刚体速度是否在同一坐标系，求向量相对风，再按向量范数与方向构造阻力；不同迎角下的有效面积与Cd通常需要进一步建模，不能简单沿三轴套同一面积而不说明假设。

限幅的边界：默认标准车初始1.078N、宽板2.156N，均远低于20N；允许参数的极端组合仍可能饱和，不能宣称所有允许输入都不触发限幅。独立积分使用相同已声明的±20N限制。验收核对实际质量、面积和wind_on与当前参数一致，并保存build/verification.json。

基准线风速w=0但不关闭气动力；若其速度v>0，则u=-v，F=.5ρCdA*u*abs(u)<0，阻碍运动。wind_on只选择规定风场或静止空气。插件和独立积分器都无条件计算阻力，默认基准从静止开始才保持原位。
