# 附加专项53 · LIO-SAM的预积分、因子图与回环

机器人沿闭合路线回到旧位置，里程计的累计误差如何被一条新约束分摊到历史轨迹？本课从扫描和IMU数据出发，跟踪点云前端、两套iSAM2图、预积分重传播及回环入图。建议先修第50课的点时间、外参和IMU传播，以及第51课的点到平面残差。

本课固定LIO-SAM的ROS 1历史提交`0be1fbe6275fb8366d5b800af4fc8c76a885c869`。点云前端为局部地图匹配提供几何特征。图优化将局部匹配、IMU预积分和历史位姿约束组织为相应的因子。实验将同一段Gazebo记录分别回放给回环关闭与开启的估计器。[LIO-SAM论文](https://arxiv.org/abs/2007.00258) · [固定实现](https://github.com/TixiaoShan/LIO-SAM/tree/0be1fbe6275fb8366d5b800af4fc8c76a885c869)

## 从分时扫描到关键帧匹配

雷达消息头给出首列采样时刻，每个点的`time`是相对偏移，`ring`指定垂直束。前端等到IMU覆盖扫描后，使用陀螺积分与插值，将点变换到首个通过投影筛选的参考点时刻。固定实现的`findPosition`返回零平移，实际deskew主要补偿扫描内旋转。IMU里程计仍可给扫描匹配提供初始位姿。使用旋转补偿的结果应结合平台速度与转动观察，沿路面快速平移时仍可能看到残余形变。[固定前端去畸变](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/imageProjection.cpp#L443)

前端把回波整理到按束与方位组织的距离图。特征提取根据局部平滑度和遮挡关系选择角点与面点。当前特征与邻近历史关键帧构成的局部子地图匹配，建立点到直线或点到平面残差。局部配准给出该扫描的位姿估计，达到关键帧条件后再更新地图图。追源码时可以按`imageProjection`、`featureExtraction`、`mapOptmization`的顺序读。[特征提取](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/featureExtraction.cpp) · [地图匹配](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/mapOptmization.cpp)

本课采集340圈，每圈200列，每列16束。Gazebo每0.5ms做一次实际射线查询，IMU以200Hz发布角速度、比力和姿态。姿态四元数来自Gazebo IMU传感器的理想仿真姿态，用于前端初始化等计算。课程没有另设姿态估计器，航向初始化开关保持关闭。单独保存的IMU连杆世界位姿供离线评估。

实际LiDAR在IMU系中的平移为T_IL=(0.04165, 0.02326, −0.0284)m，旋转为单位阵。固定代码在构造`imu2Lidar`时会取配置`extrinsicTrans`的负号，因此本课参数填写−T_IL。轨迹评估需要把IMU连杆真值变换到LiDAR原点。其世界位置为p_WI+R_WI T_IL。先核对评估原点，再比较位姿误差。[预积分节点的外参使用](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/imuPreintegration.cpp#L216)

## 一条约束怎样进入最小二乘

因子连接它所涉及的变量，并定义一个残差。先验因子直接约束某个位姿，相对位姿因子约束两个位姿之间的变换。仅用相对位姿约束时，整条轨迹可同时改变全局原点和朝向。首帧先验为图选定参考坐标，噪声模型规定约束的强度。以平移一维玩具模型为例，若里程计测得从x₀到x₁移动了d，则可取r=(x₁−x₀)−d。实际三维位姿因子需要在SE(3)上比较预测相对变换和测量，残差在局部坐标中表达。

不同因子精度不同。若标量噪声标准差为σ，白化残差为r/σ。目标中的平方项为r²/σ²。两条残差都为0.2m时，σ=0.1m的白化残差为2，σ=0.4m的为0.5，代价贡献相差16倍。对一般协方差Σ，可用下三角因子L使Σ=LLᵀ，再求L⁻¹r。白化使用协方差描述的方向与尺度。若误差模型彼此有关，单独缩放各坐标无法表达这种相关性。

iSAM2是稀疏非线性图的增量求解方法。新因子进入后，它利用Bayes树更新受影响的部分，根据需要重新线性化，并保留可复用的计算。前端的局部点云配准和iSAM2各解不同问题。配准从点几何获得相对约束，iSAM2调整图中的一批状态，使约束在各自噪声权重下更一致。[iSAM2原论文](https://www.cs.cmu.edu/~kaess/pub/Kaess12ijrr.html)

## 两处白化与加权练习

打开个人`learner.py`，实现`whitened_residual(state, observation, sigma)`与`weighted_position(observations, sigmas)`。第一个函数用状态减测量再除标准差。第二个函数求令Σ((x−z_i)/σ_i)²最小的x。先对x求导并令其为零，再把乘在x上的系数移到分母。例子中两个位置测量为0和10m，标准差为1和3m，较精确的测量获得9倍权重，因此最优位置为1m。

```bash
python3 student_check.py
```

这是可以独立检查的一维图问题。真实课程回放仍使用GTSAM处理三维位姿、速度与偏置等变量。

## 两套图分别存什么

| 图 | 节点 | 固定实现中的主要约束 |
|---|---|---|
| IMU预积分图 | 校正时刻的位姿X、速度V、偏置B | 初始先验、IMU预积分因子、相邻偏置的随机游走、激光校正位姿先验 |
| 地图关键帧图 | 被保存的关键帧位姿 | 首帧先验、连续关键帧之间的里程计约束、通过验证的回环约束，以及可选GPS位置约束 |

两套图各自有一个iSAM2实例。地图节点提供激光里程计校正给IMU预积分节点，后者输出更高频的惯性里程计，为后续点云处理提供运动信息。地图图可以通过回环调整旧关键帧，IMU图负责惯性状态与零偏估计。GPS是上游可选输入，本课的回环对照聚焦雷达和IMU。[预积分图](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/imuPreintegration.cpp#L290) · [关键帧图](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/mapOptmization.cpp#L1381)

### IMU预积分与偏置重置

连续两次激光校正之间，IMU可能有许多采样。预积分把这一段读数合成相对旋转、速度增量、位置增量，并传播其不确定性。因子连接两端位姿、速度及起端偏置。偏置随机游走用另一条约束连接相邻B，令估计在时间上有合理的连续性。接到激光位姿校正后，程序用当前估计预测初值，把预积分因子、偏置因子和校正位姿先验送入iSAM2。[预积分原论文](https://arxiv.org/abs/1512.02363) · [固定因子构造](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/imuPreintegration.cpp#L370)

求解后，从图中取出新的位姿、速度与偏置。优化用预积分对象以新偏置清空累计量。高频里程计另有一个预积分对象，在校正后以新状态、新偏置重新传播队列中较晚的IMU。重置的是积分起点与偏置线性化参考，估计的偏置值会继续传递。固定源码还在key达到100时，用最新位姿、速度、偏置及其边际协方差作为新的先验来限制预积分图规模。地图关键帧图继续维护自己的历史轨迹。[积分重置与队列重传播](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/imuPreintegration.cpp#L320)

## 回环候选、验证与入图

重访以前的位置时，地图节点先从已估计关键帧中选历史候选。基于距离的候选还需满足时间间隔，避免把相邻关键帧反复作为回环。随后将当前关键帧点云和历史邻域点云对齐。ICP交替建立近邻对应并求刚体变换。固定实现检查输入点数、ICP收敛与fitness门槛，然后据对齐变换构造两个关键帧之间的相对位姿约束，并将fitness作为该因子六个分量的方差尺度。这是固定实现的加权规则，fitness来自点云配准代价。

要区分三个事件。候选出现说明历史位置可能重访。ICP通过说明该对齐达到几何门槛。约束真正加入关键帧图并由iSAM2更新后，旧位姿和地图才会应用本次修正。走廊或重复柱阵中可能出现几何相似的错误候选。结合候选时间、两云结构、fitness、入图记录与修正幅值判断，单靠可视化中出现连线不足以确认约束质量。[候选与ICP验证](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/mapOptmization.cpp#L529) · [回环入图与iSAM2更新](https://github.com/TixiaoShan/LIO-SAM/blob/0be1fbe6275fb8366d5b800af4fc8c76a885c869/src/mapOptmization.cpp#L1477)

## 同一录包的开关对照

课程准备阶段用`prepare.py`构建Gazebo扫描插件，`build_lio_sam.py --download`核对固定源码归档并构建独立Noetic工作区。首次构建包含GTSAM 4.0.3，后续复用缓存。固定版本、归档哈希与程序哈希见`build/lio-sam.json`。开始实验后保持Gazebo运行，在课程终端执行以下命令。

```bash
python3 adapter.py run
```

对照先采集一次，保存实际雷达与IMU记录。扫描器沿圆形参考路线运动，重访后继续前进，为待处理约束保留后续关键帧。位姿变化由ODE根据外力和力矩积分。两组分别以0.8倍墙钟节奏回放同一份`sensors.bag`，核对SHA256，独立启动估计器，只切换回环开关。bag保留`/gt_lio/replay_points`和`/gt_lio/replay_imu`。配置的关键帧位移与角度阈值为0.35m和0.15rad，回环线程按4Hz检查候选。距离搜索半径为1.3m，历史时间间隔至少12s，历史邻域参数为8，ICP fitness门槛为0.3。

每次运行生成`results/run-<uuid>/`，最新报告为`build/verification.json`。两模式目录`loop_off/`与`loop_on/`保存原生节点日志、`factor-events.json`、`keyframe-path-final.json`、在线轨迹与最终关键帧轨迹的对比文件，以及节点发布的`global-map.pcd`。其中`factor-events.json`分开记录投影和去畸变、角点/面点、IMU图更新与重启、地图因子批次和已应用的回环。验收检查关闭组无回环因子，开启组出现真正经过iSAM2更新的回环因子，并核对历史和当前关键帧的编号及时间。

先用回环日志找到应用时刻及成对关键帧，再对照`keyframe-path-before-loop.json`与`historical-keyframe-revisions.json`，查看旧位姿如何变化。回环诊断记录的前后残差是相对位姿误差经Pose3对数映射后的向量范数。它含旋转与平移分量，单位和权重不同于前面练习的标量白化残差。地图的`map-before-loop.pcd`和`global-map.pcd`按节点实际发布快照保存，适合观察几何变化。判断回环何时应用，要看iSAM2因子诊断与关键帧记录。

在线里程计记录的是当时发布的估计。最终关键帧轨迹包含后续平滑后的历史位姿。报告分别比较这两类轨迹，使用开关两组共有的采样时刻和同一个真值锚点，每组以一次首位姿SE(3)变换对齐，比例固定。将RMSE差、历史位姿修正量和回环残差放在一起观察。新增约束会改变估计轨迹，误差变化仍取决于该约束与其他观测的一致性。

若回环迟迟未触发，先核对机器人是否重访、历史时间间隔与搜索半径是否匹配，然后看候选点云大小和ICP收敛。候选通过而地图暂未变化时，检查是否有新的关键帧让待处理约束进入图。若激光与IMU时间未覆盖，先解决前端，再检查图优化。独立挑战是保持同一输入，只调整回环时间门槛或候选半径，比较候选数量、有效因子和地图修正，保存每组配置与原始日志。

在理想仿真的静止重复扫描里，点可能恰好位于已拟合直线上。原线距离雅可比含距离分母，该处不能用 0/0 形成系数。本课构建只跳过这些零距离行，检查近邻数与求解输出，避免把非有限增量写入位姿。日志里的 `GT_LIO_SAM_ZERO_LINE` 记录这一边界，正常行仍使用原来的残差、QR 和图优化。
