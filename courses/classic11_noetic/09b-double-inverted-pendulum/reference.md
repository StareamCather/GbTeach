# 参考：双级倒立摆的相对角与绝对状态

本页只读，不覆盖个人learner.py。完整实现与公式用于理解接口；作业仍需student模式执行当前个人源码并通过函数和真实运动检查。下面的设计与代数数值不充当Gazebo实测。

## 六个观测，不等于六个反馈分量原样照搬

原生观测为x、xdot、q1、q1dot、q2、q2dot。q1为第一杆相对小车的角，q2为第二杆相对第一杆的角。两杆绕同向+Y轴在同一平面运动，小车朝向固定，零位是两杆向上，因此：

```text
θ1_abs = wrap(q1)                 ω1_abs = q1dot
θ2_abs = wrap(q1+q2)              ω2_abs = q1dot+q2dot
e = [x−target_x, xdot, θ1_abs, ω1_abs, θ2_abs, ω2_abs]
```

角度包到[−π,π)，角速度不包裹。以近直立连续运动理解其导数，不把包裹边界的数字跳变当成真实无限角速度。本题不是在远离直立姿态作状态估计或完整起摆。

两个例子：q1=0.04、q2=−0.08，得到θ1=+0.04、θ2=−0.04 rad，是反向绝对角；q1dot=0.1、q2dot=−0.1，得到ω2=0。第二关节正在相对转动，但第二杆可以相对世界瞬时不转。

“双级”表示两根串联杆，不等于一个二阶状态空间系统；3个运动坐标各有位置和速度，共6状态。单杆项目有4状态。仅小车水平力被驱动，两个杆铰链均为被动，不能把本模型替换为Acrobot的肘力矩模型或两电机双摆。

## 完整参考函数

只将实现对应到自己的三个TODO，已有control流水线保留。平台不会自动把此段覆盖到个人文件。

```python
import numpy as np

K = np.array([7.07106781, 11.24116542, -161.66415569,
              3.24033851, 233.38706339, 31.37395393])
FORCE_LIMIT = 20.0


def state_error(observation, target_x=0.0):
    theta1 = (observation["q1"] + np.pi) % (2*np.pi) - np.pi
    theta2 = (observation["q1"] + observation["q2"] + np.pi) % (2*np.pi) - np.pi
    return np.array([observation["x"]-target_x,
                     observation["xdot"], theta1, observation["q1dot"],
                     theta2, observation["q1dot"]+observation["q2dot"]])


def feedback_force(error):
    return float(-K @ np.asarray(error, dtype=float))


def clip_force(force, force_limit=FORCE_LIMIT):
    return float(np.clip(force, -force_limit, force_limit))


def control(observation, target_x=0.0):
    return clip_force(feedback_force(state_error(observation, target_x)))
```

state_error先完成坐标转换再组成固定顺序的一维数组；feedback_force产生一个未限幅标量；clip_force处理正负边界。原生桥的硬保护不能代替这三个函数的正确行为。

## 给定K对应的物理模型

小车M=1 kg，两杆m1=0.2、m2=0.15 kg，全长L1=0.6、L2=0.5 m，半径r=0.015 m，质心到各杆下铰点为ℓ_i=L_i/2。均匀圆柱的横向质心惯量为：

```text
I_C,i = m_i(L_i²+3r²)/12
I_C,1 = 0.00601125 kg·m²
I_C,2 = 0.0031334375 kg·m²
```

杆端彩色球只作visual方向标记，没有额外collision或质量/惯量。不能分别拿两根杆套用孤立单摆公式后把两个控制器相加。第二杆的平移与转动能量会进入整个机构的耦合惯性。对位置坐标a=[x,θ1_abs,θ2_abs]，直立附近的质量矩阵和线性项可写为：

```text
H a¨ = G a − D a˙ + [1,0,0]ᵀ u
H = [[1.35, 0.15,       0.0375],
     [0.15, 0.07801125, 0.0225],
     [0.0375, 0.0225,   0.0125084375]]
G = diag(0, 1.4715, 0.367875)
D = [[0.05, 0,      0],
     [0,    0.004, -0.002],
     [0,   -0.002,  0.002]]
```

H的非对角项体现运动耦合。第二铰链阻尼作用于相对速度ω2−ω1，因此换成绝对坐标后，D出现相互耦合项；它不是给两根杆各独立加一项同样的对世界阻尼。

以上是可深入阅读的设计背景，不是完成填空的先修。给定K使用状态顺序[x,xdot,θ1,ω1,θ2,ω2]、Q对角项[10,1,100,1,100,1]、R=0.2；增益单位依次为N/m、N·s/m、N/rad、N·s/rad、N/rad、N·s/rad。离线线性设计可控性秩6、CARE残差约1.17×10⁻¹⁰，0.01 s零阶保持线性闭环谱半径约0.98905。这些只验证相应线性设计，不是非线性Gazebo实测，也不是全局稳定证明。[MIT Cart-Pole章节](https://underactuated.mit.edu/acrobot.html)含串联双杆扩展练习，[LQR章节](https://underactuated.mit.edu/lqr.html)给出设计原理；无需安装额外数值求解库来完成本题。
