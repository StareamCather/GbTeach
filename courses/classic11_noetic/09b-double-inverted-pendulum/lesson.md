# L09选做B：双级倒立摆的六维状态反馈

## 多一根杆，为什么不能直接复制单杆控制器

本项目在小车上的第一根杆末端再铰接第二根杆。第一杆运动会搬动第二个铰点，第二杆的反作用又会影响第一杆与小车；需要把整个机构作为一个耦合系统控制。小车仍只接受一个水平力，两处铰链都没有驱动电机，不能给两根杆各装一个控制力矩来代替本题。

建议先完成091单级选做。本课沿用三个短函数：状态误差、给定反馈、双向限幅，新增的关键是**把第二关节的相对角与相对角速度转换为第二杆的绝对状态**。

“单级/双级”在这里表示串联杆的数量，不能与微分方程的“一阶/二阶”混为一谈。小车、两根杆有3个运动坐标，各需要位置与速度，状态共6维；单杆项目则是4维。自由度变多，控制输入仍只有一个，这是欠驱动问题。

## 先认清两个角的参考

本课两杆均以**上垂线**为绝对角零位，绕+Y正转时杆顶向+X倾斜。所有角度用rad，速度用rad/s。关节链为：

```text
world ── prismatic(+X) ── cart
                            └─ revolute(+Y, q1) ── pole1
                                                     └─ revolute(+Y, q2) ── pole2
```

control收到真实关节字典observation：

| 字段 | 物理意义 | 单位 |
| --- | --- | --- |
| x、xdot | 小车位置与水平速度 | m、m/s |
| q1、q1dot | 第一杆相对小车的角与角速度 | rad、rad/s |
| q2、q2dot | 第二杆相对第一杆的角与角速度 | rad、rad/s |

小车朝向被导轨关节约束，因此第一杆绝对角θ1=wrap(q1)、角速度ω1=q1dot。第二杆的关节角q2不是它相对上垂线的角：

```text
θ1 = wrap(q1)              ω1 = q1dot
θ2 = wrap(q1+q2)           ω2 = q1dot+q2dot
wrap(a) = (a+π) mod (2π) − π
```

例如q1=0.02、q2=−0.03时，第二杆绝对角为−0.01 rad；q1dot=0.10、q2dot=−0.04时，第二杆绝对角速度为+0.06 rad/s。它相对第一杆向负方向转，不代表它相对世界也向负方向转。角度需要包裹，角速度不要作这种模运算。

输入字典和反馈状态恰好都含6个数，但最后两个数的意义不同。给定K对应的误差顺序固定为：

```text
e = [x−target_x, xdot, θ1, ω1, θ2, ω2]
目标 = [target_x, 0, 0, 0, 0, 0]，默认target_x=0
```

本模型原始零位是两杆都向上，不要添加基础被动摆的0.2 rad偏置。回合初始化改变实际关节位置，但不会把每个扰动初态重新定义为关节零位。

## 给定六个增益，只产生一个水平力

小车质量1 kg；两根均匀圆柱杆质量分别0.2、0.15 kg，全长分别0.6、0.5 m，半径均0.015 m。绕各自质心横轴的惯量分别为0.00601125、0.0031334375 kg·m²。杆端彩色球仅为visual标记，不增加碰撞、质量或惯量。小车阻尼0.05 N·s/m，两铰链阻尼各0.002 N·m·s/rad，g=9.81 m/s²。

本课已按整个标称机构和上述绝对状态离线设计LQR反馈，直接使用：

```text
K = [7.07106781, 11.24116542, −161.66415569,
     3.24033851, 233.38706339, 31.37395393]
u_raw = −K · e
u = clip(u_raw, −20 N, +20 N)
```

增益的单位依次为N/m、N·s/m、N/rad、N·s/rad、N/rad、N·s/rad。内积把六项作用合成**一个标量力**，不是为每个关节分配一个输入。K含正负项，整体负号仍要保留；不能把单杆K接上两个零，也不能依据单根杆的倾斜方向独立决定全部推力。

LQR在直立附近的线性化模型上权衡状态误差与推力代价。K已给定，不要求你求解Riccati方程；不了解背景可看[MIT的Cart-Pole与欠驱动系统](https://underactuated.mit.edu/acrobot.html)及[LQR章节](https://underactuated.mit.edu/lqr.html)。本题只验证近直立局部稳定，不提供完整起摆；任一绝对杆角超出0.65 rad局部保护边界时，桥将控制力置零。包裹角度或增加推力上限都不会自动把局部控制变成全局起摆器。

## 真实控制信息流

控制每0.01仿真秒更新，即100 Hz；物理步长0.001 s，每次输出在后续10个物理步中零阶保持。流程是：**读取真实关节位置/速度 → 相对量转换为两杆绝对状态 → 六维误差 → 给定K内积 → 学生双向限幅 → 小车水平力 → Gazebo动力学 → 新状态。**

每回合只在开始时初始化小车与两杆的实际关节位置/速度，随后靠力控制，不反复改写姿态。默认reference_demo每14仿真秒显式开始一个新演示回合，使用正负同向初值；不要把演示循环的初始化误认为控制器持续传送模型。模拟器状态直接可读，本课暂不研究传感器噪声与状态估计。

## 填空1：六维state_error

接口仍为state_error(observation,target_x=0.0)，返回形状(6,)的NumPy一维数组。

- 提示1：先问每个角“相对谁”。第二个输入关节角相对第一杆，K需要第二杆相对世界的上垂线角。
- 提示2：分别包裹q1和q1+q2；两绝对角速度分别为q1dot与q1dot+q2dot。位置误差是当前x减target_x。
- 提示3：先算两个角，再用 `np.array([...])` 按位置、速度、第一角、第一角速度、第二角、第二角速度排列。不要把q2dot直接放进最后一项，也不要包裹角速度。

## 填空2：feedback_force

按u_raw=−ΣK_i e_i计算未限幅力，返回Python float。

- 提示1：使用完整六维误差，不能只根据杆角输出，也不能返回两个杆力矩。
- 提示2：保留整体负号及给定K内各项符号；它们与坐标和状态顺序绑定。
- 提示3：NumPy的 `@` 是一维向量内积，`*` 是逐元素乘法；确认返回标量。

## 填空3：clip_force

把控制力限制到传入的正限值force_limit，默认20 N，返回float。

- 提示1：中间值保持，正负超限都处理。
- 提示2：数学形式为max(−F,min(F,u_raw))。
- 提示3：可用 `np.clip`，不要写死20而忽略传入限值。实际桥接保护不能代替这处作业，函数检查会独立检查双向限幅。

## 独立挑战与典型错误

先作代数预测，再用函数检查：q1=0.04、q2=−0.08时，两杆是否朝同一侧？q1dot=0.1、q2dot=−0.1时第二杆绝对角速度是多少？clip输入±25 N、限值20 N及3 N时输出应怎样？这些函数输入不是要求你把真实机构摆到远离局部范围的位置。

通过后，比较同向与反向初态的两个杆角、两个绝对角速度及小车位移，检查扰动后的末窗RMS与控制峰值。不要只看第一杆或“还没倒下”；两杆暂时竖直但角速度很大，也不等于已稳定。

| 现象 | 优先检查 |
| --- | --- |
| 第一杆状态正常、第二杆反馈明显错误 | 是否把q2直接当θ2，或遗漏ω2=q1dot+q2dot |
| 两杆同向初值被解释成不同方向 | 表格是绝对角；先由q2=θ2−θ1转换 |
| 同样代码从4维改成6维后形状报错 | 数组形状、完整K长度、内积而非逐元素乘法 |
| 正向限幅正确、负向失控 | 是否只处理上限、是否使用传入force_limit |
| 参考能稳，个人模式不通过 | TODO、模式、当前执行源码SHA及重载；演示无作业学分 |
| 旧运行仍在、新文件已经修改 | 保存并重载，不拿旧回合替新源码证明 |

完整起摆必须另建扩展项目并重新设计控制与运行边界，本题只学习近直立的串联双杆局部稳定。
