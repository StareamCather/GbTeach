# 附加专项 40：搭一间可测量的光照摄影棚

本课把复杂工厂中的光照问题缩小为三张相同灰卡、两个彩色聚光灯、一个白色point补光灯和一个弱中性色directional补光灯。场景保留遮挡条和接收阴影的地面。问题是：**同样的灰色材质为什么变成红色或蓝色？灯的距离、照射方向、聚光角与环境光分别影响什么？**

## 光与材质是两种参数

光源的颜色表示发出的光，材质漫反射颜色表示表面对各颜色的反射比例。两者逐通道相乘。表面法线与入射光方向的夹角进一步影响漫反射强度；背向光源的面不能简单套用正面亮度。

Classic使用传统材质与OGRE渲染。本课讨论ambient、diffuse、specular、attenuation和spot，不把它们叫作现代金属度/粗糙度PBR参数，也不把渲染像素当作经过标定的物理照度计。

| 名称 | 在本项目中的作用 |
|---|---|
| ambient 环境光 | 没有直接光照时的均匀底色；太大容易掩盖阴影与光色 |
| diffuse 漫反射 | 随入射方向变化的基本表面明暗 |
| specular 镜面反射 | 随观察方向变化的高光；同一灰卡换视角会不同 |
| attenuation 距离衰减 | point/spot在距离r处按`1/(kc+kl*r+kq*r²)`衰减，并受range限制 |
| spot 聚光 | 内角内较强，外角外消失，中间按falloff过渡 |
| cast_shadows | 光是否投射阴影；表面法线暗部与遮挡阴影是不同原因 |

## 项目结构与运行流程

`parameters.json` 规定环境光、红/蓝灯强度、线性和二次衰减、聚光外角，以及独立的 `directional_fill_intensity`。`scene.py` 将参数生成三张灰卡、两盏spot、白色point补光和弱中性directional补光的SDF。启动会重新生成 `world.sdf`，主要练习输入是参数和生成器。

`native/camera.cc` 在真实CameraSensor渲染完成时保存640×360 RGB图像与测量时间。`verify.py` 等待帧数和仿真时间推进，校验图像和元数据来自同一帧，再测量红灯灰卡与蓝灯灰卡的RGB均值。验收算法只读实际像素，不把SDF中的灯色直接报告成“测得颜色”。

默认灯到卡片的主方向距离为2.8 m。参数检查会给出该距离下的衰减项；它只是完整着色计算中的一个因子，还需考虑材质、法线、聚光与其他光源。

## 建立基准

1. 开始实验并运行验收。左灰卡应偏红，右灰卡偏蓝；中卡片被白色补光和少量溢出光照亮。
2. 运行 `python3 lab.py image`，打开输出的真实 `camera.ppm`。这张固定传感器图像用于重复测量；自由用户相机适合查灯位、阴影和遮挡关系。
3. 记录 `graycard_rgb` 与 `attenuation_at_2_8m`。不要只记录“看起来更亮”。
4. 展开模型树找到 `shadow_gobo`，从侧面查看它在中卡片前的位置；观察其遮挡与白色补光之间的关系。

## 实验一：先分离环境光

把 `ambient` 从0.04增加到0.16，其余不变，重启。预测红蓝卡片的暗通道也会上升，阴影的对比度降低。过强环境光会使“开关一盏灯”的差异不明显。

再恢复默认值。分别只改 `red_intensity` 或 `blue_intensity`。每次测量都使用同一相机视角与ROI；否则位姿变化可能比灯强变化更显著。

### 分清三类真实灯光

`red_spot`、`blue_spot` 是带内外角的spot；`white_fill` 是按距离衰减的point；`neutral_directional` 是方向固定、在本模型中不随距离衰减的directional。将 `directional_fill_intensity` 从0.02单独改为0.10，重启并对比中性灰卡真实RGB，预计三通道一起升高；彩色spot仍然存在。该参数允许0～1，但高值可能让画面饱和并掩盖色偏，此时颜色验收失败是需要诊断的实验结果。

## 实验二：距离衰减不是把range改小

默认 `kc=1`，`kl=0.12`，`kq=0.04`。对2.8 m距离，计算 `1/(1+0.12*2.8+0.04*2.8²)`。把 `attenuation_quadratic` 改为0.12，预测红蓝spot照射区更暗，重启后比较RGB。这个参数修改两盏spot的衰减；白色point补光仍保留自己的固定衰减，中性directional不使用这组距离衰减参数。

再复制一盏相同白灯和两张相同灰卡，分别放在相距灯2 m、4 m的位置。保持法线和光线方向一致，先排除环境光与其他灯，再比较真实像素均值。仅设置`range=4`不是实现严格的平方反比定律；range是范围边界，不是完整的衰减函数。

## 实验三：聚光角与遮挡

将 `spot_outer_rad` 从0.9减到0.55，保持内角0.25不动。观察卡片边缘照明范围是否收缩。角度单位是弧度，不是度。

在 `scene.py` 中对照 `cast_shadows` 的生成位置，单独关闭白色补光灯的投影，重启后从同一视角比较遮挡条的阴影。接着把遮挡条移开，再比较卡片自身背光区域：两者都可能暗，但形成机制不同。

阴影分辨率、bias、自阴影伪影以及近远裁剪的影响需要真实GUI观察。本课不通过“图像有深浅差异”就宣称阴影质量已合格。

## 实验四：材质与高光

复制一个带specular的金属外观球体到摄影棚，在用户相机中改变观察角。保持光源不动，记录高光位置变化。再降低材质specular，保留diffuse，比较两者区别。不要把高光位置变化解释为物体旋转，也不要将specular值直接当金属度。

本课固定相机没有自动曝光或HDR控制。过曝可从相机输出大量255像素发现，但降低灯强、环境光或反射率是这里的调整手段；教材不会提供当前相机不存在的曝光参数。

## 错误诊断

| 现象 | 定位顺序 |
|---|---|
| 红灯照着但卡片很暗 | 查方向、表面法线、内外角、range、距离衰减，再查灯色 |
| 全场景灰白，灯色不明显 | 环境光是否过大，是否有无意保留的强directional灯 |
| 有阴影却颜色验收失败 | 阴影和RGB色偏是不同目标；查看真实固定相机ROI是否对准灰卡 |
| 阴影边缘闪烁/条纹 | 视距、深度精度、bias和阴影贴图分辨率；用同一视角逐项调整 |
| 帧数不增长 | 仿真暂停或真实渲染失败，查DISPLAY、插件与运行日志 |
| 修改后图像不变 | 当前服务端仍持有旧场景；本课参数需要重启实验后生效 |

## 独立挑战与交付

为第38专项机床设计一套作业区照明：顶灯提供基本可见度、spot突出操作区、低强度补光减轻死黑。提交灯位、方向、衰减、材质参数，以及三张固定视角实际图像；说明各灯的职责和一个仍存在的阴影伪影。

自动验收覆盖真实帧推进和灰卡在两种光色下的RGB响应。阴影边界、高光随视角变化、美术效果及物理光度标定均另行检查，不由该自动验收代替。

不了解颜色与光的关系？[Classic官方材质说明](https://classic.gazebosim.org/tutorials?tut=color_model)。要查具体灯光字段？[SDFormat官方规范](https://sdformat.org/spec)，选择1.6版本后展开world/light，注意规范版本与libsdformat版本不是同一个数字。

相机插件采用真实 `Camera.hh`，准备程序显式读取gazebo与OGRE/Paging/Terrain/RTShaderSystem编译和链接参数，并按源与flags缓存库。相机源与第39专项一致；每帧使用标准FNV-1a64校验，验收结果保存到个人副本 `build/verification.json`。初始化和验收不会用“灯已加载”代替实际像素响应。
