# 参考：原生关节、物理摆与滑轨

本页只读，不覆盖个人副本。下面的数值推导是理论预测，未附实测日期的数据不作为真实Gazebo测量。

## 连接图、坐标图与初态

本课SDF 1.7中，pendulum_rig的frame与slider_rig的guide都是动态link，分别由fixed joint连接world。摆球通过revolute接frame，滑块通过prismatic接guide。fixed保持两端初始相对变换，revolute留下绕轴的一个转动自由度，prismatic留下沿轴的一个平移自由度。把整个rig设static会冻结动态更新，不等于只固定支架。

joint pose默认相对child；axis/xyz默认在joint frame中表达。显式relative_to改变位姿的表达基准，expressed_in改变轴向量的表达基准，两者都不代替parent/child定义的动力学连接。axis必须是非零单位方向；关节原点由pose确定，不能把xyz理解为目标坐标。

| 版本 | 轴的默认表达 | 指定模型坐标表达 |
| --- | --- | --- |
| SDF 1.5/1.6 | joint frame | use_parent_model_frame=true |
| SDF 1.7 | joint frame | xyz的expressed_in="__model__" |

旧旗标所说parent model不是parent link；Classic对原始SDF低于1.7且parent为world的部分旧设置仍有兼容分支。本课直接使用1.7及名为frame/guide的link坐标系，避免由旧版示例猜测新文件行为。[1.6规格](https://sdformat.org/spec/1.6/joint/)、[1.7坐标语义](https://sdformat.org/tutorials/specification/pose_frame_semantics/1.7/)和[Classic实际轴解析](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/physics/Joint.cc)可分别核对。

ODE在设定铰轴/锚点或滑轴时，以当前两体构型建立关节零位。基准摆初始已经偏离铅垂θ0=0.2 rad，此时q=0；滑块初始位置也是q=0。上下限是相对这个关节坐标的范围，不是世界坐标或任意visual的欧拉角。[ODE铰链与滑轨接口](https://www.ode.org/ode-latest-userguide.html)说明了零位定义。

本课实际轴符号为θ=θ0+q；θ还独立由球心与支点世界坐标计算为 `atan2(−(x_bob−x_pivot),−(z_bob−z_pivot))`，用于交叉核对原生关节读数。基准q的限位[−0.6,0.6]对应几何角[−0.4,0.8] rad；自由摆预期只在约±0.2 rad内，未碰这些stop。

文件中swing_joint的pose相对frame为零；真实Model消息的joint.pose按child link坐标序列化，初态等价于平移(0,0,0.8) m、旋转R_y(−0.2)。这是同一个支点换坐标表达，不能因数字不同就判为未加载，也不能把该消息原样当作文件的frame-relative pose覆盖回去。

## 物理摆的初始几何与周期

支点p=(-1.4,0,2) m。以绕+Y右手转角θ描述球心方向，球心应为：

```text
p_bob = p + R_y(θ) (0,0,−d)
      = (−1.4−d sinθ, 0, 2−d cosθ)
d=0.8 m，θ0=0.2 rad
初始球心≈(−1.558935465, 0, 1.215946738) m
```

改变初始幅值时，球心位置与朝向要保持同一个绕支点的变换；只旋转球形visual不能建立这种运动。球是质量1 kg、半径0.1 m的均匀实心球，杆只有visual且无质量/碰撞：

```text
I_C = 2Mr²/5 = 0.004 kg·m²
I_p = I_C+Md² = 0.644 kg·m²
I_p θ¨ + bθ˙ + Mgd sinθ = 0
ω0² = Mgd/I_p
T0 = 2π/ω0 = 1.799878979 s
```

小角近似要求sinθ≈θ；上述T0还忽略阻尼与限位。b=0.002 N·m·s/rad时，线性黏性阻尼的ω_d=√(ω0²−(b/(2I_p))²)，对应T_d≈1.799879157 s，和无阻尼值十分接近。有限振幅的一阶无阻尼修正为 `T≈T0(1+A²/16)`；A=0.2 rad给出约1.804379 s。这两个修正有各自假设，不把它们简单拼成严格的非线性阻尼解，也不要求真实周期完全等于其中一个小数。

工具的corrected_period_s进一步取弱阻尼小角周期乘上有限振幅四阶因子 `1+A²/16+11A⁴/3072`，基准约1.804389167 s，用于比较和安排观察窗口。它仍是近似参考，不是从真实轨迹测出的周期，也不是一般非线性阻尼摆的精确解。

只有I_C远小于Md²时，才可进一步约化为质点摆公式 `2π√(d/g)`。如果将杆改成有质量的刚体或加入其它配重，必须重算总质心与支点惯量，不能沿用本课球摆数值。[MIT物理摆讲义](https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/mit8_01scs22_chapter24.pdf)提供该区别的基础推导。

周期应从实测角度轨迹求得：对相邻点中同方向的过零作插值，取两个同方向过零时刻之差。采样间隔、有限振幅、阻尼和数值积分都会影响比较；不能用预测周期直接填回测量字段。

## 滑轨的未碰限位阶段

guide位于(1.4,0,1.5) m，滑动轴+Z向上。滑块质量M=1 kg，黏性阻尼b=0.5 N·s/m，关节friction的最大阻力F_c=0.1 N。初始q=q˙=0，下行且未碰限位时：

```text
M q¨ = −Mg − b q˙ + F_c
q˙(t) = −(Mg−F_c)/b · (1−exp(−bt/M))
q(t) = −(Mg−F_c)/b · [t−M/b · (1−exp(−bt/M))]
q(0.2 s) ≈ −0.187885317 m
```

这是持续下行、重力大于阻力且未触下限的分段解析预测；不能跨过碰限位时刻继续外推。b趋于0时要用相应极限式，不能直接除以0。下限−0.6 m表示相对初始零位向下0.6 m，真实stop附近可有有限约束误差与短暂过渡。

关节阻尼与速度成正比；关节friction在本版ODE中以零目标速度和FMax近似阻力。其单位为转动N·m、平动N，不是表面μ。joint limit中的effort/velocity不等于已经创建主动电机，也不保证对所有重力运动硬限幅；应根据具体引擎与施力/控制接口核实。本课只对位置约束作实际运动验收。[Classic ODE关节实现](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/physics/ode/ODEJoint.cc)可核对阻力与阻尼路径。

## 挑战推导与修改范围

1. **只改重力g=6。** I_p与d不变，T0按 `1/√g` 缩放：`T0=2π√(0.644/(6×0.8))≈2.301453388 s`。滑轨用相同阻尼/阻力公式，`q(0.2)≈−0.114163066 m`。两者均是预测，不是把完整轨迹按时间任意拉伸后当实测。
2. **只改滑轨lower=−0.5。** 到达新下限之前，运动方程未变，所以0.2 s的预测仍约−0.187885317 m；末态q应在新下限附近。upper仍为0.1。必须修改slide_joint的limit，不能误改swing_joint或仅改导轨visual长度。
3. **计算扩展d=1。** I_C仍为0.004，I_p=1.004 kg·m²，基准重力下T0≈2.010074810 s。初始球心相对支架为(−0.198669331,0,−0.980066578) m，初始朝向仍R_y(0.2)。无质量杆visual需相应伸长并移到球心与支点之间；不要把I_p填进球的inertial，那里要求的是球的质心惯量I_C。验收工具若提示几何/采样范围不适用，应先核对提示，不把更一般的机构改造当成本课必过项。

三项都要保留真实读取与预测的区别。位置stop只在到达时起作用，杆的visual不提供约束，改长杆并不自动移动link或关节支点。

## 2026-10-30 ikaros实测对照

以下来自Gazebo Classic 11.15.1正式运行，周期由真实Joint.angle轨迹的同向过零计算。周期预测栏为含弱阻尼与有限幅修正的corrected_period_s，不是无阻尼小角T0，也不充当测量值。

| 配置 | 周期预测 / s | 周期实测 / s | q(0.2 s)预测 / m | q(0.2 s)实测 / m |
| --- | --- | --- | --- | --- |
| 基准g=9.81 | 1.804389167 | 1.804358715 | −0.187885317 | −0.188854934 |
| 只改g=6 | 2.307220580 | 2.307152843 | −0.114163066 | −0.114752226 |

基准末端采样q=−0.600000000 m；只将lower改为−0.5的分支，末端q=−0.500000000 m，而基准早期位移与摆周期不变。位置stop改变终点，没有改变到达stop之前的运动方程。

基准与g=6分别记录110、140个真实关节样本，逐点以child质心几何与原生四元数朝向交叉校核；measurement_passed及cleanup.confirmed均为true。这里的小数是模拟器的观测输出，不是实际机构的计量精度。原pause=false时，收尾恢复后世界自然继续运行，JSON保留采样窗口，不要求场景一直停在最后一帧。

## 当前自动仪器的范围

以下条件服务于本课的被动小角摆与竖直滑轨，不是Gazebo所有机构的通用极限。predict在发送实验控制前检查个人文件；不合范围时先按错误提示修正。

| 项目 | 当前范围与条件 |
| --- | --- |
| 物理配置 | SDF 1.7、ODE quick；dt为0.0005至0.002 s；iters为80至200整数；竖直g为5至12 m/s² |
| 拓扑与坐标 | 每rig两link、两joint；dynamic支架以fixed接world，基座为0.15 m均匀立方体的质心惯量、质量0.5至2 kg；本课显式joint pose与axis坐标规则、轴向及基座初态保持不变 |
| 动态体 | 质量0.5至2 kg；球半径0.06至0.15 m、滑块各边0.1至0.4 m；几何居中、均匀质心惯量一致，重力开启、额外速度衰减关闭 |
| 自由摆 | 0.1≤abs(θ0)≤0.25 rad、d为0.6至1.1 m；球心随初角同步；无质量杆的长度与位置同步；球最低表面离地至少0.3 m |
| 摆关节 | damping为0至0.01 N·m·s/rad、friction=0；位置限位覆盖预计自由摆q范围，并在两侧留至少0.08 rad余量 |
| 滑轨 | lower为−0.8至−0.35 m，upper为0.05至0.2 m；damping为0.1至2 N·s/m、friction为0至0.5 N；下限处滑块底面离地至少0.2 m |
| 早期滑轨样本 | t=0.2 s预计下滑超过0.08 m，且离下限至少0.05 m，保证样本仍在未碰stop阶段 |
| 观察计划 | interval为0.03至0.06 s且每预测周期至少24点；观察2.8至3.2个修正预测周期；间隔须对应整数物理步，t=0.2 s必须落在采样格上；推进次数不超过180、仿真窗口不超过8 s |

基准每次推进50个物理步，109次推进覆盖5.45 s，连同初态共有110个样本；这取决于当前配置重新计算，不写死在测量值中。摆限位余量是为了不把碰限位后的非自由运动拿来验证小角周期；若要单独研究撞stop，应另设观察问题，不能期待当前自由周期验收继续通过。

本被动rig保持effort/velocity=-1，文件中stop stiffness=10⁶、dissipation=100，不以额外命令限幅、主动驱动或改变stop参数混入自由运动比较。需要其它轴、不同机构或主动电机时，先按对应课程建立新实验条件，不能把本课范围错误当作引擎不支持。

## 实验数据怎样形成

predict读取个人文件，检查模型与关节定义并计算物理预测。inspect只读取当前实际模型、关节和physics消息，不负责重置或生成运动轨迹。

experiment先完成文件与工具版本检查，再读原暂停状态、按确认协议进入暂停；推进1步，严格核对iterations增加1且仿真时间增加dt，以排空历史输入，然后reset ALL并采新stats基线。reset本身不能替代先排空输入。随后读取真实physics、两rig的parent/child/type、关节轴/参考系/上下限/阻尼/friction及父子质量惯量、初始pose和q零位。文件的显式参考系与运行消息的child-relative joint pose在同一几何意义下比较。

采样阶段保持一条原生连接，每格只发一次multi_step请求，以实际stats核对步数与暂停状态，再读取真实Joint.Position和link pose。保留全部原始关节坐标、model/link的四元数位姿与时钟；将位姿变换至世界坐标，独立核对θ0+q与球心几何角、支点至球心距离、固定基座位置与朝向、滑轨横向/转动约束及摆球R_y(θ)朝向。model pose用于坐标变换，不冒充关节q。

| 自动比较 | 当前判定 |
| --- | --- |
| 摆周期 | 同方向过零线性插值，至少形成2个完整周期样本并取均值；与修正预测的差不超过0.02 s与预测4%的较大值 |
| 可辨摆动 | 实际θ在铅垂两侧均达到至少0.07 rad，不用静止序列假装测得周期 |
| 关节与几何 | θ0+q与独立几何角差≤0.005 rad，支点到球心距离误差≤0.003 m；固定基座位置误差≤0.003 m |
| 朝向约束 | 固定基座、滑块和摆球各按应有世界朝向核对，四元数角距≤0.005 rad |
| 滑轨几何 | q与相对Z位移差≤0.005 m，横向位移≤0.005 m |
| 滑轨动态与stop | t=0.2 s位移与解析预测差≤0.015 m；所有采样q在上下限外余量≤0.01 m，最后5点各距lower≤0.005 m |

这些是本课采样仪器的判定容差，不表示机构在所有时刻具有对应的机械制造精度或连续轨迹误差上界。有限采样只描述实际取得的轨迹点。

报告是模拟中的真实状态观测，理论预测与观测字段要分开。仪器会重置本课模型、速度和时钟，完成后确认并在必要时恢复原pause，保留结果；不承诺还原旧的完整state。初始化及收尾均先读状态，必要时单次改变，以实际state确认，CLI异常保留原始错误和只读回查结果；只有测量通过且收尾确认成功，才输出成功测量JSON。墙钟耗时包含查询、等待与采样，不是自由运行实时因子或纯求解CPU时间。

修改个人world.sdf后保存、predict、重载项目，再运行experiment并使用新的报告名。查看本页不会覆盖个人副本；需要回到课程模板时使用应用的备份恢复流程，先保留自己的变式和报告。
