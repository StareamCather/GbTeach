# 原生关节：物理摆与重力滑轨

## 限制运动方向，与设置初始位姿有什么不同

第03课的relative_to说明初始位姿怎样计算；本课的joint在仿真过程中持续约束两个link之间允许的运动。你将用同一套SDF关节搭建物理摆与滑轨，预测它们在重力下的运动，再对照真实关节读数和几何轨迹。无需ROS、控制器或C++先修。

**自由度**是仍可独立变化的运动坐标。刚体相对另一刚体原有3个平移、3个旋转自由度；revolute关节保留绕一条轴的旋转，prismatic保留沿一条轴的平移，fixed不保留相对自由度。joint不会自动画出销轴、轨道或电机，外观由visual负责，碰撞由collision负责。

| 本课结构 | 连接关系 | 允许的运动 |
| --- | --- | --- |
| pendulum_rig | world → fixed → frame → swing_joint → bob | frame被固定；bob绕铰轴摆动 |
| slider_rig | world → fixed → guide → slide_joint → carriage | guide被固定；carriage沿导轨轴平移 |

两个rig均为动态模型，支架link通过fixed关节连到world。world是固定环境，不需要另建一个名为world的link。把整个模型设static=true会使其不参与正常动态更新，不能代替“固定支架、活动摆球”的关节结构。

## 先把连接、位置和轴分开读

打开个人world.sdf，按以下次序找到一个joint：

1. name/type说明关节名称和类型；parent、child引用link名称，确定连接的两端。父子不表示谁有质量、谁一定静止。
2. pose给出关节原点和初始朝向。本课使用SDF 1.7，以relative_to明确表达坐标系；若省略它，**joint pose默认相对child link**，不是相对parent或model。
3. axis/xyz给出单位轴向。本课用expressed_in明确向量在哪个坐标系中表达：摆轴在名为frame的link中为+Y，滑轴在guide中为+Z。若不写expressed_in，默认使用joint frame。轴的位置由joint pose决定，xyz是方向而不是一个空间点。
4. axis/limit定义关节坐标q的上下界；axis/dynamics定义阻尼、关节摩擦等物理性质。

本课摆支点在世界(-1.4,0,2) m，摆球质心距支点0.8 m，初始绕+Y偏离铅垂向下0.2 rad。按右手规则，向下的杆绕+Y正转会偏向−X。关节原点仍在支点，不能只倾斜球的visual就声称整个摆已绕支点转动。

旧版例子需要核对声明的SDF版本：1.5/1.6可用use_parent_model_frame选择模型坐标表达的轴，1.7改用xyz的expressed_in属性；这里的parent_model也不是parent link。Classic还保留某些旧版world父连接的兼容行为，不把旧旗标机械复制进本课。需要补坐标规则可看[官方模型运动学](https://sdformat.org/tutorials/specification/spec_model_kinematics/)与[1.7坐标语义](https://sdformat.org/tutorials/specification/pose_frame_semantics/1.7/)。

## 物理摆：不能只看杆长

bob是半径0.1 m、质量1 kg的均匀实心球。细杆只是随球运动的无质量visual，不是另一根有质量、需要单独积分的杆；球的碰撞与惯性仍须一致。

设θ为支点至球心方向与铅垂向下的夹角，d=0.8 m，球绕质心且平行于摆轴的惯量为I_C，则：

```text
I_C = 2Mr²/5 = 0.004 kg·m²
I_pivot = I_C + Md² = 0.644 kg·m²
I_pivot θ¨ + bθ˙ + Mgd sinθ = 0       （关节摩擦为0、未碰限位）
T0 = 2π√(I_pivot/(Mgd)) ≈ 1.799879 s  （小角、无阻尼近似）
```

T0是物理摆预测，不能把支点至球心距离直接当成质点摆的全部信息。初始幅值0.2 rad有有限振幅修正，阻尼也会改变振幅和周期；一次真实测量不应被强行写成恰等于T0。[MIT物理摆讲义](https://ocw.mit.edu/courses/8-01sc-classical-mechanics-fall-2016/mit8_01scs22_chapter24.pdf)给出力矩与平行轴推导。

几何角θ也不等于关节零位。此场景在偏转0.2 rad的初始姿态建立铰链，关节q初始为0；本课轴符号下θ=0.2+q，所以摆垂直时q约为−0.2 rad。limits限制q，而不是把铅垂方向自动设为0。仪器把真实关节读数与球心几何角分别记录核对，不能看到q=0就断言摆已垂直。

## 重力滑轨：阻尼、摩擦与位置限位

guide在世界(1.4,0,1.5) m处固定，carriage是1 kg的均匀box。滑动轴+Z向上；q初始为0，重力使q变负。下限−0.6 m、上限0.1 m是相对初始位置的允许行程，不是世界z坐标，也不是box碰撞尺寸。

**黏性阻尼**随速度产生反向作用：转动关节为τ_d=−bq˙，b单位N·m·s/rad；平动关节为F_d=−bq˙，b单位N·s/m。这里摆的b=0.002，滑轨b=0.5。**关节friction**在此ODE实现中以零速度目标和最大阻力建模，转动用N·m、平动用N，不是第07课的无量纲接触摩擦系数μ。滑轨值为0.1 N，摆为0。

在滑块持续向下、尚未到限位的阶段，重力、速度阻尼与关节摩擦共同决定位移；不能直接用自由落体−gt²/2当精确答案。到达位置下限后，关节约束限制继续下移，不需要预先画一个实体挡块。本课以真实运动检查位置限位；effort、velocity等字段的执行范围还取决于引擎与控制路径，不保证把重力自由响应硬夹到指定值，也不自动创建驱动电机。

## 引导实验：预测、重建初态、再测量

1. 开始课程，在实验终端运行 `python3 lab.py predict`。记录初始几何、两种关节类型/轴/上下限、摆的I_pivot与T0、滑轨早期预计位移。此步骤读取个人文件作预测，不能代替检查服务器。再用“读取真实关节与模型配置”或 `python3 lab.py inspect` 查看当前真实结构；如果场景已运行，当前q可以已经离开0，不把这次读取误当成重置后的初态。
2. 运行 `python3 lab.py experiment --report measurements-baseline.json`。即使GUI启动时摆已经运动，仪器也会重新建立初态；测量期间不要拖动模型、施力或同时操作暂停/单步。
3. 对照报告中的真实关节与link位姿。摆球应围绕固定支点运动，而不是整个模型自由下落；滑块应沿轴线平移、保持朝向，并在下限附近停住。
4. 默认parameters.json以0.05 s仿真间隔采样，观察约3个预测周期；实际推进与采样时刻以stats为准。周期必须由真实θ轨迹确定。同方向两次过零的间隔是一周期，相邻反方向过零只相隔半周期；看见球又回到某个位置，还要比较运动方向。
5. 将预测值、实际加载结构、真实轨迹与统计分别保留。试验会重置本课模型、速度和仿真时钟，结束确认并在必要时恢复原暂停/继续状态，不还原完整试验前state。若恢复继续运行，世界会自然演化，JSON保存采样时刻而不保证停留在末帧。初始化与收尾均先读状态，必要时只改变一次，并以实际state确认；CLI异常保留原始错误及回查结果，成功JSON须测量和收尾确认都通过。

个人文件保存后，点击“重载项目”才会由新SDF重建关节；编辑文件不会实时改动旧服务器。

## 独立挑战：一次改变一个物理条件

每项都从基准开始，先预测，再修改个人文件、保存、运行predict、重载项目、运行experiment并另存报告。

- **重力改为6 m/s²。** 只将world中的gravity从 `0 0 -9.81` 改为 `0 0 -6`，其它参数不动。这是一个同时作用于两rig的全局物理变量：摆的无阻尼小角周期预测约2.301453 s，滑块0.2 s的未碰限位位移约−0.114163 m。比较实际周期是否变长、早期下滑是否减小；不要同时调质量或阻尼来追数值。
- **行程下限改为−0.5 m。** 恢复基准重力，只把slide_joint的lower由−0.6改为−0.5，保留upper=0.1。预测早期运动不变、停止位置改变，再核对真实q与link位移；这检验的是位置约束，不是接触摩擦或碰撞挡块。
- **计算扩展：支点至球心改为1 m。** 先在参考页推导新I_pivot与周期。若自行改模型，必须同步球心的绕支点位置和杆visual的长度/局部位置；均匀球自身质量、半径和I_C不因无质量杆变长而变化。工具适用范围以predict提示为准，这个扩展不要求额外控制程序。

## 2026-10-30 ikaros实测示例

Classic 11.15.1基准测得摆周期1.804358715 s，对照修正预测1.804389167 s；滑轨0.2 s的q为−0.188854934 m，对照解析预测−0.187885317 m，最终采样下限为−0.600000000 m。g=6时周期变长、早期下滑减小；只改lower=−0.5时末端位置改变，基准早期位移和摆周期保持不变，完整数值见参考页。

基准与g=6分别取得110、140个真实关节样本，并逐点核对child质心几何和朝向；测量与收尾状态确认均通过。报告描述这些采样点，恢复原继续状态后不要求画面冻结。

## 验收时要能解释什么

本课信息流是：**个人SDF的link、惯性与joint → 坐标/单位/限位和采样计划校验、理论预测 → 确认暂停，推进一步并确认真实时钟以排空历史输入 → reset ALL、采新基线并核对实际结构 → 定步采集真实关节与link状态 → 几何约束、同向过零周期和末5点限位比较 → 保留结果，确认并在必要时恢复原暂停状态。**

| 现象 | 优先排查 |
| --- | --- |
| 整个摆自由下落 | world固定连接、parent/child名称与实际关节是否成功加载 |
| 摆只自转、不绕预期支点 | joint pose是否误按parent解释，球心与支点初始几何是否一起配置 |
| 关节轴方向与预期不同 | xyz的表达坐标、joint朝向、expressed_in及SDF版本 |
| 摆初始偏转但q=0 | 分清初始关节零位与几何铅垂角，不把它直接判为传感失败 |
| 滑块停止位置不对 | lower/upper是相对关节零位的q，另核对轴符号与实际加载文件 |
| 增大阻尼后摆幅衰减 | 这是物理耗散；不能把更快静止直接叫作求解更准确 |
| 修改已保存、结果仍旧 | 重载项目，用真实关节/模型报告核对，勿仅凭文件内容认定已生效 |

继续阅读[SDFormat 1.7关节规格](https://sdformat.org/spec/1.7/joint/)可查看其它关节类型。

## 原生辅助工具的退出流程

本课通信工具先核对编译SDK与实际Transport动态库均为Classic 11.15.1，并检查兼容层需要的符号；不匹配时在Transport初始化前报错。主线程随后持有一个未连接的Connection，再初始化通信。这个持有者保证异步回调不会成为共享IOManager的最后一个所有者。通信结束或出现异常时，先执行Transport fini，再在主线程调用公开IOManager.Stop并等待IO线程结束，最后释放订阅、发布器、节点和持有者；回调使用的对象一直保留到这两个停止屏障之后。

这段流程只负责独立辅助进程的资源寿命，插件宿主中不执行全局Transport退出。原有命令参数、测量输出与每次控制只发布一次的规则保持；它不写入预测姿态、力或轨迹。编译缓存包含本课变更的C++源码与SDK/链接参数，保存源码后须重新准备或重载。设置`GAZEBOTEACH_IO_DIAGNOSTICS=1`可在标准错误流保留实际IO join证据，不混入实验数据输出。
