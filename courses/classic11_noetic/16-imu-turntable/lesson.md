# IMU转台：姿态、角速度与比力

绿色刚体停在空中，速度为零，加速度计为什么仍读到约9.81 m/s²？让它绕竖直轴旋转，四元数在变化，陀螺仪却可以近似保持常数；另一个真正自由下落的探针又会读到什么？本课用四个转台状态和一个自由落体对照，把这些问题分开回答。

**IMU（惯性测量单元）**通常包含陀螺仪和加速度计；具体设备还可能组合其它传感器与姿态估计算法。这里使用Gazebo Classic原生imu传感器与Noetic观测插件，输出sensor_msgs/Imu，不需要先学状态估计、导航或写C++插件。

## 先看三种不同物理量

请在平台打开的本课终端运行：

```sh
rostopic type /lesson16/imu
rostopic echo -n 1 /lesson16/imu
python3 lab.py observe --seconds 3
python3 lab.py ready
```

| 消息字段 | 表示什么 | 单位与注意事项 |
| --- | --- | --- |
| orientation | 传感器相对参考方向的姿态四元数 | x、y、z、w四分量，没有角度单位 |
| angular_velocity | 传感器轴下的角速度 | rad/s，不是姿态角 |
| linear_acceleration | 本实现输出的比力 | m/s²，不直接等于世界坐标二阶位置导数 |
| 三组covariance | 各组数据的3×3协方差信息 | 全零按ROS消息约定表示未知，不是误差已知为零 |
| header.stamp / frame_id | 本条数据时间与传感器坐标系标签 | 仿真时间；标签不自动生成TF |

observe只读、按墙钟限时，不改变模型。暂停时没有新传感器更新，不要把没等到消息直接诊断为网络断开。字段约定可查[ROS Imu消息](https://github.com/ros/common_msgs/blob/noetic-devel/sensor_msgs/msg/Imu.msg)，数据解释可读[REP145 IMU约定](https://github.com/ros-infrastructure/rep/blob/master/rep-0145.rst)。

## 世界轴、机体轴和安装位置

**世界坐标系W**固定在场景中，+Z向上；**传感器坐标系B**随IMU一起旋转。本课sensor、link坐标原点与刚体质心重合，安装旋转为零，所以B也与imu_link轴一致。正立时两组轴重合，倾斜后便不同。

令R表示把B中的向量转到W的旋转矩阵，那么同一个角速度有两种表达：

```text
omega_B = Rᵀ omega_W
```

Rᵀ是逆向旋转，不是给物体施加另一个运动。给模型设置世界Z轴角速度后，消息不总会把它写在angular_velocity.z：还要看传感器此刻怎样倾斜。本课正式正反转阶段保持正立，使这个比较可直接读懂；倾斜静止阶段单独研究重力方向。

frameName=imu_link只填写消息标签。换成world不会自动把机体角速度或比力转到世界轴，也不会向TF广播世界到IMU的变换；TF在第24课展开。程序读实际传感器和模型状态，不能用标签字符串充作变换证据。

本课的信息流如下，控制命令与观测数据分开：

```text
阶段边界的一次初始位姿/速度设置
  → ODE真实刚体运动
  → ImuSensor读取姿态与速度、计算比力并换到传感器轴
  → Noetic IMU插件
  → /lesson16/imu
  → 只读观察或与独立模型状态比较
```

自由落体探针使用同类传感器和自己的数据通道，实际测量不会由上表的预测值生成。

## 加速度计读的是比力

设a_W为IMU所在点的世界运动加速度，g_W=(0,0,−9.81) m/s²。本课零噪声实现的关系为：

```text
f_B = Rᵀ (a_W − g_W)
```

**比力（specific force）**可以理解为按质量归一化的非重力作用量，以传感器轴表达。正立静止时a_W≈0，因此f_B≈(0,0,+9.81)，而不是全零。自由落体理想情况下a_W≈g_W，因此比力接近零；静止与自由落体在世界加速度和加速度计读数上恰好不同。

本课用link/gravity=false禁止重力推动这个刚体下落，使它在没有地面接触的情况下保持a_W≈0，便于隔离姿态变量。**世界重力仍为−9.81，原生IMU仍减去世界重力**，所以这不意味着比力归零，也不代表真实装置能够凭这个设置悬浮。这个假想夹具用于教学，平台没有制造真实反重力或电机闭环。

原生实现通过世界速度的有限差分估计运动加速度，再转到传感器轴并减去世界重力，见[Gazebo 11 ImuSensor](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/sensors/ImuSensor.cc)。重设位姿或速度附近可能出现差分瞬态，应留出保护时间再比较稳定窗口，不能拿那一帧冲击值代表静止读数。

## 四个转台状态，先写预测

默认转速幅值为0.6 rad/s，倾角为绕+X轴roll=30°。本课采用右手旋转约定，正roll把机体+Y向世界+Z方向转动。

| 阶段 | 操作后的理想状态 | 陀螺仪omega_B | 比力f_B |
| --- | --- | --- | --- |
| 正立静止 | roll=pitch=yaw=0，无速度 | (0,0,0) | (0,0,9.81) |
| 倾斜静止 | roll=phi，无速度 | (0,0,0) | (0,9.81sin(phi),9.81cos(phi)) |
| 正向yaw | 正立，绕世界+Z自由转动 | 约(0,0,+omega) | 约(0,0,9.81) |
| 反向yaw | 正立，绕世界−Z自由转动 | 约(0,0,−omega) | 约(0,0,9.81) |

phi=30°时，倾斜比力约为(0,4.905,8.496) m/s²，模长仍约9.81；倾角改变的是轴上的分配。yaw旋转围绕重力方向，不使这根竖直向量在正立机体系中改变方向。传感器位于质心，避免把偏心安装引起的转动加速度混入第一轮比较。

第五个实验使用旁边独立的freefall_probe，重力开启、IMU也位于其质心，消息为`/lesson16/freefall_imu`、frame为freefall_link。验收从世界(2,0,3) m重新零速度释放，只在碰到地面前的窗口采样：它的世界速度向下增长，a_W≈g_W，而加速度计f_B≈0。探针落地后又有接触支持，不能把落地后的数据混进自由落体窗口。这个真实对照将“重力禁用的悬浮夹具”与“重力作用下的自由下落”区分开，不靠相同外观猜测运动状态。单独执行一次echo可能读到已经落地的数据，要研究下落过程须使用本轮验收的明确释放与时间窗。

```sh
python3 verify.py
```

验收在各阶段边界明确设置转台初始姿态、零线速度与所需世界角速度，并对自由落体探针做一次明确释放；随后由ODE自由推进，再读取真实IMU与独立模型状态。它不会连续把位姿写成预定动画，也没有电机调速反馈。结束恢复进入验收时两个模型的位姿、速度和原暂停状态，世界时间不会倒回；测量期间不要拖模型或同时运行另一个控制命令。

转台每阶段避开前0.2仿真秒，取得至少50条不同时间戳数据、跨度至少0.6 s；角速度各分量误差小于0.02 rad/s，比力各分量误差小于0.05 m/s²。自由落体避开前0.15 s，取得至少30条、跨度至少0.3 s，并在释放后0.65 s前完成，另查实际下落位置和速度；同时悬浮转台仍提供+g对照。两类窗口都检查四元数、消息字段与按仿真时间估计的80到120 Hz频率，不把保护期或重复时间戳充作有效样本。

原始消息、独立状态及分项结果保存在当前会话的imu-verify-唯一编号.json，终端打印trace_path；可用`python3 verify.py --report build/my-imu-check.json`指定个人报告。自动通过说明这些离散窗口符合当前模型，不能代替每一物理步的连续真值或真实硬件精度标定。

## 自己操作转台

```sh
python3 turntable.py --speed 0.6
python3 turntable.py --speed -0.6
python3 turntable.py --speed 0
python3 turntable.py --speed 0 --tilt 30
```

speed单位rad/s，允许−1.5到1.5；tilt单位度，允许−60到60，表示绕+X的初始roll。操作工具允许正立自转或倾斜静止，不同时开启非零speed与非零tilt，避免将一般非主轴自由运动混入这个固定对照。命令会暂停本课世界，把转台放到(0,0,1) m、yaw=0，建立规定初始姿态与速度，然后恢复原暂停状态；它是一次明确的初始化，不能把连续重复调用当成真实控制器。原来暂停时，点击“继续”后才观察到运动。

正反向命令从规定初始姿态开始，所以再次执行可能产生姿态跳变；这段重设不计入连续运动证据。想停止并研究倾斜，使用speed=0。Rᵀ投影公式适用于更一般的姿态，但本课操作不将倾斜与非零转速混合；正式旋转窗口只对正立绕Z运动作验收。

## 四元数不是四个欧拉角

ROS消息按(x,y,z,w)记录四元数。单位四元数满足`x²+y²+z²+w²≈1`；恒等姿态为(0,0,0,1)。正立绕Z转过psi时，预测为`(0,0,sin(psi/2),cos(psi/2))`。q与−q表示同一方向，不能因为四个分量一起换符号就宣布姿态翻转。

**roll、pitch、yaw（RPY）**是方便描述姿态的三个角。本课使用`R=Rz(yaw)Ry(pitch)Rx(roll)`的约定；它们不是一般情况下三个陀螺仪分量的直接积分。yaw在±pi处环绕，pitch接近±90°时欧拉角表示还会出现奇异性；四元数避免了这组角度参数的表示奇异，但仍需保持单位长度与约定一致。

本实现的orientation直接来自仿真刚体姿态及设定参考方向，不是把带噪陀螺仪积分、融合后得到的导航估计。因此短时间姿态与gyro吻合，不证明已经实现一个能长期无漂移的真实IMU姿态算法。

不了解旋转矩阵和四元数，可先看[Eigen官方几何表示教程](https://eigen.tuxfamily.org/dox/group__TutorialGeometry.html)中的旋转表示；本课使用的是这些数学概念，不要求先安装Eigen或编写C++。

## 初始参考与协方差要看实际实现

本课固定initialOrientationAsReference=false，使Noetic插件将原生姿态参考设为世界恒等方向。若设为true，该插件保留传感器加载时的初始参考；它不是每次运行turntable命令都重新标零，也不把机体系加速度自动变成初始坐标系分量。该配置在正式课包中保持固定，见[Noetic IMU插件](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/noetic-devel/gazebo_plugins/src/gazebo_ros_imu_sensor.cpp)。

本课native噪声与插件gaussianNoise都为零，先研究确定的几何与力学。插件对三组covariance对角填写gaussianNoise²，所以这里全零；按ROS消息定义，这表示未提供协方差，不能解释为已知绝对无误差。某组covariance[0]=−1则表示不提供这一组估计，使用者应忽略对应字段，不能把两种情况混为一谈。

原生传感器目标100 Hz，插件updateRateHZ设为200 Hz只是发布限速上界，给原生采样调度留出余量；它不会把100 Hz数据变成200条独立测量。实际频率从不同header时间戳的首末跨度计算，电脑墙钟接收频率还受实时因子影响。重复时间戳不算新采样。模型服务查询、原生连杆数据和传感器调度各有时间，不能把异步查询的姿态当作一条IMU消息的严格同时真值。

插件的gaussianNoise还会直接给四元数四个分量、角速度和加速度加随机数，不重新归一化四元数；同一个数值跨不同单位的字段也不是完整的实体传感器误差模型。因此不通过随意增大它来声称“更真实”。噪声、偏置与融合可以拓展，但正式固定结构不开放这些修改。

## 单变量实验与文件

parameters.json是本课可改参数，world.sdf保持固定夹具与安装方式。请通过以下命令一次只改一项，再重载并验收：

```sh
python3 lab.py config --speed 0.9
python3 lab.py config --tilt 45
```

speed参数是正式正反转阶段的幅值，允许0.2到1.5 rad/s；tilt允许10到60°。速度提高时，相同仿真时间内yaw变化更大，比力仍应遵循当前姿态与运动加速度；倾角30→45°时，静止f_y与f_z都约6.937 m/s²。文件保存不会自动改变正在运行的实验，需重载。

## 故障与独立挑战

| 现象 | 先检查什么 |
| --- | --- |
| 静止时加速度不是零 | 当前字段是比力，先计算Rᵀ(0−g) |
| 倾斜后读数出现在Y轴 | 本课绕+X倾斜，重力在机体系中的投影改变 |
| 旋转方向与符号不符 | 世界/机体轴、右手约定、rad与度、实际姿态 |
| 四元数分量变号 | 是否q与−q等价，而非直接比较四个数 |
| 设置速度后画面不动 | 世界是否仍暂停，是否在本课终端、真实状态是否更新 |
| 提高update_rate却没更多消息 | 原生采样与插件updateRateHZ两层限制、仿真和墙钟频率 |
| covariance全零 | 是当前插件写出的未知协方差约定，不是实测方差为零 |
| 换frameName后数值没旋转 | 它只是标签，不能代替坐标变换与TF |

独立挑战：在一次没有重设的正立旋转中记录两秒真实IMU数据，按时间戳对omega_z做数值积分，再用首末四元数计算相对yaw，比较两者。提示一：去除重复时间戳；提示二：处理yaw的±pi环绕与q/−q等价；提示三：只在本课正立绕Z条件下使用这个简化积分，不把它扩展成任意三维姿态算法。写明差异来自采样、误差还是阶段重设，不能仅凭终点接近就宣称整段连续轨迹都已验证。
