# IMU转台：只读坐标推导与测量边界

本页保留推导、示例答案和实现说明，不覆盖个人parameters.json或world.sdf。预测公式与实际观测分开，最终以本轮真实数据、独立模型状态和报告为准。

## 坐标与三种输出

R将传感器轴B中的向量转到世界轴W；Rᵀ将世界表达转回传感器表达。姿态四元数描述B相对参考方向的旋转，陀螺仪与加速度计则是按B轴表达的向量。相同frame_id不表示这三个字段可以当作同一种物理量相加。

```text
omega_B = Rᵀ omega_W
f_B = Rᵀ(a_sensor,W − g_W)
g_W = (0,0,−9.81) m/s²
```

本课sensor原点、link原点与质心重合，所以不加入偏心安装的向心与切向加速度。若将真实安装位置移开旋转轴，传感器点加速度会多出与角速度、角加速度和力臂有关的项；不能只改变frameName或插件xyzOffset就认为已经完成这种物理安装实验。

原生[ImuSensor](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/gazebo/sensors/ImuSensor.cc)用实际速度的有限差分求运动加速度，再旋转到IMU轴并减去世界重力，角速度也由世界表达转到IMU轴。它独立使用世界gravity，即使link/gravity=false也保留这一项。禁用刚体的重力运动与改变传感器解释的世界重力是两件事。

## 静止倾斜的具体数值

采用`R=Rz(yaw)Ry(pitch)Rx(roll)`，只有roll=phi时：

```text
Rx(phi) = [1,      0,        0
           0, cos(phi), −sin(phi)
           0, sin(phi),  cos(phi)]

f_B = Rx(phi)ᵀ (0,0,9.81)
    = (0, 9.81sin(phi), 9.81cos(phi))
```

| roll | f_x / m/s² | f_y / m/s² | f_z / m/s² | 模长 / m/s² |
| --- | --- | --- | --- | --- |
| 0° | 0 | 0 | 9.81 | 9.81 |
| 30° | 0 | 4.905 | 8.49571 | 9.81 |
| 45° | 0 | 6.93672 | 6.93672 | 9.81 |
| 60° | 0 | 8.49571 | 4.905 | 9.81 |

正立、无直线运动、绕Z旋转时，重力方向在机体中不变，gyro约为(0,0,±omega)，比力仍约(0,0,9.81)。这并不说明任何转动物体的加速度计都不受旋转影响：本课特意让IMU在质心并使用这种轴向运动。

自由落体中a≈g，所以f≈0；静止中a≈0，所以f≈−Rᵀg。本课另设gravity=true的freefall_probe，零速度释放后，在碰地前同时检查真实下落状态与近零比力，作为第五阶段对照。落地后的接触力和碰撞瞬态属于其它阶段，不能混入这个窗口。本课gravity=false的悬浮转台用于隔离姿态变量，也不作为一个真实机械装置的动力学模型。

## 四元数与角速度

ROS四元数顺序为(x,y,z,w)，单位长度是有效旋转的必要条件。绕单独Z轴角psi的四元数为`q=(0,0,sin(psi/2),cos(psi/2))`；绕X轴phi为`q=(sin(phi/2),0,0,cos(phi/2))`。一般组合要遵守旋转相乘顺序，不能把三个单轴四元数分量逐项相加。

q与−q是同一姿态。比较两单位四元数时，使用绝对内积来消除符号差异，例如相对角大小为`2acos(clamp(|q1·q2|,0,1))`；浮点舍入时夹到定义域，不能把|dot|略大于1的误差当作新姿态。原始模长仍应单独检查，归一化比较不能替坏数据遮掩。

在本课正立绕Z的简化条件下，yaw随仿真时间约满足`delta_yaw=omega×delta_t`。omega=0.6 rad/s、2 s时约1.2 rad，即68.75°；omega=0.9时约1.8 rad，即103.13°。这些是预测；需要用实际消息时间和真实gyro积分比较，不能把命令幅值直接代替实测角速度。

一般三维旋转时，机体角速度分量不等于roll/pitch/yaw三个导数。RPY有顺序依赖、环绕及pitch奇异问题；本课用四元数和限定轴向运动作可解释比较，不声称已实现完整姿态积分或导航滤波器。

## 参考方向、偏置参数和协方差

Noetic [gazebo_ros_imu_sensor](https://github.com/ros-simulation/gazebo_ros_pkgs/blob/noetic-devel/gazebo_plugins/src/gazebo_ros_imu_sensor.cpp)在initialOrientationAsReference=false时将原生worldToReference设为恒等方向。本课由此报告相对世界方向的仿真姿态。true保留原生传感器加载时的初始参考，后续不是每次操作都自动重新标零；它不改变gyro和比力按传感器轴表达的约定。

orientation来自仿真姿态，不是陀螺仪累计再融合出的估计。frameName只写header，不完成TF广播；本课安装旋转和rpyOffset为零。该插件的rpyOffset只左乘orientation，没有同步旋转gyro/加速度；xyzOffset在这里未用于加速度安装点计算。因此这些字段不适合被任意改动来代替一个完整、坐标一致的安装模型。

插件把gaussianNoise独立加到四个四元数分量及两组三轴向量，不再归一化四元数，并把三个协方差矩阵的对角都写成同一个sigma²。本课sigma=0，输出矩阵全零。按照[Imu消息定义](https://github.com/ros/common_msgs/blob/noetic-devel/sensor_msgs/msg/Imu.msg)，全零表示协方差未知；某组第0项为−1表示这组估计未提供。不能把打印出来的协方差当作本轮实测误差统计，更不能据此推导真实硬件的完整误差模型。

三组协方差按行优先存储3×3矩阵；orientation协方差对应小角度误差的三个轴，不是一个4×4四元数分量协方差。当前默认零噪声几何实验没有验证bias、温漂、随机游走、磁航向或多传感器融合。

## 输入、初始化与真实采样流程

parameters.json只保存speed_rad_s与tilt_deg，world.sdf保持固定结构。config工具只明确修改参数，保存后重载；prepare检查依赖与输入，不覆盖个人练习。系统加载原生imu及ROS插件，实际刚体状态进入传感器采样，最后发布ROS Imu。

turntable工具在阶段边界暂停本课世界，一次设定初始roll、yaw参考、零线速度和世界Z角速度，再恢复原暂停状态。随后的旋转由ODE推进，工具没有连续写姿态或用电机力矩维持目标。验收也采用相同的明确初始化，跳变不算连续运动；窗口避开刚切换后的差分瞬态。

转台四阶段依次为upright_static、tilted_static、positive_yaw、negative_yaw，分别检验零角速/正立比力、倾斜比力投影、正反角速及四元数随时间变化；再以独立探针做自由落体对照。程序同时读取独立的Gazebo模型姿态和速度，与IMU按实际时间靠近的观察比较；不能拿另一个时刻的姿态逐分量对照并宣称坐标变换错误。

转台每阶段保护期0.2仿真秒，之后至少50条唯一时间戳、首末跨度至少0.6 s。逐条gyro分量距预期小于0.02 rad/s，比力分量小于0.05 m/s²，四元数模距1不超过1e−6；静止姿态角误差小于0.005 rad，旋转窗口逐条展开yaw相对omega×时间差的误差小于0.02 rad。测得仿真频率须在80到120 Hz内，实际最小/中位/最大采样间隔另存，不伪造严格均匀采样。

第五阶段名为freefall，探针从(2,0,3) m零速度释放，保护期0.15 s，至少30条、跨度至少0.3 s，并要求在0.65 s前完成，避免混入落地。比力各分量小于0.05 m/s²，同窗悬浮参考至少20条、比力约(0,0,9.81)。独立位置与速度按`z=3−0.5gt², vz=−gt`比较，误差分别小于0.04 m、0.08 m/s，且z>0.5 m、vz<−0.5 m/s，防止把静止的零数组当作真实自由落体。

原生采样目标100 Hz，插件updateRateHZ=200只是更高的发布限速上界，避免再用同等上限过滤原生调度间隔的小幅变化，不增加原生测量数。测量频率按唯一header时间估计，不能把重复消息计成新数据。插件header来自Sensor.LastUpdateTime，原生比力所用连杆数据另有物理时间；异步服务查询也有请求前后时间边界。程序采用有界近时比较与离散轨迹检查，不宣称它们自动形成精确同时间戳的同步真值。

每阶段至少3次独立连杆状态比较落在有效IMU窗口内，查询前后仿真时间区间宽度不超过0.05 s，与最近IMU的间隔不超过0.06 s；姿态容差为`|omega|×(间隔+查询区间宽度)+0.02 rad`。这样明确计入已知时间不确定度，而不是要求异步查询的四元数与另一个时刻逐位相等。原始trace、状态查询边界与恢复误差保存在报告trace_path；可用verify.py的--report参数指定路径。

无论通过或失败，finally都尝试恢复进入时两个模型的真实位姿、线角速度和原暂停状态；位姿恢复允许四元数符号等价。若原来在运行，恢复后物理会继续，自由落体探针也可能继续下落，不能把稍后读数变化误当成状态没有设置成功。世界时间和原来经历过的运动不会被重演或倒回。真实传感器数据是离散采样，不等于所有物理步均有对应ROS消息。

## 独立挑战的提示

在正立、没有任何重设的连续转动中，按不同header时间戳取样，用梯形规则累计omega_z：

```text
delta_yaw_integrated += 0.5 × (omega_z[k]+omega_z[k−1]) × (t[k]−t[k−1])
```

另从首末四元数求相对yaw，正确处理±pi环绕和q/−q；比较积分与姿态变化，说明采样、时间对齐和误差容限。若窗口跨过turntable重设或模型复位，先分段，不能把跳变算作gyro应该积分出的运动。这个挑战只验证限定的单轴例子，不替代一般三维旋转积分算法。
