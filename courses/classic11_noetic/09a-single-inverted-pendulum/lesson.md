# L09选做A：用三处填空稳定单级倒立摆

## 你需要完成什么

一辆只能沿X移动的小车，上面铰接一根向上伸出的杆。杆稍微倾斜就会继续倒下；你要根据当前状态计算小车的水平推力，让它在直立附近恢复平衡。杆的铰链没有驱动力矩，只有小车受到一个水平力，这是**欠驱动系统**：两个运动自由度，只有一个控制输入。

本课已提供真实Gazebo模型、观测、控制时钟与实验工具。你只完成learner.py中的三个短函数：组成状态误差、计算反馈力、双向限幅。无需先学习ROS、编写插件或推导Riccati方程。先读懂每个量，再写几行代码即可开始实验。

默认reference_demo用独立参考控制器展示真实运动，**演示通过不代表作业完成**。三个TODO最初会明确报NotImplementedError；学生模式必须实际执行你保存的代码，函数检查与真实运动验收都通过才算完成。平台不会用参考解悄悄接替失败的学生代码，也不会覆盖learner.py。

## 先看状态，再看动作

本课把杆沿**上垂线**定义为θ=0，与基础课向下摆的几何角约定不同。绕+Y正转时，杆顶向+X倾斜。角度用rad，0.08 rad约为4.58°；不要把度数直接放进公式。

每次control收到真实关节观测字典observation：

| 字段 | 意义 | 单位 | 平衡目标 |
| --- | --- | --- | --- |
| x | 小车沿轨道的位置 | m | target_x，默认0 |
| xdot | 小车水平速度 | m/s | 0 |
| q1 | 杆相对上垂线的关节角 | rad | 0 |
| q1dot | 杆角速度 | rad/s | 0 |

相同倾角、不同角速度需要不同动作：已经快速倒下与正往回摆不是同一种状态。小车的位置和速度也要纳入，否则杆可能暂时竖住，小车却一路跑出轨道。这里直接使用模拟器的关节状态；本课暂不研究带噪声传感器或状态估计。

将角度包裹到[−π,π)，记为θ。状态误差顺序固定为：

```text
e = [x−target_x, xdot, θ, q1dot]
θ = wrap(q1)
wrap(a) = (a+π) mod (2π) − π
```

角度2π与0表示同一方向；包裹避免把绕一整圈后的微小偏角当成巨大误差。但包裹不等于允许任意姿态稳定，本课控制器只针对近直立区域。

## 给定K怎样把四个误差变成一个力

本模型的小车质量1 kg，均匀圆柱杆质量0.2 kg、全长1 m、半径0.02 m，杆质心在中点，绕质心Y轴惯量约0.016686667 kg·m²。它是有质量、有惯量的杆，不是基础课那根仅作外观的无质量示意杆。杆顶红球仅为visual方向标记，不增加碰撞、质量或惯量。轨道外观与地面提供视觉参照，真正的运动约束来自prismatic与revolute关节。

已按这组质量、几何、阻尼和坐标约定提供LQR增益。**状态反馈**就是每次读取状态，再根据误差产生控制力；LQR是在线性化模型上平衡状态误差与控制代价的一种设计方法。本课直接使用设计结果：

```text
K = [−14.14213562, −15.95141643, −92.53361631, −22.61484036]
u_raw = −K · e = −Σ K_i e_i
u = clip(u_raw, −15 N, +15 N)
```

| 增益 | 对应误差 | 单位 |
| --- | --- | --- |
| K₁ | 位置 | N/m |
| K₂ | 水平速度 | N·s/m |
| K₃ | 角度 | N/rad |
| K₄ | 角速度 | N·s/rad |

这是一个四维耦合反馈，不能把它理解成四个互不相关的“总向反方向拉回”。K含负数仍须保留公式最前面的负号。不要凭直觉把某个符号翻转，也不要照抄其它质量或坐标约定的增益。

例如只有θ=0.01 rad、其余误差为0时，公式给出u_raw=+0.9253361631 N：小车向杆倾斜的一侧加力。**这是代数算例，不是Gazebo实测。** 同时存在位置和速度误差时，其它项也会参与。

近直立线性化、有限推力和轨道长度共同限制适用范围。给定K不是从杆朝下任意起摆的保证；限幅后系统也不再是无限输入的理想线性闭环。本桥在杆角超出0.65 rad局部保护边界时将控制力置零，完整起摆必须另建扩展项目。不了解状态空间与LQR，可看[MIT的Cart-Pole讲解](https://underactuated.mit.edu/acrobot.html)和[LQR章节](https://underactuated.mit.edu/lqr.html)，本练习无需先完成这些推导。

## 控制时钟与真实运动信息流

控制每0.01仿真秒计算一次，即100 Hz；物理步长为0.001 s，即每次控制间隔有10个物理步。**零阶保持（ZOH）**指这10步内保持同一个控制力，下一次再根据新状态更新。它不是只施力1 ms、其余9步不给力，也不是依照现实墙钟随意更新。

信息流为：**真实关节位置/速度 → observation → state_error → feedback_force → clip_force → 小车水平力 → Gazebo物理推进 → 新的真实关节状态。** 控制器只输出力，不用改写杆的位置来“假装稳定”。

演示模式每12仿真秒显式开始一个新回合，交替使用正负小车位置与倾角，让你反复观察恢复过程；回合内还有短时外力扰动。学生验收逐回合只在开始时设置初态，随后靠反馈施力；不要把演示的周期性初始化误认为控制器在持续传送模型。

## 填空1：state_error

返回NumPy一维数组，形状为(4,)，顺序必须与K一致。

- 提示1：位置误差是当前位置减target_x，其余三个平衡目标为0。
- 提示2：先按上面的模运算包裹q1，再排列位置、水平速度、角度、角速度。
- 提示3：使用 `np.array([...])`；字典字段是字符串键，不要把q1dot误写成xdot，也不要返回(4,1)列数组。

## 填空2：feedback_force

把误差和给定K作内积，返回单位为N的Python float，暂不在这里限幅。

- 提示1：四项作用相加，最终只能得到一个水平力。
- 提示2：按u_raw=−ΣK_i e_i保留整体负号。
- 提示3：NumPy的 `@` 可表示一维向量内积，`*` 是逐元素乘法；返回四个数不能作为一个控制输入。

## 填空3：clip_force

将一个力限制在正的force_limit给出的双侧范围内，返回float。

- 提示1：正向和负向都要限制，中间的小力保持不变。
- 提示2：数学上为max(−F,min(F,u_raw))，不能只做上限。
- 提示3：可以使用 `np.clip`；使用传入的force_limit，不要把所有调用都写死为15。

桥接工具还会限制实际输出，但这层保护不能替代你的clip_force。函数检查会单独验证双向限幅，防止“物理演示碰巧没出问题”掩盖缺失实现。完整实现可单独打开“查看参考答案”，不会替你覆盖个人文件。

## 三个回合怎样判定

物理验收固定原有world.sdf，只修改learner.py的TODO。三个回合各10仿真秒，目标位置均为0，初始速度和角速度均为0：

| 回合 | 初始x / m | 初始θ / rad | 本回合4至4.25 s的外力 |
| --- | --- | --- | --- |
| 1 | +0.15 | +0.08 | 0 N |
| 2 | −0.15 | −0.08 | 0 N |
| 3 | +0.10 | −0.06 | +2 N水平力 |

每个采样点要求小车位置绝对值≤1.2 m、杆角绝对值≤0.35 rad，学生控制力绝对值≤15 N。第三回合的外力单独记录；它与控制力相加，合力不等于学生限幅值。

最后8至10 s还要检查四个状态的**均方根RMS**：`sqrt(mean(z²))`。位置、速度、杆角、角速度分别要求≤0.02 m、0.035 m/s、0.01 rad、0.04 rad/s。RMS保留稳态偏差，不能用先减均值的标准差代替。以上是本局部实验的验收条件，不是任意初态的稳定区域证明；30仿真秒也不保证等于30现实秒。

报告给出本次会话control/control.csv、status.json的绝对路径，保存真实状态、控制输出、扰动力、模式、源文件指纹和调用记录；学生通过报告为student-verification.json，参考演示为demo-validation.json。失败时先看本次错误和原始记录，不拿旧报告代替新结果。结束会读回确认原pause；不还原先前轨迹或仿真时间，原来继续运行时结束后也会继续演化。

## 独立挑战与排错

先不改物理模型，完成以下预测再用函数检查：只有θ=−0.01时反馈力应是什么符号？输入±25 N、限值15 N，输出应分别是多少？把限值改为3 N，函数是否仍正确？target_x=0.1、x=0.15时位置误差应为0.05 m，不能忽略传入目标。

通过后阅读报告：比较正负初态的恢复过程、短时扰动后误差和峰值控制力。一次通过只证明当前局部实验条件；不要只凭“杆没有倒”就认定所有状态都稳定。更大初角、长时间饱和和模型变更需重新设计并验证；完整起摆属于另建的扩展项目，不能直接沿用本题的局部保护桥。

| 现象 | 优先检查 |
| --- | --- |
| 演示能运行，学生验收不通过 | 当前模式、TODO、实际执行learner指纹；演示不计作业 |
| 方向明显相反、迅速倒下 | 上垂线零位、rad、K的顺序及整体负号 |
| 返回值是四个数 | 是否用了逐元素乘法，反馈应为标量内积 |
| 小正力正确，大负力错误 | clip是否只限制正方向、是否使用传入限值 |
| 文件已保存、运行仍像旧代码 | 重载并核对实际执行指纹，不用旧回合证明新代码 |
| 杆暂时竖住但小车漂走 | 是否遗漏位置/水平速度误差、是否误用了目标符号 |
