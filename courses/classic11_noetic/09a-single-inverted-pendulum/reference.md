# 参考：单级倒立摆的三个函数

本页只读，不覆盖learner.py。参考控制器独立用于reference_demo；作业通过仍要求student模式实际执行当前个人文件，并通过函数与真实运动检查。

## 约定与模型

小车沿+X移动，杆绕+Y转动；θ=0是向上直立，θ>0时杆顶向+X倾斜。观察字典中的q1已经按本模型定义为这个直立零位的真实关节坐标；不要沿用基础课θ0+q的0.2 rad偏置，也不要把向下铅垂当零位。

状态与目标为：

```text
s = [x, xdot, wrap(q1), q1dot]
s_target = [target_x, 0, 0, 0]
e = s−s_target
```

顺序与单位分别为m、m/s、rad、rad/s。wrap(a)=(a+π) mod (2π)−π，π与−π是同一朝向；在本课近直立区域不会因包裹发生跳变。wrap不是全局起摆算法。

标称小车质量M=1 kg；杆质量m=0.2 kg、全长L=1 m、半径r=0.02 m。杆质心到铰点ℓ=L/2=0.5 m，圆柱绕质心横轴惯量：

```text
I_C = m(L²+3r²)/12 = 0.0166866666667 kg·m²
J = I_C+mℓ² = 0.0666866666667 kg·m²
```

与无质量示意杆加集中球不同，本杆的质量分布已进入给定K的设计。杆顶红球只有visual，用于辨认杆端方向，没有额外collision或质量/惯量；仍按上述均匀圆柱计算。小车阻尼0.05 N·s/m、铰链阻尼0.002 N·m·s/rad，关节摩擦为0，g=9.81 m/s²。随意改质量、长度、阻尼或坐标符号后，不能保证原K仍具有同样效果。

## 给定反馈的意义与边界

在上垂线平衡附近，以δ状态线性化为 `ė≈Ae+Bu`，再按状态与力的二次代价设计反馈。本课提供Q对角项[20,2,100,2]、R=0.1对应的K：

```text
K = [−14.14213562, −15.95141643, −92.53361631, −22.61484036]
u_raw = −K e
```

这些增益按顺序具有N/m、N·s/m、N/rad、N·s/rad的单位；Q/R的数值也依赖采用的单位与状态排列。它不是四个互相独立的比例控制器。整体负号和K内各项符号都必须保留；不要因看到负增益就自行“修正”为正数。

离线设计检查只针对匹配的线性模型：可控性秩为4，CARE残差约6.83×10⁻¹²，0.01 s零阶保持线性闭环谱半径约0.98405。它们不是Gazebo物理实测，也不是对非线性、饱和与任意初态的全局稳定证明。学生无需实现CARE；这些背景用于说明K来自何种模型。[MIT LQR](https://underactuated.mit.edu/lqr.html)给出完整推导，[Cart-Pole讲解](https://underactuated.mit.edu/acrobot.html)讨论欠驱动与局部平衡。

控制每0.01仿真秒更新一次，输出在其间10个0.001 s物理步中保持。真实施加的是小车水平力，铰链没有控制力矩；回合开始后不靠持续修改状态来稳定。默认参考演示每12仿真秒显式初始化一个新回合，不能把这种演示循环误当作学生试验中的连续控制动作。

## 完整参考实现

保留已有control流水线，只需要把下面三个函数的实现对应到个人TODO处。代码展示不自动写入个人副本。

```python
import numpy as np

K = np.array([-14.14213562, -15.95141643,
              -92.53361631, -22.61484036])
FORCE_LIMIT = 15.0


def state_error(observation, target_x=0.0):
    angle = (observation["q1"] + np.pi) % (2*np.pi) - np.pi
    return np.array([observation["x"]-target_x,
                     observation["xdot"], angle,
                     observation["q1dot"]])


def feedback_force(error):
    return float(-K @ np.asarray(error, dtype=float))


def clip_force(force, force_limit=FORCE_LIMIT):
    return float(np.clip(force, -force_limit, force_limit))


def control(observation, target_x=0.0):
    return clip_force(feedback_force(state_error(observation, target_x)))
```

state_error把字典转换为有固定顺序的一维误差；feedback_force只作未限幅内积；clip_force单独处理双侧范围。control组合三步后才返回实际请求力。分开检查这三步，是为了避免桥接工具的硬限幅掩盖学生漏写或错写限幅的情况。

## 可手算的函数检查

下表均为代数预期，不是物理测量。单一误差时其它分量为0，target_x=0。

| 输入条件 | 预期结果 |
| --- | --- |
| 全部状态为0 | e为四维零数组，反馈力0 N |
| q1=0.01 rad | 未限幅反馈力+0.9253361631 N |
| q1=−0.01 rad | 未限幅反馈力−0.9253361631 N |
| x=0.15 m、target_x=0.1 m | e第一项0.05 m |
| q1=2π+0.01 rad | e角度项约0.01 rad |
| clip输入+25/−25 N、限值15 N | 分别+15/−15 N |
| clip输入+4/−4 N、限值3 N | 分别+3/−3 N |
| clip输入+0.5 N、限值3 N | 保持+0.5 N |

NumPy的 `K*e` 会返回向量，不能冒充内积。双侧限幅也不能只写min(F,u)，那样负向超限不会被处理。返回有限标量、保持接口与状态顺序，比仅删掉TODO标记更重要。

## 当前真实验收契约

本练习固定标称world.sdf，要求磁盘world与课程模板一致、运行中world指纹也匹配；它还从SDK读取实际质量、杆惯量、阻尼、物理步长和重力进行核对。当前作业只修改learner.py，不以改变物理模型来绕过控制练习。

先执行当前learner的函数行为检查，内容含正负角度包裹、非零target_x、混合状态及各坐标分量的反馈、双向/不同限值的clip和已有control流水线。桥接硬限幅不能替代函数限幅；真实回合中还比较Python输出力与实际限幅后控制力，避免后者掩盖前者越界。

三个10仿真秒回合的初态为(x,θ)=(+0.15,+0.08)、(−0.15,−0.08)、(+0.10,−0.06)，初速度均为0；第三回合在episode_time_s为4至4.25 s时加入+2 N水平扰动力。这里是**每个回合的相对时间**，不是世界时钟必须等于4 s。每回合只在开始时初始化实际关节位置/速度，随后由真实力推进。

| 检查 | 判定条件 |
| --- | --- |
| 执行证据 | student模式、当前learner源指纹一致、无Python错误；每0.01仿真秒恰好一次控制回调，完整回合至少990个实际样本 |
| 角度与几何 | 杆世界轴方向分别与sin(q1)、cos(q1)比较，误差≤0.002，校核上垂线零位及正方向 |
| 回合初态 | 第一条真实记录的x与q1分别距要求初态≤0.001 m、0.001 rad |
| 全程边界 | 所有采样点的绝对位置≤1.2 m、绝对杆角≤0.35 rad、绝对控制力≤15.000001 N |
| 输出限幅 | Python输出力与桥接后的控制力差≤10⁻⁶ N；外部扰动力另列，合力可以与控制力不同 |
| 末8至10 s RMS | x≤0.02 m、xdot≤0.035 m/s、θ≤0.01 rad、角速度≤0.04 rad/s |

RMS为该状态样本平方均值的平方根，单位与原状态一致；它会包含非零平均偏差，不是高度或角度的标准差。末窗数学范围为闭区间[8,10] s，时间端点使用10⁻⁷ s浮点容差，远小于0.01 s采样间隔，避免将略小于8的舍入结果错误排除。边界与容差只定义当前有限回合的判定，不代表连续时间所有状态的误差界或全局稳定保证。

原始control.csv和status.json位于本次应用会话目录的control子目录，报告给出绝对路径。CSV保留原生状态、几何方向、每tick回调、python_force_N、command_force_N、disturbance_N和applied_force_N；后者包含扰动，不能仅因它大于学生限幅值就判clip错误。成功学生报告为student-verification.json，参考报告为demo-validation.json。

`python3 lab.py observe --seconds 3`是独立的无学分观测，按一个非零初态执行当前控制器，结果保存raw-observation.json；observe允许1至15仿真秒，不代替三回合验收。实验或观测结束时读回确认恢复原pause，确认失败不记作成功；保留已经发生的轨迹与时间。原pause=false时世界自然继续运行，不停留在报告末帧。
