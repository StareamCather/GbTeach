# 参考推理：Qt操作、原生控制与真实物理

## 作用域和生命周期

GUIPlugin是加载进gzclient的QWidget。它获得插件配置并创建界面，不直接取得服务端World对象。world/gui下的声明、GUI插件注册类型和实际客户端缺一不可。

Classic的RenderWidget.AddPlugin把插件设为glWidget子控件、调用Load后show。本课SDK的GUIPlugin及其PluginT基类没有Init/Reset虚方法，不能复制VisualPlugin或SensorPlugin的override。生命周期应围绕Load、Qt控件和析构解释；协议若保留init_count=0，仅是兼容观察字段，不代表存在一个未触发的Init回调。客户端重开产生新实例，但服务端世界和物理状态继续存在。

## 正确的信息流

真实点击 → QPushButton.clicked → GUI线程槽函数 → 操作条件检查 → 单次原生WorldControl → 服务端实际执行 → 原生WorldStatistics回调保存缓存 → GUI线程QTimer读取/确认目标 → 更新标签与按钮状态。

Transport接收函数不直接使用QWidget。定时器在GUI线程中运行，负责读取缓存、更新控件和处理自动演示队列。线程分工避免把后台消息回调误当作界面线程，也避免在GUI线程阻塞等待网络。

## moc参与什么

Q_OBJECT声明需要Qt的元对象代码。moc从头文件生成临时C++文件，它应与插件实现共同编译链接；本例编译后移除临时moc文件，实际命令仍记在准备记录中，不将生成物作为手改模板。准备程序从Qt5Core的pkg-config host_bins定位本机moc，避免未选版本的通用qtchooser入口，不改变全局QT_SELECT。出现元对象、vtable或槽相关符号错误，先检查实际moc/链接命令，不通过删除宏掩盖缺失构建步骤。

## 两个参数的不同后果

step_count决定一次真实multi_step请求的整数步数；display_decimals只决定时间标签的小数位数。后者的字符串可能舍入，但原生模拟时间、迭代次数和物理状态不因此改变。

每个物理步长为.001s，100步是.1s，200步是.2s。GUI每50ms刷新不等于世界统计只产生20Hz，也不等于物理每50ms只推进一步。多次刷新读到同一份原生数据是正常现象，应区分原始时间与显示格式。

## 首次自由落体预测

新世界从暂停初态开始，方块质心z0=2m、初速度0、g=9.8m/s²，边长.4m。接触前连续模型为z=2−.5gt²，因此首次100步约1.951m，首次200步约1.804m。

以半隐式欧拉说明离散误差，z_N=2−g*h²*N*(N+1)/2，h=.001时相应为1.95051m和1.80302m。真实结果还需由原生位姿确认，预测式不是设置状态的方法。地面支持高度的质心约.2m；触地后不再用同一个自由落体式解释接触。

第二次步进保留已有速度，应使用当前z、v作为初态。想比较两组从静止释放，应分别重载新场景，不把GUI重开误当作世界重启。

## 一次请求，多个证据

按钮被点击、槽函数被执行、控制消息被发布、服务端达到目标，是不同事件。面板可记录点击/发布/完成序号，但序号本身不是世界真值。

步进请求携带pause=true和multi_step=N。发送后面板保持busy，依据真实统计中的时间与迭代目标确认完成；没有反馈时不盲重放。重复发送是额外动作，不能按幂等暂停命令处理。

若其他控制源在期间继续世界或重置时钟，应先识别实际边界变化并报错。不能把实际时间裁剪到目标，或在标签上补上缺失的步数。

## 自动演示和真实鼠标

课程工具可以排队后在GUI线程调用同一个QPushButton.click，用于有限演示和检查槽到世界的链路。它与真实鼠标命中可见按钮不是同一个证明。

独立图形验收需定位本次gzclient，读取属于本面板的按钮矩形，对真实X11窗口发送鼠标事件，再从原生世界统计和实体状态核对。截图说明面板和场景可显示；实际状态变化才说明控制效果。不能把RPC回执当作鼠标验收，也不能把界面标签当作独立物理真值。

## 暂停与恢复边界

物理暂停后，Qt事件循环和渲染仍可以继续；面板应能显示和响应控件。关闭GUI会移除这一客户端界面，服务端不应随之退出。重开面板重新订阅当前世界，不能暗中重置方块或时间。

演示正常结束尝试恢复入场暂停状态，但已经推进的时钟、速度、位置和消息历史不能回填。错误现场应保留真实数据；不以改写物理状态制造“执行前后一致”。

## 挑战提示

秒数输入换算整数步数时，应先确定ceil、floor或拒绝非整数倍的规则，以及最小值、上限、非有限值和busy期间行为。将决定清楚写入教材，再用真实世界验证一次发布与完成边界。

“反馈陈旧”应以接收消息的新旧和本地等待时长为依据，不能把已暂停但正常送达的统计误判成故障。暂停的模拟时间可以不变，数据接收仍可能持续。
