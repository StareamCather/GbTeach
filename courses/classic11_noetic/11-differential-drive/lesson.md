# 差速小车：轮子转了，车身走了多少

## 同一辆车的三种运动

两侧轮子同速，小车前进；两轮反向，小车原地转；两轮同向但速度不同，小车沿弧线转弯。本课用一辆两驱动轮、后部球形支撑的小车，分别观察直行、自转和圆弧，学习从车体速度算轮速，再用真实轮转角估计行程，并与Gazebo世界中的实际运动比较。

第10课通过转矩与PID研究单关节动力学；本课采用Classic自带DiffDrivePlugin直接设置理想轮关节速度，由轮地接触推动车身。它没有本课另设的转矩PID，也不把车体位置写成预定轨迹。工具会准备通信与测量程序，不要求先掌握ROS或编写插件。

## 先约定坐标与单位

车体坐标X向前、Y向左、Z向上，遵循右手系；从上方看，绕+Z逆时针转为正。v表示车体前向速度，单位m/s；Ω表示车体偏航角速度，单位rad/s；左右轮角速度ωL、ωR用rad/s。不了解右手系，可看[REP103官方坐标约定](https://github.com/ros-infrastructure/rep/blob/master/rep-0103.rst)。这里借用坐标约定，不需要运行ROS。

两轮半径r=0.1 m、轮宽0.01 m，左右轮轴中心位于y=+0.18、−0.18 m，轮距b=0.36 m，两关节正轴均为+Y。较窄轮面用于贴近每轮单点接触的运动学近似；真实轮地接触与数值求解仍会留下偏差。本课把两轮轴锚点的中点作为运动学参考点，并沿车身前方定义航向。车身质心向后偏置用于稳定支撑，它不是运动学参考点；转弯时，离转动中心不同距离的点本来就有不同轨迹。后部低摩擦小球是简化支撑，不是完整的可转向脚轮机构。

## 从车体速度算左右轮速

在轮子沿行进方向纯滚动、没有侧滑的平面近似下：

```text
ωL = (v − Ωb/2)/r
ωR = (v + Ωb/2)/r

反算：v = r(ωR+ωL)/2
      Ω = r(ωR−ωL)/b
```

正向左转时右轮更快。这里的r是半径，b是两轮中心之间的全轮距；把直径当半径或把半轮距当b都会改变结果。[Dellaert与Hutchinson的差速运动学教材](https://www.roboticsbook.org/S52_diffdrive_actions.html)提供公式与图示。

| 对照 | 目标(v,Ω) | 预测(ωL,ωR)，rad/s | 2 s理想局部位移(Δx,Δy,Δyaw) |
| --- | --- | --- | --- |
| 直行 | (0.25,0) | (2.5,2.5) | (0.5 m,0,0) |
| 自转 | (0,0.6) | (−1.08,1.08) | (0,0,1.2 rad) |
| 圆弧 | (0.25,0.5) | (1.6,3.4) | (0.420735 m,0.229849 m,1 rad) |

表中数值来自理想运动学预测；真实位移与轮角由实验独立记录，再与预测比较。每个阶段先用0.5 s平滑升速，并至少保持0.3 s确认就绪，再记录真实起点，观测2 s，最后降速并确认实际停稳。预测表只对应中间2 s测量窗，不包含起步、就绪和刹停的路程。后一个阶段从小车当前实际位置开始，比较时使用该测量窗起点的局部坐标，不要求每次回到世界原点。

## 原生速度接口为什么看起来像Pose

此版本插件订阅Classic Transport的`~/模型名/vel_cmd`，消息类型为gazebo.msgs.Pose。它把position.x的数值读为v，把四元数所表达的yaw数值读为旧接口转向量va；本课工具按`va=−Ω`转换到上述逆时针为正的约定。因此给正Ω时，消息中的yaw数值为负。

这是一种复用Pose字段的历史速度接口，不能把它当目标位置，也不能照搬新Gazebo的Twist命令。学生使用课程命令传标准v、Ω，工具负责转换。感兴趣可核对[Classic 11.15.1插件实现](https://github.com/gazebosim/gazebo-classic/blob/gazebo11_11.15.1/plugins/DiffDrivePlugin.cc)。

插件只指定left_joint、right_joint，并从实际关节锚点距离推轮距、从左轮collision包围盒最大边的一半推半径；本课规则圆轮满足这个假设。纯visual修改不会改变轮半径估计，随意添加wheel_radius或wheel_separation标签也不会让此实现采用它们。几何在加载时缓存，修改场景后需要重载。

## 轮编码里程计与世界真值

**轮编码里程计**用测量窗内真实左右轮角增量ΔqL、ΔqR累计运动：先算轮程rΔq，再算车体前进与转角，最后把局部增量转到累计航向下。它依赖滚动假设与r、b标定；轮子空转时仍会累积“走过的路”。本课并不从速度命令积分后冒充轮编码测量，原生插件本身也没有发布本课所用的里程计。

**世界真值**另从Gazebo读取实际两轮锚点中点和车身航向，再转到本测量窗的局部坐标。它与编码积分分开计算。航向跨过±π时要连续展开，否则一次小转动会被误认为接近整圈反跳。三者应分别看：命令给了什么、轮子实际转了多少、车身实际走了多少。

## 个人文件与操作入口

```text
个人练习目录/
  parameters.json  标准前向速度、自转角速度与圆弧角速度
  world.sdf        小车、地面、轮地摩擦与原生插件
  config.py       当前参数与场景约束校验
  lab.py          查看配置、运行对照、切换轮面与回算
  drive_lab.cc    已提供的原生速度发布与状态观察工具
  instrument.py   从实际CSV独立回算运动学与验收量
  prepare.py      按源版本准备工具，不覆盖个人world
  verify.py       按当前轮面验收有限阶段
```

本课允许修改个人world.sdf中的两轮摩擦；其它车体结构保持课程规定值。主“编辑练习文件”按钮打开world.sdf；参数可用课程命令或实验终端`gedit --new-window parameters.json`打开。修改个人副本，保存后重载，再检查实际加载的配置；不要修改安装目录的源模板。

## 引导实验：从预测到两种测量

1. 以正常轮面开始。先运行`python3 lab.py check-config`检查个人参数与SDF，再开始/重载课程，运行`python3 lab.py inspect`核对真实关节、半径、轮距、摩擦和加载指纹。离线检查通过只表示配置可用于实验。
2. 计算直行两轮应同为2.5 rad/s，运行`python3 lab.py run straight`。区分完整起停路程与2 s测量窗，比较轮程、编码位移和世界真值；先解释这些量的来源，再看是否落入容差。
3. 运行`python3 lab.py run spin`。预测左负右正、航向增加约1.2 rad，两轮轴中点应接近原位；车身偏置质心绕圈不能直接当作自转失败。
4. 运行`python3 lab.py run arc`。预测右轮更快，局部x与y均增加；用真实测量窗航向检查转向符号，而非把世界Y方向始终当车体左方。
5. `python3 lab.py demo`运行正常轮面三个对照；“验收实验”依据当前配置取得真实记录。测量期间保持当前文件与控制输入一致，结束后由工具降速并读回实际停稳。原始drive.csv、status.json及验收verification.json保存在本次会话control目录；单阶段结果另存phase-validation.json。

运行信息流为：**个人参数/SDF合法性检查→核对实际加载几何、轮面与指纹→发零速并确认初始停稳→升速/确认轮速就绪→读取真实轮角与世界基线→2000个1 ms测量步→降速及实际停稳确认→独立比较预测、编码积分与世界真值→确认恢复原pause后保存结果。** 不恢复已走过的轨迹或旧时钟；原来运行的世界会继续运行。

## 单变量挑战：前向速度0.25改为0.35

只把parameters.json的forward_speed_m_s由0.25改为0.35，自转与圆弧角速度保持原值。预测直行2 s走0.7 m；圆弧转角仍1 rad，但半径v/Ω变为0.7 m，局部位移约(0.589030,0.321788) m；自转结果不变。保存→check-config→重载→inspect→重跑。若自转也改变，先查是否同时改了其它字段、使用了错误基线或漏掉重载。

## 第二个对照：轮子转，车身少走

保留同一速度设置，将两只轮子的mu和mu2一起由正常0.8改为0.001，地面仍为0.8；也可用`python3 lab.py set-surface slip`明确修改个人world.sdf，再重载。工具只改文件，不会暗中把当前运行服务器切成新轮面。此处mu/mu2是两个切向方向的摩擦系数，不是静摩擦/动摩擦的分别命名。

在新的低摩擦会话只运行直行对照，先预测轮角仍会被速度接口驱动，而车身位移显著小于轮程；再从真实轮角与世界轨迹检查差距。低摩擦不是“更准确的差速车”，它让编码里程计的滚动假设失效。记录后用`python3 lab.py set-surface normal`恢复正常轮面，保存并重载；不把两种场景混在同一份未重载的测量里。

## 排错与进一步思考

| 现象 | 检查哪条信息链 |
| --- | --- |
| 正Ω却向右转 | 标准Ω与旧Pose va的负号转换、左右关节对应、两关节+Y轴 |
| 轮子转但车身少走 | 实际轮面/地面摩擦、接触与轮程—真值差，不只盯命令 |
| 自转时“车体位置”画圆 | 读取的是偏置质心还是两轮轴中点 |
| 改大visual轮子仍按旧半径驱动 | 纯外观不进入collision包围盒；本课结构约束也不接受随意几何修改 |
| 参数/摩擦保存后结果未变 | 保存、重载并检查运行指纹与实际surface |
| 航向突然跳近2π | 包裹角跨π需展开，再比较累计角 |
| 重置模型后没有自动重播 | 工具会发零速并丢弃跨复位基线，实际连续停稳确认后停止待命；暂停时需继续或实际步进取得确认样本，要重播请显式运行demo |

独立挑战可先完成正常轮面的spin或arc，再运行`python3 lab.py replay-calibration 0.48`，对**当前已完成阶段的同一份真实记录**用错误的估计轮距b̂=0.48 m离线回算编码里程计，解释转角低估及圆弧偏差。这只改变估计模型，不是又做了一次物理实验，也没有改变stock插件从实际锚点取得的0.36 m轮距。接触导致的残余误差应从实际记录分析，不能把估计轮距当作插件物理轮距，或改动摩擦来掩盖正常场景的偏差。推导与参考答案在只读参考页，个人文件不会被答案覆盖。
