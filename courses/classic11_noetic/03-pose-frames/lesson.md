# 正确安装传感器：坐标与姿态

## 先预测模型原点，再寻找红色外壳
安装架 `rig` 的世界位置是 (2,1,0.2)，yaw=90°。安装参考系 `mount_frame` 沿架子的局部 z 上移0.6 m；标记模型 `sensor_marker` 再沿安装参考系的局部 x 偏移1 m。模型原点在哪里？红色外壳中心又在哪里？先画出轴并预测。

红盒仅代表传感器外壳的安装位姿，本课没有 `sensor` 元素或传感器数据。白球标记模型原点。模型原点由建模者选择，**不必位于几何中心**。两个模型均为静态模型，悬浮不代表它们之间存在机械连接。

## 最少的坐标背景
平移使用米，角度使用弧度：90°=π/2≈1.5707963 rad。坐标采用右手系，拇指沿正轴时，四指弯曲方向是正转方向；绕 +z 正转90°，会把 +x 转到 +y。屏幕右方不等于世界 +x。本课用红、绿、蓝分别表示 +x、+y、+z。

`pose` 六数顺序是 `x y z roll pitch yaw`。使用列向量时，RPY 对应 `R=Rz(yaw)Ry(pitch)Rx(roll)`，即绕固定参考轴 X、Y、Z 的外禀旋转。一般不能交换旋转顺序，也不能把两段 RPY 逐项相加。

位置变换为 `p_parent = R_parent_child × p_child + t_parent_child`：先把局部向量转到参考坐标方向，再加原点平移；姿态由两段旋转相乘。

## 对照文件算完整链路
点击“编辑练习文件”，在个人副本 `world.sdf` 中按名字找到安装架、frame、标记模型及其 `body` link。下面箭头表示**初始数值变换的组成**，不表示机械连接：

`world → rig → mount_frame → sensor_marker → body`

1. `rig`：世界位置 (2,1,0.2)，yaw=π/2。
2. `mount_frame`：相对 rig 为 (0,0,0.6)，所以世界位置 (2,1,0.8)，yaw仍为π/2。
3. `sensor_marker`：相对 mount_frame 为 (1,0,0)，转到世界方向成为 (0,1,0)，所以模型原点在 (2,2,0.8)。
4. `body`：相对标记模型偏移 (0.15,0,0.05)，局部 yaw=0.25。该平移在世界中成为 (0,0.15,0.05)，所以红盒中心在 (2,2.15,0.85)，世界 yaw≈1.8207963。

最后一步可以直接相加 yaw，是因为本例两段旋转共轴；一般仍需矩阵或四元数组合。红盒 visual 在 body 内的 pose 为零，所以这里红盒中心才与 body 原点重合。

## 三种关系分别回答什么
- `pose relative_to`：初始位置、姿态数值用哪个坐标系表达；不会让独立模型持续追随另一个模型。
- `frame attached_to`：命名坐标系在运动学意义上附着到谁。frame 本身不是刚体，也不为其他模型创建物理约束。
- `joint`：约束刚体之间的相对运动；实际固定安装将在关节课程中展开。

本例两个独立模型位于同一个 world 下，标记自己的 link 属于标记模型。两模型的 `static=true` 使它们各自不受动力学推进。`world_axes`、`mount_axes` 是用 box 画出的独立静态轴代理，表示加载时的参考位姿；它们不是抽象 frame 的实时渲染器，也不是 TF 发布器。

## 引导实验：先预测，再保存并重载
1. 点击“开始实验”。在“项目与命令”查询 rig 和 sensor_marker 的世界位姿，对照上述数值；结合 Gazebo 窗口的彩色轴判断方向。
2. 用 `gz model -m sensor_marker -i` 查看详细消息，定位名为 body 的 link 及它直接包含的 pose。它是模型相对位姿，不要误取 visual 的 pose，也不要直接当作世界位姿。
3. 只将 rig 的 yaw 改为0，保存并点击“重载项目”。预测模型原点应在 (3,1,0.8)，红盒中心在 (3.15,1,0.85)。查询并运行“验收实验”。
4. 将 rig yaw 恢复π/2，只把标记模型相对 mount_frame 的平移改为 (0,1,0)。保存、重载；先预测世界 x 将减小，再测量核对。
5. 恢复基准后，只删除 sensor_marker 模型 pose 的 `relative_to="mount_frame"`，保留 `1 0 0 0 0 0`。这个 world 直属模型改按 world 表达，原点应在 (1,0,0)。不要删除其他元素的同名属性。观察后恢复。

## 四元数、挑战和验收
四元数不是四个角。本课声明顺序为 `(x,y,z,w)`，姿态使用单位四元数；`q` 与 `-q` 表示同一旋转。例如 yaw=π/2 可写成 (0,0,0.7071068,0.7071068)，整体相反数也等价。本课 SDF 1.7 的 pose 仍填写六数 RPY，不能把四元数拼成七数 pose。

独立挑战采用第4步的侧向安装：手算模型原点和红盒中心的位置、朝向，再查询并验收。进一步只将 body 的局部 yaw 从0.25改为−0.25，预测哪些量变、哪些量不变。数学答案在单独的只读参考页，不会覆盖个人副本。

自动验收从当前副本解析变换链，对照真实 model/link 位姿，并按旋转等价性比较姿态。它会短暂把 rig 沿世界 x 移动0.35 m，检查独立标记没有被拖走，最后恢复 rig；不会改变原暂停状态。验收期间不要手动移动模型。坐标轴草图、原点识别和三种关系的解释仍由你人工完成。
