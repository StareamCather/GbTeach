# GazeboTeach 1.0.0

> 发布候选状态（2026-10-31）：26 个项目已有逐课实机记录；新增环境弹窗与安装器通过本地检查，仍待 ikaros 独立安装验收。设备当前不可连接，v1.0.0 标签及安装资源尚未发布，下面的发行页为预定入口。


V1 是一个通过 `.sh` 启动的中文 PyQt5 桌面教学应用。它为课程准备个人练习，启动真实 Gazebo、操作终端和观察终端，记录实际测量与验收结果。

## 交付范围

- **24 门主课：L01–L24。** 覆盖 SDF、坐标与模型、GUI 编辑器、质量惯性、摩擦碰撞、数值稳定性、关节、电机 PID、差速小车、Gazebo Transport、材质灯光地形 Actor、接触/激光/IMU/RGB/深度/力矩及其他传感器、同步 lockstep、ROS launch、URDF/Xacro、RViz/TF/仿真时钟。
- **2 项倒立摆选做：091 / 092。** 单级和双级近直立控制，采用 Python 关键行填空、背景补充、分层提示与独立只读参考。默认 TODO 保留给学员；不包含完整起摆算法。
- 教材、离线场景、资源、练习模板、参考材料和真实行为验收程序随应用分发。
- 独立课程进程、Master 与日志；暂停、单步、重置、窗口重开、练习持久化、模板恢复和实验清理。
- 启动环境检测及逐课兼容结果窗口。版本不匹配、缺依赖或未完成检测均保留阅读入口；符合声明条件不等于完成全部实际图形验证。
- 本机 / Docker 执行后端接口与可校验的 Docker 配置结构。Docker 自动连接和课程执行尚未实现；安装指南提供手动容器配置步骤。
- 自解包 `.sh`、相同载荷 `.tar.gz`、来源和逐文件摘要清单、SHA256 校验文件，以及安装运行指南。

## 兼容范围

真实验证平台：**ikaros，Ubuntu 20.04 x86_64、Python 3.8、PyQt5 / Qt 5.12、Gazebo Classic 11.15.1、ROS 1 Noetic**。

ROS 2 和现代 Gazebo 不替代本课程包使用的 ROS 1 / Classic API。其他设备可先运行诊断，依照逐课条件开放实验；Ubuntu 22.04 / ROS 2 用户可按指南手动建立 Focal / Noetic / Classic 容器。Docker、其他发行版、其他架构及各类宿主 GPU 组合尚未纳入本版本端到端验证。

安装包包含完整应用与这 26 个项目的资源，不捆绑操作系统、ROS、Gazebo、驱动或系统依赖，也不自动修改它们。部分课程首次启动会在独立工作目录编译随包提供的 SDK 程序。

## 安装与来源

请阅读 [V1 安装运行指南](V1_INSTALL.md)。推荐下载 `GazeboTeach-1.0.0-ubuntu20.04-x86_64.sh`，校验 SHA256，先执行 `--check`，再安装。

默认应用入口：

```bash
"$HOME/.local/opt/GazeboTeach/bin/gazeboteach"
```

个人练习与记录默认保存到 `~/.local/share/GazeboTeach`，与安装版本分开。源码提交和课程目录以随包 `release-manifest.json` 为准。课程逐项验证记录见 [VALIDATION_LOG.md](VALIDATION_LOG.md)；最终安装包的实测范围以发行页附带的验证记录为准。

安装器流程：从固定 Git 提交生成载荷 → 验证归档摘要和逐文件清单 → 写入临时版本目录 → 再次验证 → 原子安装该版本 → 更新当前入口。重复安装同版本会校验复用，拒绝覆盖修改过的版本或无关目录；卸载保留个人数据和其他版本。

启动兼容流程：探测实际环境 → 按每课版本和依赖生成结果 → 弹窗展示不能运行或尚未确认的课程 → 用户阅读教材并进入满足条件的实验。Docker 配置校验与本机执行分开，保存或校验配置不会触发容器操作。
