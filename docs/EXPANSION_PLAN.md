# 附加专项与多版本课程实施计划

本计划在 V2 已交付的39个项目之上增加专项课程。原01–37与091/092的课程文件、课号、教学顺序和学员练习保持不变；新专项链接相关基础课。源码新功能与已发布的 v2.0.0 安装包分别记录，旧安装包不自动包含本计划中的新增内容。

## 执行原则与当前目标

每次只保留一个活动目标；完成真实验收、独立提交、Windows中转推送和远端SHA核对，才结束该目标并建立下一目标。并行协作只编写/审查当前目标所需材料；已产生的后续草稿不是已完成课程。遇到失败保留日志、修复后重跑对应条件，不把启动成功计为教学目标通过。

当前活动目标：**G03 计划与版本适配框架**。已有附加课草稿均待逐项验收和发布。后续状态以 `docs/EXPANSION_VALIDATION.md` 的提交与证据为准。

## 多版本边界

首个新运行配置为 **Ubuntu24.04 / ROS2 Jazzy / Gazebo Harmonic (gz-sim8)**，与原 **Ubuntu20.04 / ROS1 Noetic / Classic11.15.1** 分开。独立Gazebo课程不凭ROS是否存在而禁用，ROS2课程则检查Jazzy包索引与逐课依赖。没有匹配实现的Humble/Fortress、Ionic、Jetty等组合显示检测结果、允许阅读、明确禁用不兼容实验；不会把相近版本或命令同名当作已适配。

参考[官方ROS/Gazebo配套表](https://gazebosim.org/docs/harmonic/ros_installation/)和[Jazzy安装平台](https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html)。未来适配其他发行版须新增运行配置及实际测试记录。本批现代课是独立专项轨道，不声明原37门Classic插件/GUI课已全部移植，也不声明ros_control等价于ros2_control。

容器首先用于隔离测试与用户手动启动整套应用。现有Docker配置接口不等于自动从宿主连接容器的运行器。保留用户现有系统、GPU驱动和网络设置；只清理本次创建的具名容器/进程。

## LIO三课的实现约束

使用[FAST_LIO官方仓库](https://github.com/hku-mars/FAST_LIO)及[Point-LIO官方仓库](https://github.com/hku-mars/Point-LIO)，分别固定提交、依赖与源码许可；第一代与FAST-LIO2不能都用同一默认分支后仅改标题。算法和第三方源码保留其各自许可，不把上游GPL源码重新标为本平台MIT。

共同前置是三维点云、IMU比力与角速度、SO(3)/误差状态、外参、时间单位。讲解保持专业表述，附必要背景和官方/原论文链接。课程提供可运行完整参考与少量有提示的局部填空，不能靠屏蔽核心估计步骤来让参考演示通过。

数据必须来自真实模拟器传感器或有来源的上游公开数据。普通二维LaserScan不能伪装三维旋转雷达；把每帧header.stamp复制成所有点的“采样时刻”不能声称已实现扫描内去畸变。瞬时扫描若offset均为零，须明确瞬时模型；扫描跨时刻采集时保存真实每点offset、ring与单位。IMU与点云有共同模拟时钟、已知外参、静止初始化段和激励运动。

先审计原始字段/时间范围/单位/外参，再运行上游估计器，最后比较Gazebo真值轨迹、地图一致性、有效输出率和计算耗时。转弯/快速运动/时间偏移/错误外参/退化场景作为单变量；不能只以RViz中有点云判通过。ROS2端口标明官方或社区来源，并单独测试；ROS1桥接不自动等于原生ROS2实现。

## 因子图LIO专项

A53以[LIO-SAM官方实现](https://github.com/TixiaoShan/LIO-SAM)为主，ROS1主分支与上游ROS2分支分别固定源码和GTSAM依赖。先用一个可计算的小位姿图解释变量、因子、残差、协方差/白化、雅可比、线性化和增量求解，再进入真实LiDAR/IMU系统。小图练习不能冒充完整LIO实现。

阅读与实验沿真实数据流：逐点去畸变 → 特征/关键帧 → 里程计因子 → IMU预积分和偏置估计 → iSAM2增量更新 → 全局地图修正。解释全程地图图与周期重置IMU图的职责，区分增量平滑、局部窗口和固定滞后边缘化，不能把所有优化都称为滑动窗口。回环和GPS是附加约束；缺少有效输入时不虚构约束或成功结果。

使用相同来源/审计标准的场景和传感器，分别验证不开回环、真实重访并开回环、可选GPS约束。记录ATE/RPE、回环接纳/拒绝、优化前后关键帧及重建全局地图，不能仅观察RViz累积点云。IMU姿态输入、轴向和外参按所固定的上游实现要求核对，六轴与九轴输入不混为一谈。GTSAM与上游许可完整保留，ROS2端口另做编译和运行验收。

## 每课统一交付

每课包含完整背景、信息流和算法步骤、个人配置与素材、预测实验、单变量调整、错误诊断、独立挑战、先修链接及独立验收。记录区分源码草稿、已构建、真实自动验收、真实GUI检查、待人工检查。学员填空的成绩与参考实现运行验收分开。保持现有练习不被参考答案覆盖。
