## 框架接口与默认行为

- Python 3.8 + PyQt5，兼容 Qt 5.12；由 ./launch.sh 在图形桌面启动。
- CLI：python3 -m gazeboteach --diagnose / --list / --smoke ID [--gui] / --gui-check。
- 环境识别区分安装与激活，首版只提供 Classic 11/Noetic 课程；无 ROS 时独立课程仍开放。
- 课程描述提供编号、版本、依赖、教材、世界、命令、prepare、after_start、startup 和 verify。
- 每次实验独立 Master 端口与 IGN_PARTITION，仅管理自己创建的进程组。
- 个人练习保存在用户数据目录；模板更新保留个人修改并提示差异。自动验收始终使用全新副本。
- 浏览课程不默认弹窗；开始实验才初始化，可在应用中设置进入即启动。
- 初始化、构建和验证在后台执行，所有实际步骤和日志可查看。
- 提供暂停/继续/单步/重置模型/重启/编辑练习/备份恢复/结束实验；终端与 GUI 可分别恢复。
- 课程内容保持专业术语，提供必要背景、算法信息流、预测实验、数据分析、错误诊断和先修外链。

## 验收约束

- 每课至少通过 SDF/资源解析、实际服务端运行与一个对应教学目标的自动观测。
- GUI 编辑器和渲染类教学需额外图形检查，人工交互学习目标明确标注。
- 相机、深度和 GPU 传感器在真实图形会话验证；无 GUI 不等于没有渲染依赖。
- 失败保留日志，先定位依赖/接口/数值问题再修改；不以延长等待掩盖功能问题。
- 故障诊所允许预期失败，但必须验证故障可检测且修复路径可运行。
- 初学者可运行演示；进入练习时保留关键教学操作，不自动替代学习任务。
