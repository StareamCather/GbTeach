# GazeboTeach 2.0.0

V2 交付 L01–L37 主课与 L091 / L092 倒立摆选做，合计 **39 个独立项目**。中文 PyQt5 工作台管理个人练习、真实 Gazebo / ROS 会话、终端、控制、测量日志和课程验收；模板、参考材料、离线场景及需现场编译的源码随安装包提供。

## 相对 V1 的交付变化

- 补全 L25–L37：ros_control、Model / World / Sensor / Visual / GUI / System 六类 Classic 插件、状态日志和隔离回放、多机器人、性能与批量实验、故障诊所、仓库与机械臂综合任务。
- 框架世界控制增加精确 Classic 11.15.1 SDK 下的每会话持久原生助手。暂停 / 继续读取实际 WorldStatistics；单步核对实际 iterations；模型复位保留模拟时钟。修改命令只发一次，未知结果不自动换路径重发，助手先于本会话服务端清理。[控制流程](NATIVE_CONTROL.md)
- 启动检测区分运行环境、SDK、C++ / Qt 开发条件、已安装和当前激活的 ROS，并按逐课依赖显示可运行、禁用与未确认原因。教材和只读前置资料仍可阅读。[检测流程](ENVIRONMENT_V2.md)
- 发布工具强制 V2 精确 39 课与必要源码 / 文档，从单一 Git commit 导出自解包 `.sh`、相同载荷 `.tar.gz`、逐文件 manifest、SHA256SUMS 和独立 V2 指南。[安装和打包流程](V2_INSTALL.md)

V1 的 26 课安装包、标签和说明保留原有含义；本版本扩展范围不追写成 V1 已交付内容。

## 课程能力与边界

课程顺序、实际输入输出和先修关系见 [V2 课程地图](V2_CURRICULUM.md)。L091 / L092 默认保留 Python 关键代码填空；未填写时未评分是预期状态，参考答案仅用于独立临时回归，不覆盖学生练习。两课讲近直立稳定，不包含完整起摆。

L20 实测对象是 GPS、磁力计、高度计、声纳和 Logical Camera 的 Classic 原生消息与模型边界；没有卫星信号、气压解算、声波传播或图像识别。L36 从真实激光扫描、轮式运动、物理滑门与测量条件完成有限状态机任务，扫描投影不是 SLAM 或通用导航栈。L37 使用真实双关节力矩、解析运动学、腕部 FT 与接触反馈推动物块，并演示失能超时、显式复位和恢复；HOLD 阶段仍进行 PD 保持，不能用零力矩作为正确保持的条件。

## 兼容与分发

原生基准是 Ubuntu 20.04 x86_64、系统 Python 3.8、PyQt5 / Qt 5.12、Gazebo Classic 11.15.1、ROS 1 Noetic、gazebo_plugins 2.9.3。需要 C++ / Qt / ROS 依赖的课程各自检查；框架 SDK 助手是可选能力，基础课程在不具备该能力时有明确 legacy-cli 记录。精确 ABI 课程不把未知补丁版本当作兼容。

ROS 2、现代 Gazebo、其他架构与其他发行版没有自动课程移植。用户仍可阅读教材和诊断具体缺项。Docker 交付范围为执行后端接口、可校验配置结构和[手动配置指南](V2_DOCKER.md)，没有自动拉取镜像或自动容器课程执行，未宣称容器 GUI / GPU / 全39课已经端到端验收。Noetic 镜像标签也不保证内含精确 11.15.1 SDK 与 2.9.3 插件。

发行包包含应用与全部39课源码资源，不捆绑或替换操作系统、Gazebo、ROS、系统依赖、GPU 驱动。安装器不执行 apt / sudo；新版本使用独立目录和原子 current 入口，保留个人练习和其他版本，拒绝覆盖修改过的版本。
